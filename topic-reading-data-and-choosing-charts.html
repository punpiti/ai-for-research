อ่านข้อมูลและเลือกกราฟให้ตรงงานของผู้อ่าน

  • ขอให้ AI แสดงข้อมูลดิบ/การแจกแจงก่อนตารางสรุป อธิบายได้ว่าสถิติสรุปเท่ากันซ่อนรูปร่างข้อมูลที่ต่างกันอย่างไร และถาม AI ได้ว่ากรอง ตัด หรือรวมแถวใด และตัวหารของภาพคืออะไร
  • ระบุงานอ่านค่าของผู้อ่านก่อนให้ AI วาด เลือกจุดเริ่มต้นของกราฟจากตารางงานอ่านค่า และตรวจข้อเสนอกราฟของ AI ด้วยคอลัมน์ 'สิ่งที่ต้องตรวจ'
  • เลือกการเข้ารหัสให้ตรงงานเปรียบเทียบ (ตำแหน่ง/ความยาวก่อนมุม/พื้นที่/สี) ใช้สีเน้นทีละเรื่อง เลือก colormap ที่ความสว่างเรียงลำดับ และตรวจว่าภาพยังอ่านได้เมื่อเป็นขาวดำและสำหรับผู้ที่มองบางสีไม่เห็น
  • แยกความหมายของ SD, SE, CI และ IQR เลือก interval ให้ตรงคำถาม และเขียนชนิด interval พร้อม n ในคำบรรยายภาพทุกครั้ง

Notebook 1

ดูข้อมูลจริงก่อนเชื่อสถิติสรุป

ใน Notebook นี้คุณจะรัน Part A ใน Google Colab เทียบกราฟสรุปกับข้อมูลจริง แล้วได้บันทึกของตัวเองว่าสถิติสรุปซ่อนอะไรและภาพแต่ละภาพใช้แถวใด

ทำใน Google Colab อย่างเดียว ไม่ต้องใช้ AI ในส่วนนี้ — เปิด รัน ดู แล้วจดสิ่งที่เห็นด้วยตัวเอง

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • บัญชี Google สำหรับเปิด Google Colab
  • notebook Part A — อ่านกราฟและตรวจสิ่งที่ AI เลือก (เปิดจากลิงก์ได้ทันที)
  • ถ้าใช้ Colab ไม่ได้: ไฟล์ชุดเดียวกัน course-materials/module-07/notebooks/module-07a-read-and-audit.ipynb (ติดตั้งมากับ Module 1) เปิดด้วย tools/start-module-07 (Module 1 สร้างให้เมื่อเห็น MODULE7_READY) หรือดาวน์โหลด module-07-notebook-bundle.zip

ขั้นตอน

  1. เปิดลิงก์ Part A ด้วยบัญชี Google ของคุณ แล้วกด Runtime → Run all (cell แรกติดตั้งไลบรารีและฟอนต์ไทยให้เอง)
    • หาหัวข้อจาก สารบัญ ด้านซ้ายของ Colab · อยากเก็บสิ่งที่แก้ให้ File → Save a copy in Drive ก่อน
    • ข้อมูลทั้งหมดใน notebook เป็นข้อมูลจำลองเพื่อการสอน · ห้ามอัปโหลดข้อมูลวิจัยจริงหรือข้อมูลส่วนบุคคลขึ้น Colab
  2. ไปที่ Part A › หัวข้อ 1 › ดูสถิติสรุปก่อน
  3. ดูกราฟ mean ± SD แล้ว เดาก่อน ว่าข้อมูลแต่ละกลุ่มหน้าตาอย่างไร จดคำเดาไว้หนึ่งบรรทัดต่อกลุ่ม (กระดาษหรือโน้ตใดก็ได้)
  4. ดู cell ถัดไปที่เฉลยด้วย violin + จุดข้อมูล เทียบกับที่เดาไว้ (กลุ่มใดใกล้ปกติ กลุ่มใดมีสองยอด กลุ่มใดมีค่าผิดปกติค่าเดียว)
  5. ไปที่ Part A › หัวข้อ 3 › สิ่งที่ถูกตัดออกอาจเปลี่ยนการตัดสินใจ เทียบภาพซ้าย (เฉพาะแถวที่ล้มเหลว) กับภาพขวา (การทดสอบทั้งหมด)
  6. จดเองเป็น บันทึก "แถวในภาพซ้าย/ขวา": ภาพซ้ายและภาพขวาใช้แถวใด และข้อสรุปต่างกันอย่างไร
  7. เขียนหนึ่งประโยค: สถิติสรุปในตัวอย่างนี้ซ่อนอะไรไว้ และกราฟแบบใดเปิดเผยได้

ทำใน VS Code กับ AI อย่างเดียว ไม่ต้องเปิด Colab — AI อ่านไฟล์ notebook ที่ติดตั้งไว้ในเครื่องแล้ว

  • โฟลเดอร์ module-07-work/ และ Python ของโมดูล .venv-module07 (ตัวติดตั้ง Module 1 สร้างไว้ เมื่อเห็น MODULE7_READY)
  • บันทึก "แถวในภาพซ้าย/ขวา" ที่คุณจดใน Notebook ของส่วนนี้ (look-at-raw-data-before-summary-stats)

    อ่าน course-materials/module-07/notebooks/module-07a-read-and-audit.ipynb เฉพาะหัวข้อ 3 “สิ่งที่ถูกตัดออกอาจเปลี่ยนการตัดสินใจ” แล้วบอกว่าภาพแต่ละภาพกรอง ตัด หรือรวมแถวใดไปบ้าง ตัวหารของแต่ละภาพคืออะไร และข้อสรุปเปลี่ยนอย่างไรเมื่อใส่แถวที่ถูกตัดกลับเข้ามา ยกบรรทัดโค้ดที่ใช้กรองแถวมาด้วย ห้ามแก้ไฟล์ใด ๆ

  2. เปิดไฟล์ .ipynb ใน VS Code ค้นบรรทัดโค้ดที่ AI ยกมา แล้วตรวจเองว่าเงื่อนไขกรองตรงกับโค้ดจริงหรือไม่

    • รายการจุดที่ AI ตอบผิดหรือไม่ครบ (ถ้าไม่มี ให้เขียนว่าไม่มี)

Exploring 1

ดูข้อมูลจริงก่อนเชื่อสถิติสรุป

ใน Exploring workshop นี้คุณจะเขียน prompt เองให้ AI แสดงการแจกแจงของข้อมูลที่อยู่เบื้องหลังตารางหรือกราฟสรุปหนึ่งชิ้น แล้วสร้าง module-07-work/output/raw-vs-summary.md ที่ตัดสินว่าข้อสรุปเดิมยังใช้ได้หรือไม่

ผู้เรียนเขียน prompt เอง ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว · โฟลเดอร์ module-07-work/ (ตัวติดตั้ง Module 1 สร้างไว้)
  • ทำ workshop "ดูข้อมูลจริงก่อนเชื่อสถิติสรุป" (Notebook และ Prompt) ของหัวข้อนี้แล้ว
  • ตารางสรุปหรือกราฟสรุปหนึ่งชิ้น (เช่น mean ± SD ต่อกลุ่ม) พร้อมข้อมูลต้นทาง จากงานวิจัยของคุณหรือของนิสิตที่คุณดูแล ที่มีสิทธิ์นำเข้า AI
    • ถ้ายังไม่มี: ใช้ course-materials/module-07/examples/figure-consistency/mock-study-data.csv (ติดตั้งมากับ Module 1) หรือกรณีฝึกสำรองประชากรไทย (ข้อมูลเปิด ให้ AI ดาวน์โหลดและทำใบรับข้อมูลตามหน้านั้น)

ขั้นตอน

  1. สร้างโฟลเดอร์ module-07-work/output/ และไฟล์ module-07-work/output/prompts.md (ถ้ามีจาก Exploring workshop ข้ออื่นแล้ว ให้เพิ่มหัวข้อใหม่ต่อท้าย) ไว้จดทุกรอบเป็น prompt → สรุปคำตอบของ AI → สิ่งที่คุณตัดสินใจ
  2. เขียน prompt ให้ AI แสดงข้อมูลระดับ observation หรือการแจกแจงของตัวแปรเดียวกับตารางสรุป ก่อนให้ AI สรุปใด ๆ
  3. เขียน prompt ให้ AI รายงานว่าแถวใดถูกกรอง ตัด หรือรวม ด้วยเกณฑ์อะไร และตัวหารของภาพคืออะไร แล้วตรวจกับโค้ดหรือข้อมูลเอง
  4. เทียบภาพการแจกแจงกับตารางสรุปเดิม แล้วตัดสินว่าข้อสรุปเดิมยังใช้ได้หรือไม่
  5. สร้าง module-07-work/output/raw-vs-summary.md บันทึกผล พร้อมภาพการแจกแจงอย่างน้อย 1 ภาพ

ข้อกำหนด

  • เขียน prompt เองทุกข้อ ไม่ใช้ prompt สำเร็จรูปจาก workshop และจดทุกรอบใน module-07-work/output/prompts.md
  • ระบุว่าตรวจผลของ AI อย่างไร (เปิดภาพดูเอง คำนวณเอง หรือเปิดข้อมูลต้นทาง) และแก้อะไรเอง
  • ข้อมูลที่ไม่มีสิทธิ์นำเข้า AI (ข้อมูลส่วนบุคคล ข้อมูลลับ manuscript ที่ยังไม่เผยแพร่) ให้ใช้ข้อมูลจำลอง/ข้อมูลเปิดแทน
  • ถ้า AI เสนอวิธีทางสถิติที่คุณอธิบายเหตุผลไม่ได้ ให้หยุดและปรึกษาผู้เชี่ยวชาญก่อนใช้ผล

ขั้นตอน

  1. สั่ง AI

    อ่านโค้ดของกราฟในหัวข้อ 3 “เส้นกลางและแถบเงาตอบคนละคำถาม” จาก course-materials/module-07/notebooks/module-07a-read-and-audit.ipynb แล้วบอกว่าเส้นกลางคำนวณจากอะไร แถบเงาคือ SD, SE, CI หรือ IQR ตอบคำถามอะไร n เท่าไร และเขียนคำบรรยายภาพหนึ่งประโยคที่ระบุชนิด interval กับ n ห้ามแก้ไฟล์

  2. เทียบคำตอบของ AI กับบันทึก "เส้น · แถบ · n" ของคุณ (แถบนี้คือช่วง 25–75% ของ runs ไม่ใช่ CI) และเปิดโค้ดใน .ipynb ดูเองว่าแถบคำนวณอย่างไร

  3. ถ้า AI เรียกว่า CI หรือ "ความน่าจะเป็นที่ค่าจริงอยู่ในแถบ" ให้จดเป็นข้อผิดพลาด

  4. สร้างไฟล์ module-07-work/interval-notes.md แล้วเขียน: คำบรรยายภาพหนึ่งประโยคที่ระบุชนิด interval และ n ถูกต้อง (แก้จากของ AI ถ้าจำเป็น) · AI ระบุชนิด interval ถูกหรือผิด

Exploring 4

แสดงความไม่แน่นอนให้ตรงความหมาย (SD, SE, CI, IQR)

ใน Exploring workshop นี้คุณจะเขียน prompt เองให้ AI ตรวจชนิด interval และ n ของกราฟหนึ่งภาพในงานของคุณ แล้วได้ภาพก่อน–หลังกับ module-07-work/output/interval-check.md ที่มีคำบรรยายภาพใหม่

ผู้เรียนเขียน prompt เอง ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว · โฟลเดอร์ module-07-work/ และ Python ของโมดูล .venv-module07 (ตัวติดตั้ง Module 1 สร้างไว้)
  • ทำ workshop "แสดงความไม่แน่นอนให้ตรงความหมาย" ของหัวข้อนี้แล้ว
  • กราฟที่มี error bar หรือแถบเงาหนึ่งภาพจากงานของคุณหรือของนิสิต พร้อมโค้ดหรือข้อมูลต้นทาง ที่มีสิทธิ์นำเข้า AI
    • ถ้ายังไม่มี: ใช้ course-materials/module-07/examples/figure-consistency/mock-study-data.csv (ติดตั้งมากับ Module 1) หรือกรณีฝึกสำรองประชากรไทย (ข้อมูลเปิด ให้ AI ดาวน์โหลดและทำใบรับข้อมูลตามหน้านั้น)

ขั้นตอน

  1. สร้างโฟลเดอร์ module-07-work/output/ และไฟล์ module-07-work/output/prompts.md (ถ้ามีจาก Exploring workshop ข้ออื่นแล้ว ให้เพิ่มหัวข้อใหม่ต่อท้าย) ไว้จดทุกรอบเป็น prompt → สรุปคำตอบของ AI → สิ่งที่คุณตัดสินใจ
  2. เขียน prompt ให้ AI ตรวจจากโค้ด/ข้อมูลต้นทางว่า interval นั้นคือ SD, SE, CI หรือ IQR และ n เท่าไร แล้วยืนยันเองจากโค้ดหรือการคำนวณ
  3. ตัดสินว่าชนิด interval ตรงกับคำถามของภาพหรือไม่ (บรรยายการกระจาย หรือความแม่นของค่าประมาณ) ถ้าไม่ตรง ให้ AI ปรับภาพ และบันทึกภาพก่อน–หลังไว้ใน module-07-work/output/
  4. เขียนคำบรรยายภาพใหม่ที่ระบุชนิด interval และ n; ถ้า n น้อย ให้แสดงจุดข้อมูลจริงด้วย
  5. สร้าง module-07-work/output/interval-check.md บันทึกผลตรวจ เหตุผล และคำบรรยายภาพใหม่

ข้อกำหนด

  • เขียน prompt เองทุกข้อ ไม่ใช้ prompt สำเร็จรูปจาก workshop และจดทุกรอบใน module-07-work/output/prompts.md
  • ระบุว่าตรวจผลของ AI อย่างไร (เปิดภาพดูเอง คำนวณเอง หรือเปิดข้อมูลต้นทาง) และแก้อะไรเอง
  • ข้อมูลที่ไม่มีสิทธิ์นำเข้า AI (ข้อมูลส่วนบุคคล ข้อมูลลับ manuscript ที่ยังไม่เผยแพร่) ให้ใช้ข้อมูลจำลอง/ข้อมูลเปิดแทน
  • ถ้า AI เสนอวิธีทางสถิติที่คุณอธิบายเหตุผลไม่ได้ ให้หยุดและปรึกษาผู้เชี่ยวชาญก่อนใช้ผล
