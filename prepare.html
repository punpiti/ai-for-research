สิ่งที่จะพร้อมใช้หลังติดตั้ง

ใช้ทำอะไรซอฟต์แวร์รุ่น
เขียนงานและคุยกับ AIVS Code + Codex, Claude Code หรือ Clineรุ่นที่รองรับล่าสุด

คำสั่ง Terminalเลือกระบบ แล้วคัดลอกคำสั่งไปวาง

Windows 11

เปิด PowerShell แบบปกติ

& { $env:AI_RESEARCH_PROJECT_NAME='ai-for-research-workspace'; $setup = Join-Path $env:TEMP 'ai-research-setup.ps1'; Invoke-WebRequest -UseBasicParsing -ErrorAction Stop "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-windows.ps1" -OutFile $setup; powershell -NoProfile -ExecutionPolicy Bypass -File "$setup" -Mode Install -Agent openrouter }

วางคำสั่ง กด Enter และตอบ Yes หาก Windows ขอสิทธิ์

macOS

เปิด Terminal

setup="$(mktemp)" && curl -fsSL "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-macos.sh" -o "$setup" && AI_RESEARCH_PROJECT_NAME='ai-for-research-workspace' AI_GRAD_AGENT=openrouter bash "$setup" --install

วางคำสั่ง กด Enter และใส่รหัสผ่านของเครื่องเมื่อระบบขอ

Linux (Ubuntu/Debian)

เปิด Terminal

setup="$(mktemp)" && curl -fsSL "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-linux.sh" -o "$setup" && AI_RESEARCH_PROJECT_NAME='ai-for-research-workspace' AI_GRAD_AGENT=openrouter bash "$setup" --install

วางคำสั่ง กด Enter และใส่รหัสผ่านของเครื่องเมื่อระบบขอ

ระหว่างติดตั้ง: ระหว่างติดตั้งด้วยสิทธิ์ admin จะมีแถบความคืบหน้าและเวลารออัปเดตทุก 10 วินาที แม้การดาวน์โหลดไม่มีเปอร์เซ็นต์ให้รายงาน ให้เปิดหน้าต่างติดตั้งทั้งสองไว้จนเสร็จ
ติดตั้งสำเร็จเมื่อ: หน้าติดตั้งแสดง FINAL_RESULT PASS และ VS Code เปิดโฟลเดอร์ ai-for-research-workspace

AIRR — AI for Research & Review (แนะนำ): ใช้บัญชีเว็บสร้าง AIRR Key ครั้งเดียว แล้วส่งจาก VS Code โดยไม่ต้องกรอกรหัสคลาสหรือชื่อผู้ส่ง

ถ้าสร้าง AIRR Key ก่อนติดตั้ง ตัวติดตั้งเชื่อม VS Code ให้แล้ว ใช้คำสั่งด้านล่างได้เลย ถ้ายังไม่ได้เชื่อม ให้กลับไปสร้าง key ที่ขั้น 2 แล้วคัดลอกคำสั่ง login ที่หน้าเว็บแสดง

& .\tools\airr.ps1 init module-1; & .\tools\airr.ps1 submit module-1
bash tools/airr.sh init module-1 && bash tools/airr.sh submit module-1
