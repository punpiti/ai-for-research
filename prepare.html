รู้จัก Terminal / CLI

Terminal คืออะไร?

Terminal คือช่องสำหรับบอกคอมพิวเตอร์ให้ทำงานด้วยข้อความ ส่วน CLI หรือ Command-Line Interface คือโปรแกรมที่เราเรียกใช้ผ่านช่องนี้ หนึ่งบรรทัดคือหนึ่งคำสั่ง ในกิจกรรมนี้ไม่ต้องจำคำสั่งและไม่ต้องพิมพ์เอง—อ่านก่อน กด Copy วาง แล้วกด Enter

Windows 11

เปิด PowerShell แบบปกติ

  1. 1
    กดปุ่ม Windows บน keyboard หรือคลิก Start
  2. 2
    พิมพ์ PowerShell
  3. 3
    คลิก Windows PowerShell หรือกด Enter
  4. 4
    ตรวจ title bar ต้องไม่มีคำว่า Administrator

พร้อมเมื่อเห็น PS C:\Users\ชื่อผู้ใช้>

ตัวอย่าง PowerShellPS C:\Users\student> ▌PS = PowerShell · C:\Users\student = โฟลเดอร์ปัจจุบัน · ▌ = จุดวางคำสั่ง
  • Paste: Ctrl+V
  • Run: กด Enter แล้วรอจนเห็น PS ...> กลับมา
  • Stop: กด Ctrl+C แล้วเรียกผู้สอน
  • Safety: อ่านก่อนรัน และไม่วาง password/token

macOS

เปิด Terminal

  1. 1
    กด Command (⌘) + Space
  2. 2
    พิมพ์ Terminal
  3. 3
    เลือกแอป Terminal แล้วกด Enter
  4. 4
    ใช้หน้าต่างปกติ ไม่พิมพ์ sudo ในขั้นนี้

พร้อมเมื่อเห็นชื่อเครื่องตามด้วย % หรือ $

ตัวอย่าง macOS Terminal (zsh)student@MacBook ~ % ▌student@MacBook = ผู้ใช้และชื่อเครื่อง · ~ = home folder · % = พร้อมรับคำสั่ง
  • Paste: Command (⌘)+V
  • Run: กด Enter แล้วรอจนเห็น % หรือ $ กลับมา
  • Stop: กด Control+C แล้วเรียกผู้สอน
  • Safety: อ่านก่อนรัน และไม่วาง password/token

Linux (Ubuntu/Debian)

เปิด Terminal

  1. 1
    Linux: เปิดแอป Terminal
  2. 2
    รอจนเห็นบรรทัด prompt
  3. 3
    ยังไม่พิมพ์ sudo ในขั้นนี้

พร้อมเมื่อเห็นชื่อผู้ใช้และเครื่องตามด้วย $

ตัวอย่าง Linux (Ubuntu/Debian) Terminalstudent@ubuntu:~$ ▌student@ubuntu = ผู้ใช้และชื่อเครื่อง · ~ = home folder · $ = พร้อมรับคำสั่ง
  • Paste: Ctrl+Shift+V
  • Run: กด Enter แล้วรอจนเห็น $ กลับมา
  • Stop: กด Ctrl+C แล้วเรียกผู้สอน
  • Safety: อ่านก่อนรัน และไม่วาง password/token
จบขั้นที่ 1 เมื่อ: เปิด Terminal แบบปกติได้ รู้ตำแหน่ง prompt และทำ Copy → Paste → Enter ได้ โดยยังไม่ติดตั้งอะไร

ก่อนติดตั้ง

คุณจะใช้ AI ตัวไหน?

เลือก AI ที่จะใช้ครั้งเดียว จากนั้นคัดลอกคำสั่งติดตั้งที่หน้าเว็บเตรียมให้

ยังไปต่อไม่ได้: กรุณาเลือก AI หนึ่งตัว

ขั้นที่ 2 · Installation

ติดตั้งซอฟต์แวร์

คำสั่งเดียวจะเตรียม VS Code, AI ที่เลือก และเครื่องมือสำหรับอ่าน วิเคราะห์ และสร้างเอกสารที่ใช้ในคลาส

ระหว่างติดตั้ง: รอให้แถบความคืบหน้าจบ หากระบบถามสิทธิ์ติดตั้งให้กดยืนยันหรือใส่รหัสผ่านของเครื่อง แล้วกลับมารอที่หน้าต่างเดิม
ชื่อนี้จะใช้เป็นโฟลเดอร์งานของคุณ

Windows 11

เปิด PowerShell ปกติ

1 คัดลอกคำสั่งนี้แล้วกด Enter ครั้งเดียว

& { $env:AI_RESEARCH_PROJECT_NAME='ai-for-research-workspace'; $setup = Join-Path $env:TEMP 'ai-research-setup.ps1'; Invoke-WebRequest -UseBasicParsing -ErrorAction Stop "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-windows.ps1" -OutFile $setup; powershell -NoProfile -ExecutionPolicy Bypass -File "$setup" -Mode Install -Agent codex }

หาก Windows ถามสิทธิ์ ให้ตอบ Yes แล้วรอจน VS Code เปิดขึ้นมา

macOS

เปิด Terminal ปกติ

1 คัดลอกคำสั่งนี้แล้วกด Enter ครั้งเดียว

setup="$(mktemp)" && curl -fsSL "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-macos.sh" -o "$setup" && AI_RESEARCH_PROJECT_NAME='ai-for-research-workspace' AI_GRAD_AGENT=codex bash "$setup" --install

ใส่รหัสผ่านของเครื่องเมื่อระบบขอ แล้วรอจน VS Code เปิดขึ้นมา

Linux (Ubuntu/Debian)

setup="$(mktemp)" && curl -fsSL "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-linux.sh" -o "$setup" && AI_RESEARCH_PROJECT_NAME='ai-for-research-workspace' AI_GRAD_AGENT=codex bash "$setup" --install

ใส่รหัสผ่านของเครื่องเมื่อระบบขอ แล้วรอจน VS Code เปิดขึ้นมา

ตรวจว่า Workspace เปิดแล้ว

คำสั่งติดตั้งจะเปิด Workspace ให้อัตโนมัติ หากเห็นโฟลเดอร์งานใน VS Code แล้ว ไม่ต้องเปิดซ้ำ ให้ไปที่ “เชื่อมต่อบัญชี AI” ได้เลย วิธีด้านล่างใช้เมื่อปิดหน้าต่างไปแล้วหรือต้องการเปิดใหม่เท่านั้น

Workspace ไม่เปิดอัตโนมัติ? ดูวิธีเปิดใหม่

    รอให้ VS Code เปิดโฟลเดอร์งาน
code --profile "AI for Research - codex" (Join-Path $HOME 'ai-for-research-workspace')

  4. 4
    วางตำแหน่งโฟลเดอร์ด้านล่าง กด Enter แล้วกด Open
~/ai-for-research-workspace

รู้จักโฟลเดอร์งานของคุณ

ใช้หนึ่งโฟลเดอร์ต่อหนึ่งงานวิจัย เพื่อให้ต้นฉบับและผลงานที่ AI สร้างแยกจากกันและค้นกลับได้ง่าย

โปรเจกต์นี้อยู่ที่ ai-for-research-workspace

ai-for-research-workspace/
├── README.md        คำอธิบายงาน
├── content.md       เอกสาร Markdown สำหรับทดลอง
├── input/           ไฟล์ต้นฉบับ
└── output/          รายงาน ตาราง ภาพ และ PDF ที่สร้างใหม่

เก็บไฟล์ต้นฉบับไว้ใน input/ และให้ AI บันทึกงานใหม่ใน output/ โดยไม่เขียนทับต้นฉบับ

  1. 01
    เปิด README.md
    ดูชื่อและเป้าหมายของงาน
  2. 02
    เปิด input/
    ดูตำแหน่งเก็บไฟล์ต้นฉบับ
  3. 03
    เปิด output/
    ดูตำแหน่งเก็บผลงานที่สร้างใหม่
พร้อมเมื่อ: รู้ว่าไฟล์ต้นฉบับและผลงานใหม่ต้องเก็บไว้ที่ใด

ฝึกบอกบริบทของคุณให้ AI

กรอกเฉพาะข้อมูลที่ช่วยให้ AI เข้าใจงานวิจัยและสิ่งที่คุณต้องการ ช่องที่ไม่เกี่ยวข้องข้ามได้ และไม่ต้องใส่รหัสผ่านหรือข้อมูลส่วนบุคคลที่ไม่จำเป็น

  1. 01
    กรอกข้อมูลเท่าที่จำเป็น
    เน้นสาขา หัวข้อวิจัย ระยะของงาน และสิ่งที่อยากได้จากคลาส
  2. 02
    ตรวจแล้วบันทึก
    ข้อมูลจะอยู่ในเบราว์เซอร์เครื่องนี้ และแก้ไขได้ภายหลัง
พร้อมเมื่อ: บันทึกหัวข้อวิจัยและเป้าหมายการเรียนเรียบร้อย

ทดลองไฟล์ Markdown แรก

  1. 01
    เปิดและแก้ Markdown
    คลิก content.md แล้วแก้ข้อความตัวอย่าง
  2. 02
    ดู Markdown Preview
    กด Ctrl+Shift+V (macOS: Command+Shift+V) เพื่อดูผลลัพธ์ที่จัดรูปแบบแล้ว
  3. 03
    ให้ AI สร้าง PDF

    คลิก output/content.pdf และตรวจว่าเนื้อหาครบและภาษาไทยแสดงผลถูกต้อง
