รู้จัก Terminal / CLI

Terminal คืออะไร?

Terminal คือช่องสำหรับบอกคอมพิวเตอร์ให้ทำงานด้วยข้อความ ส่วน CLI หรือ Command-Line Interface คือโปรแกรมที่เราเรียกใช้ผ่านช่องนี้ หนึ่งบรรทัดคือหนึ่งคำสั่ง ในกิจกรรมนี้ไม่ต้องจำคำสั่งและไม่ต้องพิมพ์เอง—อ่านก่อน กด Copy วาง แล้วกด Enter

Windows 11

เปิด PowerShell แบบปกติ

  1. 1
    กดปุ่ม Windows บน keyboard หรือคลิก Start
  2. 2
    พิมพ์ PowerShell
  3. 3
    คลิก Windows PowerShell หรือกด Enter
  4. 4
    ตรวจ title bar ต้องไม่มีคำว่า Administrator

พร้อมเมื่อเห็น PS C:\Users\ชื่อผู้ใช้>

ตัวอย่าง PowerShellPS C:\Users\student> ▌PS = PowerShell · C:\Users\student = โฟลเดอร์ปัจจุบัน · ▌ = จุดวางคำสั่ง
  • Paste: Ctrl+V
  • Run: กด Enter แล้วรอจนเห็น PS ...> กลับมา
  • Stop: กด Ctrl+C แล้วเรียกผู้สอน
  • Safety: อ่านก่อนรัน และไม่วาง password/token

  • Stop: กด Control+C แล้วเรียกผู้สอน
  • Safety: อ่านก่อนรัน และไม่วาง password/token

ก่อนติดตั้ง

คุณจะใช้ AI ตัวไหน?

เลือก AI ที่จะใช้ครั้งเดียว จากนั้นคัดลอกคำสั่งติดตั้งที่หน้าเว็บเตรียมให้

ยังไปต่อไม่ได้: กรุณาเลือก AI หนึ่งตัว

ขั้นที่ 2 · Installation

ติดตั้งซอฟต์แวร์

ติดตั้งครั้งแรกด้วยคำสั่งเดียวหลังโหลด Script: เตรียม VS Code พร้อม AI extension ที่เลือก, PDF Viewer, CSV Viewer และ JSON Viewer, Python 3.12, LaTeX/XeLaTeX ผ่าน TinyTeX, Pandoc และ OCR ไทย–อังกฤษ แล้วให้ AI ดาวน์โหลดไลบรารี Python และแพ็กเกจ LaTeX เพิ่มเมื่อจำเป็น

ติดตั้งต่อเนื่อง: Script ติดตั้งสิ่งที่ขาดตาม AI ที่เลือก โดยไม่ถามยืนยันทีละโปรแกรม เมื่อจบแล้วจึง Sign in หรือใส่ API key ไม่ต้องเลือกรุ่น Python, แพ็กเกจ LaTeX หรือ AI ตัวอื่นระหว่างติดตั้ง
สิทธิ์ครั้งแรก: Windows จะถาม UAC; macOS และ Linux อาจถามรหัสผ่านเพื่อติดตั้งเครื่องมือระบบ จากนั้น Python, TinyTeX และแพ็กเกจเพิ่มเติมใช้พื้นที่ของบัญชีผู้ใช้ปกติ

Extension สำหรับดูไฟล์จะติดตั้งพร้อมกันทุกตัวเลือก AI: PDF Viewer เปิดไฟล์ PDF, Edit CSV ดู CSV เป็นตาราง และ JSON Viewer ดู JSON เป็นโครงสร้างต้นไม้ สำหรับ CSV ให้เปิดไฟล์แล้วเลือกคำสั่ง Edit as CSV; สำหรับ JSON เลือก Open in json viewer จาก Command Palette

ถ้ารันซ้ำหรือแก้ปัญหา: ต้องคัดลอกคำสั่งโหลด Script ในข้อ 1 ใหม่ก่อนเสมอ แล้วตรวจว่าเห็น SETUP_VERSION 2026.10.07.4

Windows 11

เปิด PowerShell ปกติ

1 โหลด Script

curl.exe -fL "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-windows.ps1" -o "$HOME\Downloads\setup-windows.ps1"

2 รันครั้งเดียว แล้วตอบ Yes เมื่อ UAC ถาม

powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\setup-windows.ps1" -Mode Install -Agent codex

Script ลงเครื่องมือระบบในหน้าต่างที่ขอสิทธิ์ แล้วกลับมาเตรียม Python, TinyTeX และ AI ในหน้าต่างปกติให้อัตโนมัติ ต้องเห็น FONT_READY และ RUNTIME_READY

macOS

เปิด Terminal ปกติ

1 โหลด Script

curl -fL "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-macos.sh" -o "$HOME/Downloads/setup-macos.sh"

2 รันครั้งเดียว; ใส่รหัสผ่านเมื่อระบบถาม

AI_GRAD_AGENT=codex bash "$HOME/Downloads/setup-macos.sh" --install

ติดตั้ง Homebrew เมื่อยังไม่มี แล้วเตรียมเครื่องมือระบบและเครื่องมือของผู้ใช้ต่อเนื่อง ต้องเห็น SETUP_VERSION 2026.10.07.4, FONT_READY และ RUNTIME_READY หากเลือก Codex หรือ Claude จะเห็น CREATE VS_CODE_PROFILE ด้วย Script จะเปิด Workspace ใน VS Code ให้อัตโนมัติ

Linux (Ubuntu/Debian)

เปิด Terminal ปกติ

1 โหลด Script

mkdir -p "$HOME/Downloads" curl -fL "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-linux.sh" -o "$HOME/Downloads/setup-linux.sh"

2 รันครั้งเดียว; ใส่รหัสผ่านเมื่อ sudo ถาม

AI_GRAD_AGENT=codex bash "$HOME/Downloads/setup-linux.sh" --install

รองรับ Ubuntu/Debian; Python และ TinyTeX ติดตั้งในบัญชีผู้ใช้ปกติ ต้องเห็น RUNTIME_READY

ติดตั้งสำเร็จเมื่อ: เห็น RUNTIME_READY ซึ่งยืนยัน Python, XeLaTeX และการสร้าง PDF ภาษาไทยผ่าน template จริง แล้ว Workspace เปิดพร้อม AI panel หากขั้นใดล้มเหลว Script จะหยุดและแสดงข้อผิดพลาด

มีอยู่แล้วให้ใช้ต่อ

Installer ใช้ซอฟต์แวร์ที่มีอยู่และติดตั้งเฉพาะตัวที่ขาด จะไม่อัปเดตทุกโปรแกรมเป็นรุ่นล่าสุด หาก Node รุ่นเดิมต่ำกว่าที่ AI frontend ต้องใช้ จะเตรียม Node LTS ที่รองรับในพื้นที่เครื่องมือของคอร์สโดยเก็บรุ่นระบบไว้ ส่วน Python 3.12 และ TinyTeX ของคอร์สจะใช้ชุดเดิมเมื่อรันซ้ำ

LaTeX ที่ติดตั้งไว้ระดับระบบอาจยังต้องขอ Admin เมื่อลงแพ็กเกจเพิ่ม จึงเตรียม TinyTeX ที่ผู้ใช้เขียนได้แยกไว้ตั้งแต่ครั้งแรก ผู้เรียนสามารถอัปเดตเครื่องมือภายหลังเมื่อพบปัญหาหรือมีเหตุผลด้านการรองรับงาน โดยบันทึกรุ่นก่อนและหลัง

VS Code และ OpenRouter อยู่ในชุดแรก

Windows และ macOS ติดตั้ง VS Code ให้เมื่อยังไม่มี; Linux ติดตั้งแพ็กเกจ VS Code จาก Microsoft บน Windows โปรแกรมและคำสั่งทั้งหมดทำงานใน Windows โดยตรง

หากเลือก OpenRouter จะติดตั้ง Cline extension ให้ จากนั้นเปิด Cline Settings เลือก OpenRouter ใส่ API key ในช่องที่กำหนด เลือกโมเดล และตรวจเครดิต/ราคา Installer เตรียม extension ให้ แต่การใช้โมเดลขึ้นกับบัญชี OpenRouter ของคุณ

อ้างอิง: Cline กับ OpenRouter

เพิ่มเติม: สำหรับผู้ที่มี WSL2 อยู่แล้ว

WSL2 เป็นทางเลือกสำหรับผู้ที่คุ้นกับ Linux และมี Ubuntu/WSL2 พร้อมใช้งานอยู่แล้ว ใช้ Script ของ Linux ภายใน WSL ได้ โดย Script จะเรียก powershell.exe ของ Windows เพื่อติดตั้ง VS Code และ WSL extension ฝั่ง Windows แล้วกลับมาทำงานใน Ubuntu ไม่ต้องติดตั้ง PowerShell 7 เพิ่ม

Python, LaTeX และคำสั่งวิเคราะห์จะรันใน WSL ให้ตรวจมุมล่างซ้ายของ VS Code ว่าเป็น WSL: Ubuntu หรือชื่อ distribution ของคุณ ดู คู่มือ VS Code ใน WSL

ให้ AI ติดตั้งเพิ่มได้เมื่อจำเป็น

Python environment, cache และ TinyTeX อยู่ในโฟลเดอร์เครื่องมือของผู้ใช้ แยกจากโฟลเดอร์งานและ OneDrive ไฟล์ tools/runtime-env.json บอกตำแหน่งจริง และ tools/runtime-env.sh / tools/runtime-env.ps1 ใช้เปิด environment ซ้ำได้

Codex: Installer สร้าง .codex/config.toml เฉพาะ Workspace นี้ ให้เขียนไฟล์งานและโฟลเดอร์เครื่องมือ ดาวน์โหลดผ่านเครือข่าย และรันคำสั่งโดยไม่ถามยืนยันซ้ำ ยอมรับความเชื่อถือของ Workspace ครั้งแรก แล้วเริ่ม session ใหม่เพื่อโหลดค่า เครื่ององค์กรอาจมีนโยบายที่ override ค่าเหล่านี้ได้

Claude Code: เตรียมการอนุญาต uv, tlmgr, pandoc และ xelatex เฉพาะ Workspace ผ่าน .claude/settings.local.json คำสั่งอื่นอาจยังถาม หากมี config เดิม Installer จะเก็บไว้และแจ้งให้ตรวจค่า

Cline/OpenRouter: โหลด environment ของ Workspace ใน Terminal แล้วตั้ง Auto Approve ครั้งแรกใน Cline ให้ตรงกับงาน หากต้องการให้ติดตั้งแพ็กเกจโดยไม่ถาม ต้องเปิดการรันคำสั่งที่ต้องขออนุญาตด้วย เพราะ Cline อาจจัดคำสั่งติดตั้งเป็นกลุ่มนี้ การตั้งค่านี้อนุญาตคำสั่งอื่นด้วย จึงต้องใช้กับ Workspace ที่ไว้วางใจ อ่าน คำอธิบาย Auto Approve ก่อนเลือก

อ้างอิง: Python ผ่าน uv · TinyTeX และ tlmgr · สิทธิ์และเครือข่ายของ Codex

ทดลองไฟล์ Markdown แรก

  1. 01
    เปิดและแก้ Markdown
    คลิก content.md แล้วแก้ข้อความตัวอย่าง
  2. 02
    ดู Markdown Preview
    กด Ctrl+Shift+V (macOS: Command+Shift+V) เพื่อดูผลลัพธ์ที่จัดรูปแบบแล้ว
  3. 03
    ให้ AI อ่านและสร้าง PDF
    วาง prompt ด้านล่างใน Codex panel; agent จะอ่านคำสั่งใน Workspace และใช้ Integrated Terminal เบื้องหลังเมื่อจำเป็น
    อ่าน content.md แล้วสร้าง output/content.pdf ตามรูปแบบที่กำหนดไว้ใน Workspace โดยไม่เปลี่ยนไฟล์ต้นฉบับ จากนั้นตรวจว่าไฟล์ PDF สร้างสำเร็จ
  4. 04
    ตรวจสิทธิ์ของ Workspace
    Codex ที่โหลด config ของคอร์สแล้วจะรันได้ทันที หากยังถาม ให้ยอมรับ Workspace และเริ่ม session ใหม่ สำหรับ Claude ให้ตรวจว่าโหลดการอนุญาต pandoc จาก config ของ Workspace แล้ว
  5. 05
    เปิด PDF
    คลิก output/content.pdf และตรวจว่าเปิดอ่านได้ เป็นกระดาษ A4 ภาษาไทยใช้ Sarabun จาก Google Fonts ที่ติดตั้งพร้อม Workspace และมีรูปแบบสีตาม template
