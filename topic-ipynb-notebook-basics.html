Notebook

เปิด รัน และอ่าน notebook บน Colab

ใน workshop นี้คุณจะเปิด notebook Part A ของ Module 7 ใน Google Colab รันตามลำดับ และรันใหม่ตั้งแต่ต้นเพื่อดูว่าผลลัพธ์เชื่อได้หรือไม่

ทำใน Google Colab อย่างเดียว ไม่ต้องใช้ AI ในส่วนนี้ notebook ใช้ข้อมูลจำลองทั้งหมด

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • บัญชี Google หนึ่งบัญชี
  • ลิงก์ notebook: Part A — อ่านกราฟและตรวจสิ่งที่ AI เลือก
  • ไม่มี Colab: ไฟล์ .ipynb ชุดเดียวกันอยู่ที่ course-materials/module-07/notebooks/ (ตัวติดตั้ง Module 1 วางไว้ให้) เปิดด้วย tools/start-module-07

ขั้นตอน

  1. เปิดลิงก์ Part A แล้วดูโครงของ notebook: cell ข้อความ (หัวข้อ คำอธิบาย) กับ cell โค้ด (มีปุ่ม ▶) สลับกัน ใต้ cell โค้ดคือ ผลลัพธ์ เช่น ตารางหรือกราฟ
  2. เปิดสารบัญ ด้านซ้าย แล้วกระโดดไปหัวข้อ 1 ดูว่าหัวข้อในสารบัญมาจาก cell ข้อความ
  3. ลองกด ▶ ที่ cell โค้ดกลางเรื่องก่อนรัน cell แรก แล้วจดว่าเกิดอะไร (มักขึ้นข้อผิดพลาด เพราะ cell ก่อนหน้ายังไม่ได้รัน)
  4. กด Runtime → Run all รอจนทุก cell มีเครื่องหมายรันเสร็จ แล้วดูกราฟของหัวข้อ 1 อีกครั้ง
  5. กด Runtime → Restart session and run all แล้วเทียบว่ากราฟยังเหมือนเดิมหรือไม่ — ผลลัพธ์ที่เชื่อได้คือผลที่รันใหม่ตั้งแต่ต้นแล้วได้เท่าเดิม
  6. ถ้าจะลองแก้: กด File → Save a copy in Drive ก่อน แล้วแก้ในสำเนาของคุณ (ต้นฉบับของคลาสไม่เปลี่ยน)

Exploring

Notebook (.ipynb): cell, ลำดับการรัน และผลลัพธ์ที่ต้องรันใหม่ก่อนเชื่อ

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI ใน VS Code อ่านไฟล์ .ipynb ในเครื่อง แล้วตรวจคำตอบของ AI กับ notebook จริง

ไม่มี prompt สำเร็จรูป — เขียนเองกับ AI ใน VS Code โดยให้ AI อ่านไฟล์ .ipynb ในเครื่อง (ไม่ต้องเปิด Colab ให้ AI)

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้ใน Colab แล้ว
  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • course-materials/module-07/notebooks/module-07a-read-and-audit.ipynb (ตัวติดตั้ง Module 1 วางไว้ให้ อ่านอย่างเดียว)
  • (ข้อ 3 เท่านั้น) notebook ของงานคุณเอง หรือของนิสิตที่ดูแล

โจทย์ (เลือกอย่างน้อย 1 ข้อ)

ก่อนเริ่ม สร้างไฟล์ output/prompts.md ในโฟลเดอร์งานของคุณ สำหรับเก็บ prompt ทุกรอบ

  1. ให้ AI อ่าน course-materials/module-07/notebooks/module-07a-read-and-audit.ipynb แล้วสรุปโครงของ notebook: มีกี่หัวข้อ แต่ละหัวข้อใช้ข้อมูลอะไรและสร้างกราฟอะไร — ตรวจกับสารบัญใน Colab ว่าตรงกันไหม
  2. ให้ AI บอกว่า cell โค้ดใดต้องรันก่อน cell ใด (ตัวแปรหรือข้อมูลที่ถูกสร้างไว้ก่อน) แล้วลองพิสูจน์ใน Colab ด้วยการรัน cell นั้นก่อน
  3. ถ้ามี notebook ของงานคุณเอง (หรือของนิสิตที่ดูแล): ให้ AI ตรวจว่ามี cell ที่ผลลัพธ์ไม่ตรงกับโค้ดหรือข้อมูลที่ใช้ไม่มีอยู่ในเครื่องหรือไม่ โดยห้ามแก้ไฟล์

ข้อกำหนด

  • ระบุว่าตรวจคำตอบของ AI อย่างไร (เปิด notebook ดูเอง รันใหม่ใน Colab)
  • ไม่อัปโหลดข้อมูลวิจัยจริงหรือข้อมูลส่วนบุคคลขึ้น Colab
