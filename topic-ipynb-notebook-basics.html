Notebook

เปิด รัน และอ่าน notebook จาก VS Code

ใน workshop นี้คุณจะเปิด notebook Part A ของ Module 7 จาก VS Code รันตามลำดับ และรันใหม่ตั้งแต่ต้นเพื่อดูว่าผลลัพธ์เชื่อได้หรือไม่ ไม่ต้องติดตั้งอะไรเพิ่ม และไม่ต้องใช้ AI ในส่วนนี้ notebook ใช้ข้อมูลจำลองทั้งหมด

ใช้เมื่อ: ก่อนเปิด notebook ใน Module 7 หรือเมื่อได้รับไฟล์ .ipynb จากผู้อื่น

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code (ตัวติดตั้ง Module 1 ลง JupyterLab และไลบรารีของ Module 7 ไว้ใน .venv-module07 แล้ว)
  • course-materials/module-07/notebooks/module-07a-read-and-audit.ipynb (อ่านอย่างเดียว ห้ามแก้)
  • ทางสำรอง ถ้าเปิด JupyterLab ไม่ได้: Part A ใน Google Colab ใช้บัญชี Google ทำขั้นเดียวกัน (ชื่อเมนูของ Colab อยู่ในวงเล็บ)

คำที่ใช้ใน workshop นี้

  • notebook (.ipynb) — ไฟล์ที่มี cell ข้อความ cell โค้ด และผลลัพธ์อยู่ด้วยกัน
  • cell ข้อความ — หัวข้อและคำอธิบาย · cell โค้ด — มี [ ]: ด้านซ้าย · ผลลัพธ์ — ตารางหรือกราฟใต้ cell โค้ด
  • kernel — โปรแกรม Python ที่รันโค้ดของ notebook ชื่อ Python (AI for Research M07)
  • Restart kernel — ล้างตัวแปรทั้งหมดในหน่วยความจำ เหมือนเริ่มเปิดใหม่

เริ่มหัวข้อ — ให้ AI รู้ว่ากำลังทำโมดูลไหน

ถ้าแชต AI เดิมทำโมดูลอื่นอยู่ ให้เปิดแชตใหม่ก่อน แล้ววาง prompt นี้

เริ่ม Module 1 หัวข้อ "Notebook (.ipynb): cell, ลำดับการรัน และผลลัพธ์ที่ต้องรันใหม่ก่อนเชื่อ": ทำงานตามแผนที่ไฟล์ใน module-01-work/ เท่านั้น อ่าน input/ และ course-materials/ โดยห้ามแก้ และเขียนผลลงตำแหน่งที่หัวข้อนี้กำหนด

ตรวจ: AI บอกได้ว่าไฟล์ที่หัวข้อนี้ใช้อยู่ที่ไหน · ถ้าไม่พบไฟล์ของหัวข้อนี้ ให้สั่ง AI รัน AIRR init module-1 ครั้งเดียว

ขั้นที่ 1 — เปิด JupyterLab จาก VS Code

ใน VS Code เลือก Terminal → New Terminal แล้วรันคำสั่งของระบบตนเอง

  • Windows: powershell -NoProfile -ExecutionPolicy Bypass -File tools\start-module-07.ps1
  • macOS / Linux: bash tools/start-module-07.sh

JupyterLab จะเปิดในเบราว์เซอร์ที่หน้ารวม Part A–C ให้เปิด module-07a-read-and-audit.ipynb จากหน้ารวมหรือแถบไฟล์ด้านซ้าย

ตรวจ: แท็บที่เปิดชื่อ module-07a-read-and-audit.ipynb และมุมขวาบนแสดง kernel Python (AI for Research M07) (Colab: เปิดลิงก์ทางสำรองแล้ว)

ขั้นที่ 2 — ดูโครง notebook

เลื่อนดู cell ข้อความ cell โค้ด และผลลัพธ์ที่สลับกัน

ตรวจ: ชี้ได้หนึ่งตัวอย่างของแต่ละแบบ: cell ข้อความ cell โค้ด และผลลัพธ์

ขั้นที่ 3 — ใช้สารบัญ

เปิดสารบัญ: View → Table of Contents (Colab: ไอคอนสารบัญด้านซ้าย) แล้วกระโดดไปหัวข้อ 1

ตรวจ: หัวข้อในสารบัญตรงกับหัวข้อใน cell ข้อความ

ขั้นที่ 4 — รัน cell กลางเรื่องก่อน

คลิก cell โค้ดกลางเรื่องแล้วกด Shift+Enter ก่อนรัน cell แรก จดว่าเกิดอะไร

ตรวจ: คุณจดข้อผิดพลาดที่ขึ้นไว้ และอธิบายได้หนึ่งบรรทัดว่าเกิดเพราะ cell ก่อนหน้ายังไม่ได้รัน

ขั้นที่ 5 — รันทุก cell ตามลำดับ

Run → Run All Cells (Colab: Runtime → Run all) รอจนทุก cell รันเสร็จ แล้วดูกราฟของหัวข้อ 1

ตรวจ: ทุก cell โค้ดมีตัวเลขใน [ ]: (ไม่มี [*] ค้าง) และไม่มีข้อผิดพลาดค้าง

ขั้นที่ 6 — Restart แล้วรันใหม่ตั้งแต่ต้น

Kernel → Restart Kernel and Run All Cells (Colab: Runtime → Restart session and run all) แล้วเทียบกราฟหัวข้อ 1 กับก่อน Restart

ตรวจ: กราฟเหมือนเดิม (หรือคุณจดได้ว่าต่างตรงไหน) — ผลที่เชื่อได้คือผลที่รันใหม่ตั้งแต่ต้นแล้วได้เท่าเดิม

ขั้นที่ 7 — (ถ้าจะลองแก้) ทำสำเนาก่อน แล้วปิด JupyterLab

File → Save Notebook As… บันทึกเป็น module-07-work/notebook-practice.ipynb แล้วแก้ในสำเนา (Colab: File → Save a copy in Drive) เมื่อเลิกใช้ ให้กลับไปที่ Terminal ใน VS Code แล้วกด Ctrl+C เพื่อปิด JupyterLab

ตรวจ: แท็บที่แก้อยู่ชื่อ notebook-practice.ipynb และ notebook ต้นฉบับใน course-materials/ ไม่เปลี่ยน

Exploring

Notebook (.ipynb): cell, ลำดับการรัน และผลลัพธ์ที่ต้องรันใหม่ก่อนเชื่อ

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI ใน VS Code อ่านและตรวจไฟล์ .ipynb ในเครื่อง แล้วตรวจคำตอบของ AI กับ notebook จริงใน JupyterLab

ไม่มี prompt สำเร็จรูปให้

โจทย์ (เลือกอย่างน้อย 1 ข้อ)

ก่อนเริ่ม สร้างไฟล์ module-07-work/output/prompts.md สำหรับเก็บ prompt ทุกรอบ

  1. ให้ AI อ่าน module-07a-read-and-audit.ipynb แล้วสรุปโครง: มีกี่หัวข้อ แต่ละหัวข้อใช้ข้อมูลอะไรและสร้างกราฟอะไร — ตรวจกับสารบัญใน JupyterLab ว่าตรงกันไหม
  2. ให้ AI บอกว่า cell โค้ดใดต้องรันก่อน cell ใด (ตัวแปรหรือข้อมูลที่ถูกสร้างไว้ก่อน) แล้วพิสูจน์เองใน JupyterLab ด้วยการรัน cell นั้นหลัง Restart kernel
  3. ให้ AI ตรวจ notebook ของงานคุณว่ารันใหม่ตั้งแต่ต้นได้หรือไม่ โดยให้ AI รันสำเนาด้วย Python ใน .venv-module07 (เช่น jupyter nbconvert --to notebook --execute เขียนผลลง module-07-work/output/) และรายงาน cell ที่ผิดหรือใช้ไฟล์ที่ไม่มีอยู่ในเครื่อง ห้ามแก้ไฟล์ต้นฉบับ

ข้อกำหนด

  • notebook ต้นฉบับไม่ถูกแก้ ผลรันเก็บเป็นไฟล์ใหม่ใน module-07-work/output/
