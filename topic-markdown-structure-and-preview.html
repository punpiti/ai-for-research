Workshop

Markdown: หัวข้อ รายการ และ Preview — แก้ที่ต้นฉบับ ไม่แก้ที่ PDF

ใน workshop นี้คุณจะให้ AI ทำสำเนาไฟล์ Markdown ตัวอย่าง อ่านโครงสร้างผ่าน Preview แล้วให้ AI เปลี่ยนชื่อหัวข้อหนึ่งแห่งโดยตรวจว่าเนื้อหาส่วนอื่นไม่เปลี่ยน

ใช้เมื่อ: ก่อนแก้รายงานใน Module 8 หรือข้อสรุปใน Module 2/3 (ถ้าอ่าน Markdown ได้อยู่แล้ว ข้ามไปทำงานจริงได้เลย)

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • ไฟล์ตัวอย่างอยู่ที่ module-01-work/input/file-basics/ (ตัวติดตั้ง Module 1 วางไว้ให้ อ่านอย่างเดียว ห้ามแก้) ถ้ายังไม่มี ให้สั่ง AI ว่า AIRR init module-1 · งานที่คุณสร้างหรือแก้ทั้งหมดใน X01 เก็บที่ module-01-work/output/file-basics/
  • module-01-work/input/file-basics/room-temperature-note.md — ข้อความจำลอง ไม่มีข้อมูลจริงของใคร เนื้อหาตามด้านล่าง
# Room temperature note ## Observation - Room A: 26.5 degrees Celsius - Room B: value missing ## Limitation One reading per room cannot describe the whole day.

คำที่ใช้ใน workshop นี้

  • Markdown (.md) — ไฟล์ข้อความที่ใช้เครื่องหมายบอกโครงสร้าง เปิดและแก้ได้ใน VS Code
  • # / ## — หัวข้อหลัก / หัวข้อย่อย · - — รายการ · ข้อความหลังเครื่องหมายยังเป็นเนื้อหาที่ตรวจและแก้ได้
  • Preview — มุมมองที่แสดงผลเป็นหัวข้อและรายการ (Ctrl+Shift+V · macOS: Command+Shift+V)
  • ต้นฉบับ — ไฟล์ .md ที่แก้ได้ ส่วน PDF เป็นผลลัพธ์ที่สร้างจากต้นฉบับ

เริ่มหัวข้อ — ให้ AI รู้ว่ากำลังทำโมดูลไหน

ถ้าแชต AI เดิมทำโมดูลอื่นอยู่ ให้เปิดแชตใหม่ก่อน แล้ววาง prompt นี้

เริ่ม Module 1 หัวข้อ "Markdown: หัวข้อ รายการ และ Preview": ทำงานตามแผนที่ไฟล์ใน module-01-work/ เท่านั้น อ่าน input/ และ course-materials/ โดยห้ามแก้ และเขียนผลลงตำแหน่งที่หัวข้อนี้กำหนด

ตรวจ: AI บอกได้ว่าไฟล์ที่หัวข้อนี้ใช้อยู่ที่ไหน · ถ้าไม่พบไฟล์ของหัวข้อนี้ ให้สั่ง AI รัน AIRR init module-1 ครั้งเดียว

ขั้นที่ 1 — ให้ AI ทำสำเนาไฟล์ตัวอย่างไว้แก้

ต้นฉบับใน input/ ห้ามแก้ จึงให้ AI ทำสำเนาไปไว้ใน output/ ก่อน วาง prompt นี้

คัดลอก module-01-work/input/file-basics/room-temperature-note.md ไปที่ module-01-work/output/file-basics/room-temperature-note.md ทุกตัวอักษร ถ้ายังไม่มีโฟลเดอร์ให้สร้าง ถ้ามีไฟล์ชื่อนี้อยู่แล้วให้หยุดและบอกฉันก่อน ห้ามแก้ไฟล์ใน input/

ตรวจ: เปิด module-01-work/output/file-basics/room-temperature-note.md แล้วข้อความตรงกับตัวอย่างทุกบรรทัด

ขั้นที่ 2 — เปิด Preview และจับคู่กับต้นฉบับ

เปิด Preview ของสำเนาใน module-01-work/output/file-basics/ แล้วชี้ว่าหัวข้อหลัก หัวข้อย่อยสองอัน และรายการสองข้อ มาจากบรรทัดใดในต้นฉบับ

ตรวจ: ทุกส่วนใน Preview จับคู่กับบรรทัดในต้นฉบับได้ครบ ไม่มีส่วนที่หาที่มาไม่เจอ

ขั้นที่ 3 — ให้ AI เปลี่ยนชื่อหัวข้อหนึ่งแห่ง

เลือกหัวข้อเอง (เช่น ## Observation → ## Morning observation) แล้ววาง prompt นี้พร้อมระบุหัวข้อเดิมและชื่อใหม่

อธิบายหัวข้อและรายการในไฟล์ Markdown นี้จากข้อความที่มีอยู่ แล้วเปลี่ยนเฉพาะชื่อหัวข้อที่ฉันระบุ แสดงสิ่งที่เปลี่ยนและรอให้ฉันตรวจ อย่าเปลี่ยนตัวเลขหรือข้อจำกัด

ตรวจ: AI แสดงสิ่งที่เปลี่ยนเพียงบรรทัดเดียว คือบรรทัดหัวข้อที่คุณระบุ

ขั้นที่ 4 — ตรวจไฟล์หลังแก้

เปิดไฟล์และ Preview อีกครั้ง

ตรวจ: Preview แสดงหัวข้อใหม่ และ 26.5 degrees Celsius, value missing กับข้อความใต้ ## Limitation ยังเหมือนเดิม ไม่มีบรรทัดอื่นเปลี่ยน

ขั้นที่ 5 — บอกว่าถ้า PDF ผิดต้องแก้ที่ไหน

สมมติว่าไฟล์นี้ถูกสร้างเป็น PDF แล้วคุณเจอคำผิดใน PDF เขียนหนึ่งประโยคว่าจะแก้ที่ไฟล์ใดและทำอะไรต่อ (ถ้าต้องการเก็บ ให้บันทึกคำตอบของขั้นที่ 2 และ 5 ลง module-01-work/output/file-basics/file-reading.md)

ตรวจ: คำตอบคือแก้ที่ไฟล์ .md แล้วสร้าง PDF ใหม่ ไม่ใช่แก้ PDF

ตรวจก่อนจบ workshop

Exploring

Markdown: หัวข้อ รายการ และ Preview — แก้ที่ต้นฉบับ ไม่แก้ที่ PDF

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI ปรับโครงสร้างไฟล์ Markdown จากงานของคุณ โดยกำหนดเองว่าอะไรห้ามเปลี่ยน แล้วตรวจผลกับ Preview และต้นฉบับ

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้แล้ว (มี module-01-work/output/file-basics/room-temperature-note.md ใช้เป็นชุดสำรองได้)
  • ข้อความจากงานของคุณที่มีหัวข้อและรายการ เช่น โครงร่างบทความ บันทึกประชุมวิจัย หรือรายการตรวจวิทยานิพนธ์ ที่มีตัวเลขหรือข้อจำกัดอย่างน้อยหนึ่งจุด

โจทย์

  1. สร้างไฟล์ .md จากข้อความของคุณในโฟลเดอร์งานที่เลือก (หรือใช้ไฟล์ชุดสำรองข้างต้น)
  2. สร้างไฟล์ output/prompts.md ในโฟลเดอร์งานเดียวกัน สำหรับเก็บ prompt ที่ใช้ทุกรอบ
  3. เขียน prompt ของตนให้ AI ปรับโครงสร้าง (เช่น เปลี่ยนชื่อหัวข้อ เลื่อนระดับหัวข้อ หรือแยกรายการ) โดยกำหนดเองว่าอะไรห้ามเปลี่ยน
  4. ตรวจ Preview และตรวจว่าเนื้อหาที่ห้ามเปลี่ยนยังเหมือนเดิม

ข้อกำหนด

  • เก็บต้นฉบับเดิมไว้ (ให้ AI เขียนฉบับแก้เป็นไฟล์ใหม่ หรือบันทึกสิ่งที่เปลี่ยนให้เทียบได้)
  • ระบุว่าตรวจผลของ AI อย่างไร และแก้อะไรเอง
