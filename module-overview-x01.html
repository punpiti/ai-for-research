ผลลัพธ์การเรียนรู้

จบโมดูลนี้ คุณจะ

รู้และอธิบายได้

  • แต่ละชนิดไฟล์ยืนยันอะไรได้และไม่ได้
  • ต้นฉบับกับผลลัพธ์ต่างกันอย่างไร

ทำได้ด้วยตนเอง

  • อ่านชื่อคอลัมน์ ระบุว่าหนึ่งแถวแทนอะไร บอกหน่วยและค่าที่ขาดได้ (ช่องว่างไม่เท่ากับศูนย์) ใ
  • แยกหัวข้อ รายการ และข้อความเนื้อหาในไฟล์ .md ชี้บรรทัดต้นฉบับจาก Preview ได้ สั่ง AI เปลี่
  • เปิด PDF แยกข้อความที่เลือกคัดลอกได้กับภาพสแกน ตรวจลำดับข้อความ ตัวเลข หน่วย และเชิงอรรถที
  • อ่านชื่อช่อง ค่า และกลุ่มข้อมูลใน JSON แยกข้อความ จำนวน true/false/null ได้ ให้ AI แก้เฉพา
  • แยก cell ข้อความกับ cell โค้ดและผลลัพธ์ใน notebook ได้

ตัดสินได้เอง

  • เลือกชนิดไฟล์ให้ตรงงาน
  • ตรวจสิ่งที่ AI อ่านกลับกับไฟล์ต้นทาง

ลงมือตามลำดับ

  1. CSV: หนึ่งแถวแทนอะไร ชื่อคอลัมน์ หน่วย และค่าที่ขาด
  2. Markdown: หัวข้อ รายการ และ Preview — แก้ที่ต้นฉบับ ไม่แก้ที่ PDF
  3. สร้าง PDF แรกจาก Markdown ด้วย AI: แก้ที่ต้นฉบับ แล้วสร้างใหม่
  4. PDF: ข้อความที่เลือกได้ ภาพสแกน และการตรวจสิ่งที่ AI อ่านกับหน้าต้นทาง
  5. JSON: ชื่อช่อง ค่า และสถานะ true/false/null — อ่านผ่านไม่ได้แปลว่าค่าถูก
  6. Notebook (.ipynb): cell, ลำดับการรัน และผลลัพธ์ที่ต้องรันใหม่ก่อนเชื่อ
