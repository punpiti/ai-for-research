Workshop

เตรียมเครื่อง: ต้องทำอะไร โครงสร้างเป็นอย่างไร และใช้งานเบื้องต้น

ใน workshop นี้คุณจะติดตั้งเครื่องมือ ให้ AI ทดสอบการเชื่อม AIRR ให้ AI สร้างและแก้ไฟล์แรก แล้วติ๊กทบทวนความพร้อมบนเว็บ

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • คอมพิวเตอร์ที่จะใช้จริง อินเทอร์เน็ต และสิทธิ์ติดตั้งโปรแกรม
  • OpenRouter key ที่ได้รับจากผู้สอน (ทุกคนได้) — ถ้ามีบัญชี Claude หรือ ChatGPT ของตนเองก็ใช้แทนได้
  • เข้าสู่ระบบเว็บคลาสด้วยบัญชี Google แล้ว (คำสั่งติดตั้งจะใส่รหัสเชื่อมคลาสให้เอง)

คำที่ใช้ใน workshop นี้

  • Terminal — หน้าต่างพิมพ์คำสั่งของเครื่อง (Windows เรียก PowerShell) ใช้แค่ตอนติดตั้ง
  • workspace — โฟลเดอร์งานของคลาสชื่อ ai-for-research-workspace ที่ตัวติดตั้งสร้างให้
  • VS Code — โปรแกรมเปิด workspace มีแผง Explorer ด้านซ้ายแสดงโฟลเดอร์และไฟล์
  • AI panel — ช่องคุยกับ AI ใน VS Code (Claude Code, Codex หรือ Cline ตามบัญชีที่เลือก)
  • prompt — ข้อความที่คุณวางหรือพิมพ์ใน AI panel เพื่อสั่งงาน
  • AIRR — ระบบของคลาสที่เชื่อม workspace กับผู้สอน ใช้รายงานว่าติดตั้งแล้วและส่งงาน
  • AIRR Key — รหัสที่ผูก workspace กับบัญชีและคลาสของคุณ ห้ามส่งต่อหรือแสดงให้ใครเห็น

Windows 11

& { $env:AI_RESEARCH_PROJECT_NAME='ai-for-research-workspace'; $setup = Join-Path $env:TEMP 'ai-research-setup.ps1'; Invoke-WebRequest -UseBasicParsing -ErrorAction Stop "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-windows.ps1" -OutFile $setup; powershell -NoProfile -ExecutionPolicy Bypass -File "$setup" -Mode Install -Agent openrouter }

macOS

Linux / WSL2 (Ubuntu/Debian)

setup="$(mktemp)" && curl -fsSL "https://urban.cpe.ku.ac.th/ai-for-research/downloads/setup-linux.sh" -o "$setup" && AI_RESEARCH_PROJECT_NAME='ai-for-research-workspace' AI_GRAD_AGENT=openrouter bash "$setup" --install

ขั้นที่ 5 — ให้ AI สร้างและแก้ไฟล์แรก

  1. สั่ง AI (แทน … ด้วยหัวข้องานวิจัยของคุณ ไม่ใส่ข้อมูลลับหรือข้อมูลส่วนบุคคล)

    สร้างไฟล์ module-01-work/output/first-note.txt ที่มีสองบรรทัด: บรรทัดแรกคือหัวข้องานวิจัยของฉัน "…" บรรทัดที่สองคือวันที่วันนี้ ห้ามแก้ไฟล์อื่น แล้วบอกว่าไฟล์อยู่ที่ไหน

  2. เปิด module-01-work/output/first-note.txt ใน VS Code แล้วอ่านเองว่าตรงกับที่สั่ง

  3. สั่ง AI แก้หนึ่งบรรทัด

    แก้ module-01-work/output/first-note.txt โดยเพิ่มบรรทัดที่สามว่า "ทดสอบการแก้ไฟล์ด้วย AI" ห้ามเปลี่ยนบรรทัดอื่น แล้วแสดงสิ่งที่เปลี่ยน

  4. เปิดไฟล์อีกครั้ง ตรวจว่าเปลี่ยนเฉพาะบรรทัดที่สั่ง

  5. ปิด VS Code แล้วเปิดกลับมาที่ workspace เดิม เปิด first-note.txt ได้อีกครั้ง

ตรวจ: module-01-work/output/first-note.txt มีสามบรรทัด และไม่มีไฟล์อื่นถูกแก้

อยากลองสร้าง PDF ต่อ: ดูหัวข้อ สร้าง PDF แรกจาก Markdown ด้วย AI: แก้ที่ต้นฉบับ แล้วสร้างใหม่ ในโมดูลเสริม (ไม่บังคับ)

ขั้นที่ 6 — ทบทวนและติ๊กความพร้อมบนเว็บ (ไม่ใช้ AI)

  1. เปิดหน้า Module 1 · จบบทเรียน
  2. ติ๊กเฉพาะข้อที่ทำได้จริง 4 ข้อ: เปิด workspace ได้ · เชื่อม AI panel ได้ · รู้ว่าต้นฉบับอยู่ใน module-01-work/input/ และงานใหม่อยู่ใน module-01-work/output/ · ให้ AI สร้าง module-01-work/output/first-note.txt และเปิดดูได้
  3. ครบ 4 ข้อ หน้าเว็บขึ้น ผ่าน แล้วกดปุ่ม "แจ้งผู้สอนว่าเสร็จ" ครั้งเดียว (ส่งเฉพาะผลเช็กลิสต์และเวลาโดยประมาณ ไม่ส่ง key ไฟล์ หรือข้อมูลวิจัย) · เว็บส่งไม่ได้: ใช้ "หรือแจ้งผ่าน AIRR ใน VS Code" ในหน้าเดียวกัน AI จะรันคำสั่งเดียว ไม่ถามคำถาม

ในคลาสนี้คุณจะเจอไฟล์ 4 แบบซ้ำ ๆ คือ Markdown (.md), CSV (.csv), JSON (.json) และ PDF (.pdf) ตัวติดตั้งวางตัวอย่างของจริงไว้ใน workspace แล้ว รอบนี้ให้คุณเขียน prompt เองทั้งหมด เพื่อให้ AI อธิบายไฟล์เหล่านี้ แล้วเปิดไฟล์ดูเองว่า AI พูดถูกไหม

ทุกไฟล์ในรอบนี้ อ่านอย่างเดียว ห้ามแก้ (อยู่ใน course-materials/ หรือ input/original/)

โจทย์ (เลือกทำอย่างน้อย 2 แบบ)

  1. Markdown — course-materials/module-04/citation-audit-rules.md ให้ AI อธิบายว่าเครื่องหมาย # ## 1. **…** ในไฟล์นี้หมายถึงอะไร แล้วเปิดไฟล์เอง กด Preview (Ctrl+Shift+V) เทียบว่าหน้าตาตรงกับที่ AI อธิบายไหม อ่านต่อ: หัวข้อ Markdown: หัวข้อ รายการ และ Preview — แก้ที่ต้นฉบับ ไม่แก้ที่ PDF
  2. CSV — course-materials/module-07/examples/figure-consistency/mock-study-data.csv (ข้อมูลจำลอง PM2.5) ให้ AI บอกว่าหนึ่งแถวแทนอะไร มีกี่คอลัมน์ แต่ละคอลัมน์มีหน่วยอะไร แล้วเปิดไฟล์เองนับหัวคอลัมน์และดูแถวแรก อ่านต่อ: หัวข้อ CSV: หนึ่งแถวแทนอะไร ชื่อคอลัมน์ หน่วย และค่าที่ขาด
  3. JSON — course-materials/module-07/install-receipt.json (บันทึกของตัวติดตั้ง) ให้ AI อธิบายว่าไฟล์บันทึกอะไร field ไหนเป็นตัวเลข ข้อความ หรือรายการ แล้วเปิดไฟล์เองเทียบค่า installed กับจำนวนรายการใน files อ่านต่อ: หัวข้อ JSON: ชื่อช่อง ค่า และสถานะ true/false/null — อ่านผ่านไม่ได้แปลว่าค่าถูก
  4. PDF — module-04-work/input/original/mock-paper.pdf (บทความจำลอง) ให้ AI บอกว่า PDF นี้มีข้อความที่เลือกและคัดลอกได้ หรือเป็นภาพสแกน และชื่อบทความคืออะไร แล้วเปิด PDF เองลองลากเลือกข้อความเทียบ อ่านต่อ: หัวข้อ PDF: ข้อความที่เลือกได้ ภาพสแกน และการตรวจสิ่งที่ AI อ่านกับหน้าต้นทาง

ข้อกำหนด

  • เขียน prompt เอง ทุก prompt ต้องบอกขอบเขต: ไฟล์ที่ให้อ่าน และสั่งชัดว่าห้ามแก้ไฟล์ใด
  • ตรวจคำตอบของ AI โดยเปิดไฟล์ดูเองทุกครั้ง
  • เก็บ prompt ทุกรอบไว้ในไฟล์ข้อความ module-01-work/output/prompts.txt (ไฟล์ .txt แบบเดียวกับ first-note.txt ในขั้นที่ 5) แต่ละรอบเขียน prompt ที่ใช้ แล้วตามด้วยบรรทัดสั้น ๆ ว่าตรวจแล้วตรงหรือไม่ และปรับ prompt เพราะอะไร จะพิมพ์เองหรือสั่ง AI เพิ่มต่อท้ายไฟล์ก็ได้
