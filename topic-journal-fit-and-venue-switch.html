Workshop

เลือกวารสาร และผลของการเปลี่ยนวารสาร

ใน workshop นี้คุณจะเทียบวารสารจำลองสองแห่งจากเอกสารที่ติดตั้งไว้ ตัดสิน fit จากหลักฐาน และบันทึกผลกระทบเมื่อเปลี่ยนวารสารโดยไม่เปลี่ยนข้อมูล วิธี ผล หรือข้อจำกัดของงาน

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน M1 และติดตั้ง M8 แล้ว
  • มี module-08-work/journal-dossiers/, input/module-07-highlights.md และ input/analysis-summary.csv
  • ถ้าไม่ได้ทำ M7 ให้ใช้ highlights และกราฟชุดสำรองที่ตัวติดตั้งเตรียมไว้

คำที่ใช้ใน workshop นี้

  • journal dossier — แฟ้มข้อกำหนดจากแหล่งทางการพร้อม URL วันที่ และข้อความหลักฐาน
  • scope fit — หัวข้องานอยู่ในขอบเขตวารสารหรือไม่
  • audience fit — ผู้อ่านของวารสารต้องการข้อค้นพบแบบนี้หรือไม่
  • evidence fit — หลักฐานที่มีรองรับชนิดบทความและข้ออ้างที่ต้องใช้หรือไม่
  • BLOCKED — ยังตัดสินไม่ได้เพราะขาดหลักฐานหรือการตัดสินของมนุษย์

ขั้นที่ 1 — ตรวจ dossier ก่อนตัดสิน

เปิด profile ของ Journal A และ Journal B ตรวจว่าทุกข้อกำหนดมีแหล่งที่มา วันที่ และสถานะ confirmed / unclear / not found ให้ AI ช่วยจัดตารางได้ แต่ห้ามให้ AI เติมข้อกำหนดจากความจำ

ตรวจ: ข้อกำหนดที่ไม่มีหลักฐานยังเป็น unclear หรือ not found และไม่มี URL ที่ AI แต่งขึ้น

ขั้นที่ 2 — ตัดสิน fit

ให้ AI เทียบ highlights, วิธี และข้อจำกัดของชุดฝึกกับ dossier แล้วร่าง module-08-work/journal-dossiers/fit-decision.md แยก scope, audience และ evidence fit พร้อมข้อความหลักฐาน คุณเลือกสถานะ fit / conditional fit / no fit และเขียนเหตุผลสุดท้ายเอง

ตรวจ: เหตุผลทุกข้ออ้างข้อความจาก dossier หรือข้อจำกัดของงาน และไม่มีเปอร์เซ็นต์โอกาสตีพิมพ์

ขั้นที่ 3 — ประเมินผลกระทบเมื่อเปลี่ยนวารสาร

สร้าง module-08-work/journal-dossiers/venue-change-impact.md เทียบโครงสร้าง จำนวนคำ รูป ตาราง citation style anonymity declarations และ submission package ของสองวารสาร แยกสิ่งที่ต้องเปลี่ยน สิ่งที่ต้องคงเดิม และสิ่งที่ยัง BLOCKED

ตรวจ: data, method, result และ limitation อยู่ในรายการ “ต้องคงเดิม”; ข้อกำหนดใหม่ไม่ถูกใช้เป็นเหตุผลแต่งผลเพิ่ม

Exploring

เลือกวารสาร และผลของการเปลี่ยนวารสาร

เขียน prompt เองเพื่อเปรียบเทียบวารสารจริงอย่างน้อยสองแห่งจากเว็บไซต์ทางการ

โจทย์

  1. เก็บ Aims & Scope, Guide for Authors, article type, template และ submission checklist พร้อม URL วันที่ และข้อความหลักฐาน
  2. ตัดสิน scope, audience และ evidence fit
  3. ทำ venue-change impact สำหรับวารสารลำดับที่สอง

ข้อกำหนด

  • ไม่ใช้ข้อกำหนดที่ AI ตอบจากความจำ
  • เก็บ prompt ทุกรอบใน module-08-work/output/prompts.md
  • จุดที่ยังต้องถาม editor หรือผู้ร่วมวิจัยต้องเป็น BLOCKED

เสริม · Workshop

เปลี่ยนวารสาร: ข้อกำหนดใหม่ เนื้อหาวิจัยเดิม (venue-change impact)

ใน workshop นี้คุณจะให้ AI กรอกตาราง venue-change impact จาก Journal A ไป Journal B แล้วตัดสินเองว่าอะไรเปลี่ยนได้ (การนำเสนอ) อะไรต้องคงไว้ (เนื้อหาวิจัย) และข้อกำหนดใดเป็น BLOCKED

ใช้วารสารจำลอง 2 ฉบับ (ไม่ใช่วารสารจริง) และต้นฉบับ PM2.5 จำลอง เป็นกิจกรรม “ถ้ามีเวลา” ในตาราง 75 นาทีของ M8 — ถ้าเวลาไม่พอให้ตัดหัวข้อนี้ก่อน ไม่ตัดการตรวจ PDF

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ติดตั้ง Module 8 แล้ว ตัวติดตั้งวางไฟล์เหล่านี้ไว้ให้:
    • module-08-work/journal-dossiers/journal-a/original/profile.md และ module-08-work/journal-dossiers/journal-b/original/profile.md
    • module-08-work/submission/venue-change-impact.md — แม่แบบตารางเปล่า (Requirement | Journal A | Journal B | Change in Markdown or package | Research content must remain) และส่วน Fit decision
    • module-08-work/source/manuscript.md — ต้นฉบับที่ตั้ง target_journal: journal-a (ถ้าทำ paragraph-contract-reverse-check แล้ว จะมีย่อหน้า Results และ Limitations ที่คุณเขียน)
  • fit decision ของ Journal A จากกิจกรรม “เลือกวารสารก่อนเขียน” (module-08-work/journal-dossiers/journal-a/journal-dossier.md)
  • (เฉพาะขั้นที่ 4) PDF ของ Journal A จากหัวข้อ ต้นฉบับ Markdown ชุดเดียว → LaTeX ที่ AI สร้าง → PDF และการแก้ build ตามชั้น: module-08-work/build/manuscript.pdf

ขั้นตอน

  1. อ่าน Journal B เอง (2 นาที) เปิด journal-b/original/profile.md ดู Methods Brief (2,200 คำ, structured abstract ≤ 220 คำ, numbered citations, ต้องรายงาน sensor definition, missingness, repeated observations, uncertainty และ reproducibility note) และ Evidence-fit Gate ที่บอกว่า fit เป็นแบบมีเงื่อนไข

  2. ส่ง prompt ให้ AI เทียบผลกระทบ AI จะกรอก submission/venue-change-impact.md และบันทึกการตัดสินของ Journal B เป็นไฟล์ใหม่ใน journal-dossiers/journal-b/

    ใช้ module-08-work/journal-dossiers/journal-b/original/profile.md เป็นข้อกำหนดวารสารใหม่ บันทึกการตัดสินของ Journal B แยกไว้ใน module-08-work/journal-dossiers/journal-b/ ห้ามแก้ไฟล์ของ Journal A กรอก module-08-work/submission/venue-change-impact.md เทียบ Journal A กับ B ทุกแถว: scope และ audience, article type และหัวข้อ, abstract, จำนวนคำ/รูป/ตาราง, รูปแบบอ้างอิง, anonymization, declarations/ไฟล์ที่ต้องส่ง ช่อง “Research content must remain” ต้องคงข้อมูล วิธี ผล ตัวเลข และข้อจำกัดเดิม ระบุข้อกำหนดของ Journal B ที่ข้อมูลชุดนี้ไม่มี เป็น BLOCKED ห้ามแต่งรายละเอียด sensor หรือ calibration เพิ่ม ห้ามเปลี่ยน data, method, result หรือ limitation เพื่อให้ดู fit แล้วหยุดรอ

  3. ตรวจและตัดสินเอง (4 นาที)

    • เปิด submission/venue-change-impact.md ดูว่าทุกแถวที่ “เปลี่ยน” เป็นการนำเสนอจริง (โครงหัวข้อ abstract style citation) และไม่มีแถวใดเปลี่ยนตัวเลขหรือข้อจำกัด
    • ดูว่า BLOCKED ครอบคลุมสิ่งที่ profile ของ Journal B ระบุว่าไม่มีในชุดข้อมูล (calibration record, รายละเอียดเครื่องมือ)
    • กรอกส่วน Fit decision ในไฟล์เดียวกันเอง: New fit status, BLOCKED requirements, Presentation changes approved และ Changes rejected because they would alter the research

  4. (ถ้ามีเวลา) สั่ง AI สร้าง PDF ของ Journal B ให้ AI สร้าง LaTeX ชุดใหม่จาก source/manuscript.md ตามข้อกำหนด Journal B เป็นไฟล์แยกจาก generated/main.tex และ build/manuscript.pdf ของ Journal A แล้ว build จดชื่อไฟล์ที่ AI สร้าง และเปิด PDF ใหม่เทียบกับ PDF ของ Journal A ว่าตัวเลขและข้อจำกัดยังตรงกัน

เปลี่ยนวารสาร: ข้อกำหนดใหม่ เนื้อหาวิจัยเดิม (venue-change impact)

ในกิจกรรมนี้คุณจะเขียน prompt เองเพื่อให้ AI ช่วยทำ dossier ของแหล่งเผยแพร่ที่สอง และตาราง venue-change impact ที่แยกสิ่งที่เปลี่ยนได้กับสิ่งที่ต้องคงไว้ (ไม่มี prompt สำเร็จรูปให้)

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • งานของคุณเองที่มีวารสาร/แหล่งเผยแพร่เป้าหมายแล้ว พร้อมข้อกำหนดของแหล่งเดิม
  • แหล่งที่สองที่อาจส่งแทน (เช่น หลังถูกปฏิเสธ หรือเปลี่ยนจากวารสารเป็นการประชุมวิชาการ) และเข้าเว็บไซต์ทางการได้

โจทย์

  1. สร้างโฟลเดอร์ output/ ในโฟลเดอร์งานของคุณ (ถ้ายังไม่มี) และไฟล์ output/prompts.md สำหรับบันทึก prompt ทุกรอบ (prompt, สรุปผลที่ได้, สิ่งที่ปรับในรอบถัดไปและเหตุผล)
  2. เขียน prompt ให้ AI ช่วยทำ dossier ของแหล่งที่สองลง output/dossier-new-venue.md แยกจากของเดิม — ทุกข้อกำหนดมี URL ทางการ วันที่เข้าถึง และสถานะ ห้ามให้ AI เติมข้อกำหนดจากความจำ
  3. เขียน prompt ให้ AI ทำ output/venue-change-impact.md — ห้ามเปลี่ยนข้อมูล วิธี ผล หรือข้อจำกัดเพื่อให้เข้าแหล่งใหม่
  4. ตรวจผลของ AI เทียบกับเอกสารทางการ บันทึกว่าตรวจกับเอกสารใดและแก้อะไรเอง
