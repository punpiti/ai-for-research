Workshop

วิทยานิพนธ์รูปแบบ มก. ด้วย kuthesis: สร้าง PDF จากตัวอย่างและใช้ refs.bib ของตัวเอง

ใน workshop นี้ (ถ้ามีเวลาหรือทำหลังเรียน) คุณจะดาวน์โหลดแม่แบบ kuthesis ให้ AI build เล่มตัวอย่าง example-th.tex ที่มากับแม่แบบเป็น PDF ตรวจรูปแบบเอง แล้วลองเปลี่ยนไปใช้ไฟล์อ้างอิง refs.bib ของคุณ — ขั้น 1–4 ไม่ต้องใช้ข้อมูลของตัวเอง

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว (ตัวติดตั้ง Module 1 ติดตั้ง latexmk/xelatex ให้)
  • ติดตั้ง Module 8 แล้ว: มีโฟลเดอร์ module-08-work/ (ตัวติดตั้ง Module 8 สร้างให้)
  • อินเทอร์เน็ตสำหรับดาวน์โหลดแม่แบบจาก https://github.com/punpiti/kuthesis
  • ฟอนต์ TH Sarabun New (ฟอนต์แห่งชาติ ดาวน์โหลดฟรี) ติดตั้งในเครื่อง — ถ้ายังไม่มี ไม่เป็นไร ขั้น 2 มีทางเลือกฟอนต์สำรอง
  • (ขั้น 5 เท่านั้น) ไฟล์อ้างอิงหนึ่งไฟล์:
    • module-04-work/output/refs.bib จากหัวข้อ “ทะเบียนตรวจ citation: OpenAlex → full text → register” (กิจกรรมสร้าง BibTeX พร้อม abstract) ของ Module 4 หรือ
    • ถ้าไม่มี ใช้ module-08-work/literature/references.bib (ตัวติดตั้ง Module 8 สร้างให้) เพื่อฝึกการเปลี่ยนไฟล์อ้างอิง — เป็นระเบียนจำลองภาษาอังกฤษ จึงไม่ได้ฝึกการแก้ปี พ.ศ.

ขั้นตอน

  1. ดาวน์โหลดแม่แบบ เปิด Terminal ที่โฟลเดอร์ workspace แล้วรัน คำสั่งนี้จะสร้างโฟลเดอร์ module-08-work/kuthesis/

    git clone https://github.com/punpiti/kuthesis module-08-work/kuthesis

    หรือดาวน์โหลด ZIP จาก GitHub แล้วแตกไฟล์ไว้ที่ module-08-work/kuthesis/ เปิดโฟลเดอร์นั้นดูว่ามี example-th.tex, README.md, kuthesis.cls, kuthesis.bbx และ kuthesis.cbx

  2. ให้ AI build ตัวอย่าง ส่ง prompt นี้ AI จะสร้าง example-th.pdf ใน module-08-work/kuthesis/ (หรือ example-th-practice.tex กับ example-th-practice.pdf ถ้าคุณเลือกฟอนต์สำรอง)

    ใน module-08-work/kuthesis/ ให้สร้าง PDF ของ example-th.tex ด้วย latexmk -xelatex ตามที่ README.md ระบุ ห้ามแก้ kuthesis.cls, kuthesis.bbx และ kuthesis.cbx ถ้าขาด package ให้ติดตั้งด้วย tlmgr เฉพาะที่ขาด เช่น biblatex biber fancyhdr enumitem needspace pdflscape pict2e refcount hyperref แล้วรายงานรายชื่อที่ติดตั้ง ถ้าไม่พบฟอนต์ TH Sarabun New ในเครื่องให้หยุดถามฉันก่อน ถ้าฉันเลือกฟอนต์สำรอง ให้สร้างสำเนา example-th-practice.tex ที่ใช้ตัวเลือก thaifont=Sarabun,latin=sarabun และระบุในรายงานว่าไม่ใช่รูปแบบส่งเล่มจริง สรุปจำนวนหน้า คำเตือนที่เหลือ และคำสั่งที่ใช้ แล้วหยุดรอ

  3. ตรวจผลของ AI อ่านรายงานของ AI: รายชื่อ package ที่ติดตั้งต้องมาจาก tlmgr เท่านั้น และไฟล์ .cls/.bbx/.cbx ต้องไม่ถูกแก้ (ถ้าใช้ git clone ให้ดูว่าไม่มีการเปลี่ยนแปลงในไฟล์เหล่านั้น)

  4. ตรวจ PDF ทุกส่วนที่สำคัญ เปิด example-th.pdf (ประมาณ 25 หน้า) ตรวจปก สารบัญ การอ้างอิงในเนื้อความ และหน้า “เอกสารและสิ่งอ้างอิง” ลองเปิดตัวเลือก guides เพื่อดูเส้นวัดระยะขอบตามคู่มือ แล้วปิดก่อนถือเป็นฉบับส่ง จดรายการสิ่งที่ต้องแก้

  5. ใช้ refs.bib ของตัวเอง ส่ง prompt นี้ (ระบุตำแหน่งไฟล์อ้างอิงจาก “ก่อนเริ่ม”) AI จะสร้างสำเนาของ example-th.tex ที่ชี้ไปยังไฟล์อ้างอิงของคุณ จากนั้นตรวจผลเอง

    ในสำเนาของ example-th.tex ให้เปลี่ยนไฟล์อ้างอิงเป็น refs.bib ที่ฉันให้ (ระบุตำแหน่งไฟล์) โดยไม่แก้ไฟล์คลาส ก่อน build ให้ทำรายการระเบียนภาษาไทยใน refs.bib พร้อมปีและชื่อผู้แต่งปัจจุบัน ห้ามแก้ปีหรือชื่อเอง ให้หยุดรอให้ฉันยืนยันปี พ.ศ. และชื่อผู้แต่งอักษรไทยตามที่ปรากฏบนเอกสาร เมื่อฉันแก้แล้ว ให้ build และรายงาน citation ที่ไม่พบ คำเตือนที่เหลือ และจำนวนหน้า

    biblatex อ่าน refs.bib ได้ทันที ช่องสำหรับการตรวจ เช่น abstract_source และ identity_check ไม่ถูกพิมพ์ในรายการอ้างอิง แต่เอกสารไทยต้องใส่ปีเป็น พ.ศ. ตามที่ปรากฏบนเอกสาร (OpenAlex ให้ปี ค.ศ.) และชื่อผู้แต่งไทยต้องเป็นอักษรไทย ไม่ใช่ชื่อทับศัพท์

ตรวจก่อนจบ

ข้อควรรู้

  • kuthesis ไม่ใช่เอกสารทางการของมหาวิทยาลัย ก่อนส่งเล่มจริงต้องตรวจกับข้อกำหนดล่าสุดและแบบฟอร์มของบัณฑิตวิทยาลัย
  • ตัวเลือกที่ใช้บ่อย: numbered, guides, english — ดูทั้งหมดใน README.md ของ kuthesis

ส่งงาน

  • ส่งตามขั้นตอนส่งงานของโมดูล (ตอนนี้ Module 8 ยังไม่กำหนดช่องทางส่ง)

Exploring

วิทยานิพนธ์รูปแบบ มก. ด้วย kuthesis: สร้าง PDF จากตัวอย่างและใช้ refs.bib ของตัวเอง

ในโจทย์นี้คุณจะเขียน prompt เอง (ไม่มี prompt สำเร็จรูปให้) เพื่อให้ AI นำเนื้อหาจริงหนึ่งบทเข้าแม่แบบ kuthesis build เป็น PDF แล้วตรวจรูปแบบด้วยตัวเอง

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop หลักของหัวข้อนี้แล้ว: มี module-08-work/kuthesis/ และ build example-th.pdf (หรือ example-th-practice.pdf) ได้
  • เนื้อหาจริงหนึ่งบท (เช่น บทนำหรือบททบทวนวรรณกรรม) จากวิทยานิพนธ์ของคุณหรือของนิสิตในที่ปรึกษา (ได้รับอนุญาตแล้ว)
  • รายการอ้างอิงของบทนั้นอย่างน้อย 5 รายการ ที่มีเอกสารภาษาไทยอย่างน้อย 1 รายการ และตัวเอกสารภาษาไทยนั้น (ไว้ตรวจปี พ.ศ. และชื่อผู้แต่ง)

โจทย์

  1. เริ่มไฟล์ output/prompts.md ไว้บันทึก prompt ทุกรอบ
  2. เขียน prompt ให้ AI นำเนื้อหาบทนั้นเข้าแม่แบบ kuthesis (ไม่แก้ไฟล์คลาส) และทำ refs.bib ของบทนั้น
  3. build เป็น PDF แล้วตรวจรูปแบบ บันทึกลง output/thesis-check.md ที่คุณสร้างในขั้นนี้ (ปก/สารบัญ/การอ้างในเนื้อความ/หน้าเอกสารอ้างอิง/ระยะขอบด้วย guides)

ข้อกำหนด

  • output/prompts.md เก็บ prompt ทุกรอบ (prompt, สรุปผลที่ได้, สิ่งที่ปรับในรอบถัดไปและเหตุผล)
  • ระบุว่าตรวจผลของ AI อย่างไร (เทียบกับไฟล์/เอกสารต้นทางใด) และแก้อะไรเอง
  • ผลงาน: ไฟล์ต้นฉบับของบท, refs.bib, PDF และ output/thesis-check.md
  • ปี พ.ศ. และชื่อผู้แต่งภาษาไทยต้องตรวจกับตัวเอกสารเอง ไม่ใช้ค่าจาก OpenAlex โดยไม่ตรวจ
