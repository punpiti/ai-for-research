Workshop

หาข้อมูลเรื่องที่สนใจเพิ่มด้วย OpenAlex — ค้น คัด ทำ BibTeX พร้อม abstract แล้วสรุป

ใน workshop นี้คุณจะหาผลงานวิชาการในเรื่องที่คุณสนใจจาก OpenAlex สองทาง คือค้นเองบนเว็บ และให้ AI เรียก API แล้วคัดแหล่งที่ไม่ต้องการออก สร้าง refs.bib ที่มี abstract แล้วสรุปด้วย prompt หลายแบบ นี่ไม่ใช่การทำรีวิว แต่เป็นการหาข้อมูลเพิ่มแบบที่ทุกข้อสรุปชี้กลับไปหาผลงานได้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • เรื่องที่คุณสนใจหนึ่งเรื่อง และคำถามหนึ่งข้อ (ไม่ต้องเป็นหัวข้อวิจัยใหม่)
  • ต้องมี OpenAlex API key ของตัวเองในตัวแปร OPENALEX_KEY (ขั้นที่ 7 ของหัวข้อ "บัตรสรุป" — ถ้ายังไม่ได้ทำ กลับไปทำขั้นนั้นก่อน)
    • Windows: เปิด PowerShell พิมพ์ setx OPENALEX_KEY "key ของคุณ" แล้วปิด–เปิด VS Code ใหม่
    • macOS / Linux: เพิ่มบรรทัด export OPENALEX_KEY="key ของคุณ" ใน ~/.zshrc หรือ ~/.bashrc แล้วเปิด terminal ใหม่
    • ห้ามวาง key ใน prompt ไฟล์งาน หรือภาพหน้าจอ (ไม่มี key AI จะเรียก API ไม่ได้ — OpenAlex ตอบ 429)
  • ไฟล์ทั้งหมดของหัวข้อนี้อยู่ใน module-02-work/openalex/ (ดูแผนที่ไฟล์ใน module-02-work/openalex/README.md)

คำที่ใช้ใน workshop นี้

  • OpenAlex — ฐานข้อมูลเปิดของผลงานวิชาการ (บทความ หนังสือ รายงาน) ราว 250 ล้านรายการ พร้อมผู้แต่ง สถาบัน วารสาร การอ้างอิง และ abstract
  • work — หนึ่งผลงานใน OpenAlex มีรหัสแบบ W1234567890
  • source — แหล่งตีพิมพ์ เช่น วารสาร หรือ repository
  • abstract จาก OpenAlex — OpenAlex เก็บ abstract เป็นดัชนีคำ (abstract_inverted_index) ต้องประกอบกลับเป็นข้อความ บางผลงานไม่มี abstract
  • topic card — module-02-work/openalex/topic-card.json หัวข้อ คำถาม และจำนวนผลงาน ที่ส่งให้ผู้สอนรู้ว่าคุณสำรวจเรื่องอะไร

เริ่มหัวข้อ — ให้ AI รู้ว่ากำลังทำโมดูลไหน

ถ้าแชต AI เดิมทำโมดูลอื่นอยู่ ให้เปิดแชตใหม่ก่อน แล้ววาง prompt นี้

เริ่ม Module 2 หัวข้อ "หาข้อมูลเรื่องที่สนใจเพิ่มด้วย OpenAlex": ทำงานในหัวข้อนี้เฉพาะใน module-02-work/openalex/ เท่านั้น อ่าน module-02-work/openalex/README.md ก่อน แล้วตรวจว่ามีตัวแปร OPENALEX_KEY หรือไม่ (ตอบแค่ว่ามีหรือไม่มี ห้ามแสดงค่า) ถ้าไม่มี ให้หยุดและบอกฉันให้กลับไปทำขั้นที่ 7 ของหัวข้อบัตรสรุปก่อน ห้ามเรียก OpenAlex โดยไม่มี key

ตรวจ: มี module-02-work/openalex/README.md และ topic-card.json และ AI ตอบว่ามี OPENALEX_KEY (ถ้าไม่มี ให้ตั้งค่าตาม "ก่อนเริ่ม" แล้วเปิด VS Code ใหม่) · ถ้าไม่พบไฟล์ของหัวข้อนี้ ให้สั่ง AI รัน AIRR init module-2 ครั้งเดียว

ขั้นที่ 1 — รู้จัก OpenAlex: ค้นเองบนเว็บก่อน

  1. เปิด openalex.org พิมพ์คำค้นเรื่องของคุณ (ภาษาอังกฤษได้ผลดีกว่า)
  2. ลองตัวกรองด้านซ้าย: ปีที่ตีพิมพ์ ประเภทผลงาน และ Open Access
  3. เปิดผลงานหนึ่งรายการ ดูว่ามี abstract ผู้แต่ง วารสาร จำนวนครั้งที่ถูกอ้าง และรหัส W… อะไรบ้าง
  4. เปิด module-02-work/openalex/topic-card.json ใน VS Code แก้ topic (เรื่องสั้น ๆ หนึ่งบรรทัด) และ question (คำถามหนึ่งข้อ) เอง ตัวเลขยังปล่อยเป็น 0

ตรวจ: topic-card.json มี topic และ question ของคุณ และคุณจดได้ว่าค้นบนเว็บแล้วพบประมาณกี่รายการด้วยคำค้นใด

ขั้นที่ 2 — ให้ AI ค้น OpenAlex API เอง

วาง prompt นี้ แล้วแก้คำค้นและปีให้เป็นของคุณ

อ่าน topic และ question จาก module-02-work/openalex/topic-card.json แล้วค้น OpenAlex API ที่ https://api.openalex.org/works ด้วย search="<คำค้นของฉัน>" กรองปี from_publication_date:2018-01-01 และ type:article|review ใช้ API key จากตัวแปร OPENALEX_KEY เท่านั้น ห้ามพิมพ์ key ลงไฟล์ log หรือผลลัพธ์ใด ขอ per-page=50 เรียงตาม relevance_score เก็บผลลัพธ์ทั้งก้อนลง module-02-work/openalex/works.json บันทึก search-log.md: วันเวลา คำค้น ตัวกรอง URL ที่เรียก (ตัด api_key ออก) จำนวนที่พบทั้งหมด (meta.count) และจำนวนที่เก็บไว้ แสดงตารางสิบรายการแรก: ลำดับ | ปี | ชื่อเรื่อง | source | cited_by_count | มี abstract ไหม แล้วหยุดรอ

ตรวจ: มี works.json และ search-log.md ใน module-02-work/openalex/ · URL ใน log ไม่มี key · จำนวนที่พบใกล้เคียงกับที่คุณค้นบนเว็บด้วยคำค้นเดียวกัน (ถ้าต่างมาก ให้ถาม AI ว่าตัวกรองต่างกันตรงไหน)

ขั้นที่ 3 — คัดสิ่งที่ไม่อยากเอามาออก (คุณเป็นคนตัดสิน)

จาก module-02-work/openalex/works.json สรุปตาราง source ที่พบ: source | ประเภท | จำนวนผลงาน และนับผลงานที่ไม่มี abstract ผลงานที่ is_retracted เป็น true และผลงานที่ไม่ใช่ภาษาอังกฤษหรือไทย ยังไม่ต้องตัดอะไร แล้วหยุดรอ

ดูตารางแล้วตัดสินเองว่าจะไม่เอาอะไร เช่น วารสารที่คุณไม่เชื่อถือ ผลงานที่ถูกถอน (retracted) หรือผลงานที่ไม่มี abstract แล้วสั่ง

คัดออก: <รายการที่คุณเลือก พร้อมเหตุผลสั้น ๆ> บันทึก module-02-work/openalex/excluded.md: สิ่งที่คัดออก | เหตุผลของฉัน | จำนวนผลงานที่หายไป ห้ามแก้ works.json ให้ถือรายการที่เหลือเป็นชุดที่เก็บไว้ แล้วบอกจำนวนที่เหลือ

ตรวจ: excluded.md มีเหตุผลที่เป็นของคุณทุกแถว และ works.json ไม่ถูกแก้

ขั้นที่ 4 — สร้าง BibTeX พร้อม abstract

สร้าง module-02-work/openalex/refs.bib จากผลงานที่เก็บไว้ (works.json ลบด้วยรายการใน excluded.md) หนึ่ง entry ต่อหนึ่งผลงาน key แบบ ผู้แต่งคนแรกปีคำแรกของชื่อเรื่อง เช่น smith2021school ใส่ author, title, year, journal, doi และ field openalex_id ทุก entry ประกอบ abstract จาก abstract_inverted_index ของ OpenAlex เท่านั้น ห้ามแต่งหรือเรียบเรียงใหม่ ถ้าไม่มี abstract ให้ใส่ abstract_source = {none} และเว้น abstract ว่าง ถ้ามีให้ใส่ abstract_source = {openalex} แล้วแก้ตัวเลขใน module-02-work/openalex/topic-card.json: works_found = meta.count จาก search-log.md, works_kept = จำนวน entry, sources_excluded = จำนวนแถวใน excluded.md, bib_entries = จำนวน entry ห้ามแก้ topic และ question

ตรวจ: สุ่มสอง entry ใน refs.bib เปิดรหัส W… บน openalex.org เทียบชื่อเรื่อง ปี และประโยคแรกของ abstract ด้วยตัวเอง · ตัวเลขใน topic-card.json ตรงกับไฟล์จริง

ขั้นที่ 5 — สรุปด้วย prompt หลายแบบ

เลือกอย่างน้อยสองแบบ แต่ละแบบเขียนผลลงไฟล์แยกใน module-02-work/openalex/summaries/ ทุกแบบมีกติกาเดียวกัน: ใช้เฉพาะ abstract ใน refs.bib · ทุกข้อสรุปต้องอ้าง key · ถ้า abstract ไม่พอให้บอกว่าไม่พอ

  • แผนที่ประเด็น → summaries/map.md
    จาก abstract ใน module-02-work/openalex/refs.bib จัดกลุ่มผลงานเป็น 3–6 ประเด็น ตาราง: ประเด็น | key ที่อยู่ในกลุ่ม | ประโยคเดียวว่ากลุ่มนี้ศึกษาอะไร อ้าง key ทุกแถว ห้ามใช้ความรู้นอก abstract บันทึกลง module-02-work/openalex/summaries/map.md
  • ตารางเปรียบเทียบ → summaries/compare.md
    ทำตารางจาก abstract: key | บริบท/กลุ่มตัวอย่าง | วิธี | ผลหลัก (ตัวเลขถ้ามีพร้อมหน่วย) | ข้อจำกัดที่ผู้เขียนบอก ช่องที่ abstract ไม่บอกให้เขียน "ไม่ระบุ" ห้ามเดา บันทึกลง module-02-work/openalex/summaries/compare.md
  • ตอบคำถามของฉัน → summaries/answer.md
    ตอบ question ใน topic-card.json จาก abstract เท่านั้น แยกเป็น: สิ่งที่หลายผลงานพบตรงกัน (อ้างทุก key) · สิ่งที่ผลงานขัดกัน · สิ่งที่ abstract ชุดนี้ตอบไม่ได้ จบด้วยประโยคว่าข้อสรุปนี้จำกัดอยู่ที่ abstract ไม่ได้อ่านฉบับเต็ม บันทึกลง module-02-work/openalex/summaries/answer.md
  • อ่านอะไรต่อ → summaries/next.md
    เลือก 3 ผลงานจาก refs.bib ที่ควรอ่านฉบับเต็มก่อนเพื่อตอบคำถามของฉัน บอกเหตุผลจาก abstract และสิ่งที่ต้องไปตรวจในฉบับเต็ม บันทึกลง module-02-work/openalex/summaries/next.md

ตรวจ: ในแต่ละไฟล์ สุ่มหนึ่งประโยค หา key ที่อ้าง แล้วเปิด abstract ใน refs.bib ดูว่าพูดเรื่องนั้นจริง

ขั้นที่ 6 (ไม่บังคับ) — เรียก OpenAlex API แบบอื่น

ลองทีละข้อ ทุกคำสั่งบันทึกต่อท้าย search-log.md

  • แนวโน้มตามปี: > เรียก OpenAlex works ด้วยคำค้นเดิม group_by=publication_year แล้วแสดงจำนวนผลงานต่อปี
  • งานที่ถูกอ้างมาก: > ค้นคำเดิม sort=cited_by_count:desc per-page=10 แสดงปี ชื่อเรื่อง จำนวนครั้งที่ถูกอ้าง
  • เฉพาะที่อ่านฉบับเต็มได้ฟรี: > ค้นคำเดิม filter is_oa:true แสดงลิงก์ best_oa_location
  • งานที่อ้างผลงานหนึ่ง: > เรียก works ด้วย filter=cites:<รหัส W ของผลงานที่สนใจ> แสดง 10 รายการล่าสุด

ตรวจ: ทุกคำสั่งที่ลองมีบรรทัดใน search-log.md พร้อม URL (ไม่มี key) และจำนวนที่ได้

ขั้นที่ 7 — ส่งให้ผู้สอนรู้ว่าคุณสำรวจเรื่องอะไร

เปิด topic-card.json ตรวจว่า topic, question และตัวเลขทั้งสี่ตรงกับงานจริง แล้วสั่ง

รันเครื่องมือ AIRR ด้วยคำสั่ง check module-2 --short แล้วแสดงผลให้ฉันดู หยุดรอให้ฉันยืนยันก่อน เมื่อฉันยืนยันแล้ว จึงรัน submit module-2 --short --yes

topic card จะถูกส่งไปพร้อมงานแบบทางสั้นของ Module 2 (ส่งเฉพาะหัวข้อ คำถาม และตัวเลขสี่ตัว ไม่ส่ง abstract หรือรายการอ้างอิง) ทางสั้นใช้ module-02-work/openalex/refs.bib จากหัวข้อนี้ได้เลย (ถ้าทำ meal-card.md หรือ evidence-table.md จากหัวข้อก่อนหน้าไว้แล้ว ก็นับด้วย)

ตรวจ: ผลของ check มีบรรทัด topic card: … แสดงหัวข้อของคุณ และ submit ตอบ accepted

โจทย์

  1. ค้นสองแบบแล้วเทียบ — เขียน prompt เองให้ AI ค้นคำถามเดิมด้วยวิธีที่ต่างจาก workshop อย่างน้อยหนึ่งอย่าง เช่น ค้นเฉพาะชื่อเรื่องและ abstract (title_and_abstract.search) · เปลี่ยนคำค้นเป็นคำพ้อง · จำกัดปีหรือประเทศของสถาบัน · กรองเฉพาะ Open Access เก็บผลเป็น explore/works-b.json และต่อท้าย search-log.md
  2. เทียบชุดผล — ให้ AI นับว่าผลงานซ้ำกับชุด workshop กี่รายการ ใหม่กี่รายการ แล้วเปิดดูเองว่ารายการใหม่ 3 รายการแรกเกี่ยวกับคำถามของคุณจริงไหม
  3. สรุปด้วย prompt ที่คุณออกแบบเอง — เขียน prompt สรุปแบบใหม่หนึ่งแบบที่ workshop ไม่มี (เช่น สรุปวิธีวัดที่ใช้ · หาตัวเลขที่ขัดกัน · อธิบายให้คนนอกสาขาฟัง) บันทึกใน explore/ และต้องอ้าง key ทุกข้อ
  4. สูตร prompt ของคุณ — เขียนลง module-02-work/openalex/prompts.md 3–5 ข้อว่าต้องบอก AI อะไรบ้างถึงจะได้ชุดผลงานและสรุปที่ตรวจย้อนได้ (เช่น ระบุตัวกรอง · ห้ามใช้ความรู้นอก abstract · บังคับอ้าง key)

ข้อกำหนด

  • ห้ามวาง OpenAlex API key ใน prompt หรือไฟล์ใด ใช้ OPENALEX_KEY เท่านั้น
  • ไม่แก้ works.json และ refs.bib ของ workshop
  • ทุกข้อสรุปอ้าง key และบอกเมื่อ abstract ไม่พอ
  • ถ้าผลรอบใหม่ไม่ดีกว่า ให้บันทึกตามจริง
