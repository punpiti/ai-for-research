Workshop

สร้างบัตรสรุปจากหลักฐาน แล้วสั่งย่อโดยตัวเลข หน่วย และข้อจำกัดไม่หาย

ใน workshop นี้คุณจะให้ AI สร้างบัตรอาหาร meal-card.md จากหลักฐานที่ตรวจแล้ว เปิดตรวจกับต้นฉบับเอง แล้วสั่งย่อเหลือ 5 บรรทัดโดยตัวเลข หน่วย และป้ายข้อมูลจำลองไม่หาย ชุดหลักฐานเป็นกรณีสมมติ ไม่มีข้อมูลจริงของใคร

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ไฟล์ที่แตกแล้วใน module-02-work/input/original/module-02-food-evidence/ (จาก workshop “นำเข้าหลักฐานหลายรูปแบบ แล้วดูคำตอบรอบแรกของ AI”) ไฟล์ที่ใช้ตรวจผลอยู่ในโฟลเดอร์นั้นแล้ว:
    • 03-omelette-recipe-bilingual.docx (สูตร)
    • 07-mock-nutrition.csv (โภชนาการจำลอง)
    • 04-lunch-tray.png (ภาพที่สร้างด้วย AI)
    • 08-example-meal-card.md — ผลงานต้นแบบสำหรับเทียบ เตรียมไว้ล่วงหน้า ไม่ใช่ผลการรัน AI ที่ยืนยันแล้ว และห้ามส่งเป็นงานของผู้เรียน
  • ตารางข้อสรุปที่ตรวจแล้วจาก Prompt 2 ในแชต (จาก workshop “ตรวจว่าคำตอบแต่ละข้อมีหลักฐานแบบใด”)

คำที่ใช้ใน workshop นี้

  • บัตรสรุป (บัตรอาหาร) — meal-card.md หนึ่งหน้า รวมสูตร ตารางโภชนาการจำลอง คำบรรยายภาพ แหล่งข้อมูล และสิ่งที่ยังไม่ทราบ
  • ฉบับย่อ — บัตรที่ย่อเหลือ 5 บรรทัด เป็นไฟล์ใหม่ โดยฉบับเต็มยังอยู่
  • ป้ายข้อมูลจำลอง — ข้อความที่บอกว่าตัวเลขโภชนาการแต่งขึ้นเพื่อการสอน ไม่ได้คำนวณจากสูตรหรือภาพ
  • ข้อเท็จจริงใหม่ — ข้อความในฉบับย่อที่ไม่มีในฉบับเต็มหรือในต้นฉบับ

ขั้นที่ 1 — Prompt 3: สร้างบัตรอาหารแล้วเปิดดู

สั่ง AI

จากข้อมูลที่ตรวจแล้ว สร้าง module-02-work/output/meal-card.md หนึ่งหน้า มีสูตรสำหรับ 2 ที่ ตารางโภชนาการจำลองพร้อมหน่วย และคำบรรยายภาพ ระบุแหล่งข้อมูลและสิ่งที่ยังไม่ทราบ บอกชัดว่าตัวเลขโภชนาการแต่งขึ้นเพื่อการสอน ไม่ได้คำนวณจากสูตรหรือภาพ เปิด Markdown Preview ให้ฉันดู แล้วหยุดรอ

ตรวจ: มีไฟล์ module-02-work/output/meal-card.md (ฉบับเต็ม) และ Preview แสดงสูตร ตารางโภชนาการ คำบรรยายภาพ และส่วนสิ่งที่ยังไม่ทราบ

ขั้นที่ 2 — ตรวจ meal-card.md กับต้นฉบับเอง

เปิด meal-card.md ที่ AI เพิ่งสร้าง แล้วเทียบกับไฟล์ในชุด

  • สูตรตรงกับ Word หรือไม่
  • ตัวเลขและหน่วยตรงกับ CSV หรือไม่ (energy 500 kcal, protein 18 g, carbohydrate 62 g, fat 20 g ต่อ one fictional plate)
  • คำบรรยายภาพมีสิ่งที่มองไม่เห็นปนมาหรือไม่ (ภาพยืนยันความอิ่มหรือพลังงานไม่ได้)
  • มีป้ายบอกว่าตัวเลขโภชนาการเป็นข้อมูลจำลองหรือไม่

ถ้าพบจุดผิด ให้ชี้จุดนั้นแล้วสั่ง AI แก้

ตรวจ: ในบัตรเห็น 500 kcal, 18 g, 62 g, 20 g ตรงกับ 07-mock-nutrition.csv สูตรตรงกับ 03-omelette-recipe-bilingual.docx มีป้ายข้อมูลจำลอง และคำบรรยายภาพไม่อ้างความอิ่มหรือพลังงานจากภาพ

ขั้นที่ 3 — Prompt 4: สั่งย่อเหลือ 5 บรรทัด

สั่ง AI

แก้บัตรอาหารเดิมให้เหลือ 5 บรรทัดสำหรับคนกำลังเลือกมื้อกลางวัน คงตัวเลข หน่วย และป้ายข้อมูลจำลองไว้ ไม่เพิ่มข้อเท็จจริงใหม่ เก็บฉบับเดิมไว้ แล้วเปิดฉบับย่อเทียบกัน

AI จะสร้าง ฉบับย่อ เป็นไฟล์ใหม่ใน module-02-work/output/ และเก็บ meal-card.md ฉบับเต็มไว้ จดชื่อไฟล์ฉบับย่อที่ AI บอก สังเกตว่ารูปแบบเปลี่ยนตามคำสั่งหรือไม่ ข้อมูลสำคัญหายหรือถูกเปลี่ยนหรือไม่

ตรวจ: ใน module-02-work/output/ มีทั้ง meal-card.md และไฟล์ฉบับย่อ ฉบับย่อมี 5 บรรทัด ยังมีตัวเลขพร้อมหน่วยและป้ายข้อมูลจำลอง และไม่มีข้อความที่ไม่อยู่ในฉบับเต็ม

ขั้นที่ 4 — ลองเปลี่ยนคำสั่งหนึ่งจุด

เปลี่ยนคำสั่งหนึ่งจุด (เช่น กลุ่มผู้อ่าน หรือจำนวนบรรทัด) แล้วดูผลอีกครั้ง ตรวจซ้ำว่าตัวเลข หน่วย และข้อจำกัดยังอยู่ รายงานผลตามจริง แม้ฉบับที่เปลี่ยนคำสั่งจะไม่ดีขึ้น

ตรวจ: ผลใหม่ยังมีตัวเลขและหน่วยเดิม ป้ายข้อมูลจำลอง และข้อความว่ายังยืนยันความอิ่มไม่ได้ หรือคุณจดได้ว่าข้อใดหายไป

ขั้นที่ 5 — เทียบกับตัวอย่างบัตรสรุปที่ดี

สูตรสำหรับ 2 ที่ใช้ไข่ 3 ฟอง น้ำปลา น้ำมัน และข้าว ภาพแสดงข้าว ไข่เจียว และถ้วยซุป ตารางฝึกระบุพลังงานจำลอง 500 kcal ต่อจาน ซึ่งไม่ได้คำนวณจากสูตรนี้ ราคาเริ่มต้น 55 บาทอยู่ในงบ 80 บาท แต่ราคาและเวลารออาจเปลี่ยนตามรายการและวัน ข้อมูลชุดนี้ยังยืนยันไม่ได้ว่าผู้กินจะอิ่มถึง 16:00

สังเกตว่าตัวอย่างแยกสิ่งที่เห็นในภาพ ข้อมูลจากสูตร และข้อมูลจำลองออกจากกัน และบอกสิ่งที่ยังยืนยันไม่ได้ชัดเจน แล้วเทียบกับบัตรของคุณ

ตรวจ: ชี้ต้นทาง (ไฟล์และตำแหน่ง) ของข้อความสำคัญในบัตรของคุณได้อย่างน้อยสองข้อ และชี้ได้ว่าบัตรบอกข้อที่หลักฐานยังตอบไม่ได้ไว้ตรงไหน

ขั้นที่ 6 — ส่งงานแบบทางสั้น

ทางสั้นต้องมีสองไฟล์ที่ไม่ว่าง: module-02-work/output/meal-card.md (หัวข้อนี้) และ module-02-work/output/evidence-table.md (ขั้นที่ 6 ของ workshop "ตรวจว่าคำตอบแต่ละข้อมีหลักฐานแบบใด" ในหัวข้อก่อน ถ้ายังไม่มีให้ทำขั้นนั้นก่อน) เมื่อมีครบแล้ว สั่ง AI

รันเครื่องมือ AIRR ในโฟลเดอร์ tools/ ด้วยคำสั่ง check module-2 --short แล้วแสดงผลให้ฉันดู หยุดรอให้ฉันยืนยันก่อน เมื่อฉันยืนยันแล้ว จึงรัน submit module-2 --short --yes

check ไม่ส่งอะไรออกจากเครื่อง ส่วน submit --short ส่งเฉพาะจำนวนบรรทัดของสองไฟล์และแบบประเมิน module-02-work/output/module-2-evaluation.json ไม่ส่งเนื้อหางาน ถ้า AI แจ้งว่าไม่มีแบบประเมิน ให้สั่งรัน init module-2 แล้วกรอกแบบประเมินใน VS Code ก่อน

ตรวจ: AI แสดง AIRR CHECK PASS · module-2 ก่อนส่ง และหลังส่งแสดง AIRR SUBMIT PASS · module-2 พร้อมบรรทัด receipt=

ขั้นที่ 7 (ต้องทำ) — สมัคร OpenAlex API key สำหรับหัวข้อถัดไป

หัวข้อถัดไป "หาข้อมูลเรื่องที่สนใจเพิ่มด้วย OpenAlex" ให้ AI ค้นฐานข้อมูลงานวิจัย OpenAlex ซึ่งต้องใช้ API key ของแต่ละคน (ฟรี ใช้เวลาประมาณ 5 นาที) ต้องมีทุกคน เพราะถ้าไม่มี key ทุกเครื่องในเครือข่ายเดียวกันจะแบ่งโควตาฟรีรายวันชุดเดียวกัน และหมดก่อนทำเสร็จ key นี้ใช้ต่อใน Module 4 และ Module 8 ด้วย

  1. เปิด openalex.org/settings/api สมัครหรือเข้าสู่ระบบ แล้วคัดลอก API key
  2. ใน Cline วาง prompt AIRR key set openalex — ไฟล์ .airr/keys/openalex.txt ใน workspace จะเปิดขึ้นใน VS Code (หาเองได้ที่แถบซ้าย: .airr › keys › openalex.txt)
  3. วาง key แทนบรรทัดแรกของไฟล์นั้น กด Ctrl+S (macOS: Cmd+S) แล้วปิดแท็บ (ห้ามวาง key ในแชต AI) · ไม่ต้องปิด–เปิด VS Code
  4. วาง prompt นี้
AIRR key check openalex

ตรวจ: ได้ AIRR KEY PASS · openalex และไม่มี key ปรากฏในแชต · ถ้าไม่ผ่าน ผลจะบอกว่าตรวจที่ไหนบ้างและติดตรงไหน (เช่น ยังเป็นข้อความตัวอย่าง คัดลอกไม่ครบ หรือ OpenAlex ไม่รับ key) ให้แก้ไฟล์ตามนั้นแล้วรันซ้ำ

ตรวจก่อนจบ workshop

Exploring

สร้างบัตรสรุปจากหลักฐาน แล้วสั่งย่อโดยตัวเลข หน่วย และข้อจำกัดไม่หาย

ในโจทย์เปิดนี้คุณจะเขียน prompt เองให้ AI สร้างสรุปหนึ่งหน้า my-topic-summary.md จากหลักฐานของคุณ ตรวจกับต้นฉบับ แล้วสั่งย่อสำหรับผู้อ่านกลุ่มหนึ่งโดยตัวเลข หน่วย ข้อจำกัด และป้ายสถานะข้อมูลไม่หาย

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ชุดไฟล์และตารางข้อสรุปที่ตรวจแล้วจากโจทย์เปิดของ evidence-levels-source-tracing (หัวข้อ อ่านหลักฐานหลายรูปแบบและชี้ระดับต้นทาง) (หรือชุดสำรอง module-02-work/input/original/module-02-food-evidence/ กับคำถามใหม่ของตนเอง)
  • module-02-work/output/prompts.md จากโจทย์เปิดก่อนหน้า (ถ้ายังไม่มี ให้สร้างเองตอนเริ่ม)
  • ใช้เฉพาะไฟล์ที่มีสิทธิ์ใช้ และตัดข้อมูลลับ/ข้อมูลส่วนบุคคลแล้ว

โจทย์

  1. เขียน prompt เองให้ AI สร้างสรุปหนึ่งหน้าใน module-02-work/output/my-topic-summary.md ที่ระบุไฟล์และตำแหน่งของข้อความสำคัญ และแยกส่วน “สิ่งที่ยังตอบไม่ได้”
  2. เปิด my-topic-summary.md ที่ AI สร้าง ตรวจกับต้นฉบับ แล้วสั่งแก้ส่วนที่ผิด
  3. เขียน prompt อีกรอบให้ย่อหรือเปลี่ยนรูปแบบสำหรับผู้อ่านกลุ่มหนึ่งที่คุณเลือก (เช่น นิสิตในที่ปรึกษา ผู้บริหาร หรือ abstract) โดยเก็บฉบับเต็มไว้
  4. ทำรายการเทียบฉบับเต็มกับฉบับย่อ: ตัวเลข หน่วย ข้อจำกัด และป้าย (เช่น ข้อมูลจำลอง/ประมาณ/ยังไม่ยืนยัน) ที่ยังอยู่ หาย หรือถูกเปลี่ยน

ข้อกำหนด

  • เก็บ prompt ที่ใช้ทุกรอบไว้ใน module-02-work/output/prompts.md
  • ระบุว่าตรวจผลของ AI อย่างไร: ตัวเลขใดเทียบกับไฟล์ใด และแก้อะไรเอง
  • ห้ามสั่งให้ AI แต่งข้อมูลแทนหลักฐาน ถ้าข้อมูลขาดให้ AI ถามและรอ
