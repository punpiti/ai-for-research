Prompt

ให้ AI รันคำสั่ง AIRR ที่ปลอดภัย

ใน workshop นี้คุณจะให้ AI แสดงรายการคำสั่ง AIRR รันคำสั่งที่ไม่ส่งอะไร และอ่านผลที่ AI รายงานกลับ

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: ai-for-research-workspace เปิดใน VS Code, AI panel เชื่อมแล้ว และ AI เคยรัน whoami ได้
  • เครื่องมือ tools/airr.ps1 (Windows) และ tools/airr.sh (macOS/Linux) ที่ตัวติดตั้ง Module 1 วางไว้

ขั้นตอน

  1. ให้ AI แสดงคำสั่งที่มี

    ใช้เครื่องมือ AIRR ใน tools/ ของ workspace นี้ รัน help แล้วสรุปเป็นตารางภาษาไทยว่ามีคำสั่งอะไร แต่ละคำสั่งส่งข้อมูลออกจากเครื่องหรือไม่ ห้ามรันคำสั่งอื่น ห้ามแสดง AIRR Key

  2. เทียบตารางของ AI กับตารางในสไลด์: whoami, status, check, init ไม่ส่งงาน · submit ส่ง · materials ดาวน์โหลดไฟล์ฝึก · login/logout เปลี่ยนการเชื่อม

  3. ให้ AI ดูผลการส่งของ Module 1

    ใช้เครื่องมือ AIRR รันคำสั่ง status module-1 แล้วบอกฉันว่า server ได้รับสถานะอะไร เมื่อไร ห้ามแก้ไฟล์

  4. ให้ AI ตรวจไฟล์สถานะในเครื่องโดยไม่ส่ง

    ใช้เครื่องมือ AIRR รันคำสั่ง check module-1 อธิบายผลเป็นภาษาง่าย ๆ ว่าผ่านหรือไม่ผ่านเพราะอะไร ห้ามรัน submit

  5. อ่านคำตอบของ AI ว่ามีการส่งอะไรออกไปหรือไม่ (ต้องไม่มี)

Exploring

คำสั่ง AIRR: ให้ AI รันให้ และรู้ว่าแต่ละคำสั่งส่งอะไร

ไม่มี prompt สำเร็จรูป — เขียนเองให้ AI ทำงานกับ AIRR อย่างปลอดภัย

โจทย์ (เลือกอย่างน้อย 1 ข้อ)

  1. ให้ AI อธิบายว่าเมื่อส่งงาน Module ที่คุณเรียนอยู่ ระบบส่งอะไรออกไปบ้าง โดยอ่านจากผล check และ --help ไม่ใช่เดา
  2. เขียน prompt ส่งงานของคุณเองที่บังคับให้ AI: ตรวจก่อน (check) → สรุปสิ่งที่จะส่ง → รอคุณยืนยัน → ส่ง → บอกผล

ข้อกำหนด

  • สร้างไฟล์ module-01-work/output/prompts.md เก็บ prompt ทุกรอบ
  • ห้ามให้ AI แสดง คัดลอก หรือส่งต่อ AIRR Key · ห้ามรัน logout (จะตัดการเชื่อม)
