Prompt

ให้ AI รันคำสั่ง AIRR ที่ปลอดภัย

ใน workshop นี้คุณจะให้ AI แสดงรายการคำสั่ง AIRR รันคำสั่งที่ไม่ส่งอะไรและไม่แก้ไฟล์ แล้วอ่านผลที่ AI รายงานกลับ

ใช้เมื่อ: อยากรู้ว่า AI รันคำสั่ง AIRR อะไรให้ และคำสั่งไหนส่งข้อมูลออกจากเครื่อง

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • เครื่องมือ tools/airr.ps1 (Windows) และ tools/airr.sh (macOS/Linux) ที่ตัวติดตั้ง Module 1 วางไว้

คำที่ใช้ใน workshop นี้

  • AIRR — เครื่องมือที่เชื่อม workspace ของคุณกับคลาส ปกติให้ AI รันให้ ไม่ต้องพิมพ์เอง
  • AIRR Key — รหัสที่ผูก workspace กับบัญชีของคุณ เก็บใน .airr/ ห้ามแสดง คัดลอก หรือส่งต่อ
  • ส่งออกจากเครื่อง — คำสั่งที่ส่งงานหรือสถานะของคุณไปให้ผู้สอน มีคำสั่งเดียวคือ submit
คำสั่ง ทำอะไร ส่งงานออกจากเครื่อง
help · version · whoami อธิบายคำสั่ง · ดูรุ่นเครื่องมือ · ดูคลาสที่เชื่อม ไม่
status module-N ดูผลที่ server ได้รับและ feedback ไม่
init module-N · check module-N สร้างไฟล์เริ่มต้น · ตรวจไฟล์ในเครื่อง ไม่ (แต่อาจสร้างไฟล์ในเครื่อง)
materials · update · ai-key ดาวน์โหลดไฟล์ฝึก · อัปเดตเครื่องมือ · รับ OpenRouter key ลงไฟล์ส่วนตัว ไม่ (ดาวน์โหลดลงเครื่อง)
submit module-N ส่งงานหรือสถานะให้ผู้สอน ส่ง — ต้องยืนยันก่อน
login · logout เชื่อม / ยกเลิกการเชื่อม (ตัวติดตั้งทำให้แล้ว) เปลี่ยนการเชื่อม ไม่ต้องใช้ในคลาส

ขั้นที่ 1 — ให้ AI สรุปคำสั่งทั้งหมด

ใช้เครื่องมือ AIRR ใน tools/ ของ workspace นี้ รัน help แล้วสรุปเป็นตารางภาษาไทยว่ามีคำสั่งอะไร แต่ละคำสั่งส่งงานออกจากเครื่องหรือไม่ ห้ามรันคำสั่งอื่น ห้ามแสดง AIRR Key

ตรวจ: ตารางของ AI มีคำสั่งครบตามตารางข้างบน และบอกว่ามีเพียง submit ที่ส่งงานออก

ขั้นที่ 2 — ดูรุ่นเครื่องมือ

ใช้เครื่องมือ AIRR รันคำสั่ง version แล้วบอกฉันว่าเป็นรุ่นอะไร และมีรุ่นใหม่กว่าหรือไม่ ห้ามรัน update

ตรวจ: AI รายงานเลขรุ่น และบอกว่ามีรุ่นใหม่หรือไม่ โดยไม่ได้รัน update

ขั้นที่ 3 — ดูผลที่ server ได้รับของ Module 1

ใช้เครื่องมือ AIRR รันคำสั่ง status module-1 แล้วบอกฉันว่า server ได้รับสถานะอะไร เมื่อไร ห้ามแก้ไฟล์

ตรวจ: AI รายงาน completed จำนวนครั้งที่ส่ง (attempts) และเวลาที่ server ได้รับ (ถ้ายังไม่ได้กด "แจ้งผู้สอนว่าเสร็จ" ใน Module 1 จะเห็น attempts=0) และไม่แสดง AIRR Key

ขั้นที่ 4 — ยืนยันว่าไม่มีอะไรถูกส่ง

อ่านคำตอบของ AI ทั้งสามขั้น แล้วถาม AI ว่ารันคำสั่งอะไรไปบ้าง

ตรวจ: คำสั่งที่รันมีเพียง help, version และ status ไม่มี submit และไม่มีไฟล์ในเครื่องถูกแก้

Exploring

คำสั่ง AIRR: ให้ AI รันให้ และรู้ว่าแต่ละคำสั่งส่งอะไร

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI ทำงานกับ AIRR อย่างปลอดภัย

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้แล้ว (รู้ว่ามีเพียง submit ที่ส่งงานออก)
  • Module ที่คุณกำลังเรียนและมีงานส่งผ่าน AIRR (เช่น Module 2, 3, 4 หรือ 7)

โจทย์ (เลือกอย่างน้อย 1 ข้อ)

  1. ให้ AI อธิบายว่าเมื่อส่งงาน Module ที่คุณเรียนอยู่ ระบบส่งอะไรออกไปบ้าง โดยอ่านจากผล help submit และ check ของ Module นั้น ไม่ใช่เดา
  2. เขียน prompt ส่งงานของคุณเองที่บังคับให้ AI: ตรวจก่อน (check) → สรุปสิ่งที่จะส่ง → รอคุณยืนยัน → ส่ง → บอกผล

ข้อกำหนด

  • สร้างไฟล์ module-01-work/output/prompts.md เก็บ prompt ทุกรอบ
  • ห้ามให้ AI แสดง คัดลอก หรือส่งต่อ AIRR Key · ห้ามรัน logout (จะตัดการเชื่อม)
