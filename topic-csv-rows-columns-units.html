Workshop

CSV: หนึ่งแถวแทนอะไร ชื่อคอลัมน์ หน่วย และค่าที่ขาด

ใน workshop นี้คุณจะอ่าน CSV ตัวอย่างและข้อมูลจำลอง PM2.5 ของ Module 7 ให้ AI รายงานโครงไฟล์ ตรวจค่าที่ AI ยกมากลับกับไฟล์เอง แล้วบันทึกผลลงไฟล์ file-reading.md

ใช้เมื่อ: ก่อนเปิดข้อมูลใน Module 7

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • course-materials/module-07/examples/figure-consistency/mock-study-data.csv — ข้อมูลจำลอง PM2.5 480 แถว ไม่มีข้อมูลจริงของใคร (ตัวติดตั้ง Module 1 วางไว้ให้ อ่านอย่างเดียว ห้ามแก้)
  • คำอธิบายชุดข้อมูล: ตาราง "ข้อมูล" ในหน้า Module 7 ของเว็บคลาส

ขั้นตอน

  1. อุ่นเครื่องกับตัวอย่างบนหน้านี้ (อ่านเอง ไม่ใช้ AI) CSV จำลองด้านล่างมีสองแถว

    room_id,temperature_c,reading_time A,26.5,2026-11-20T09:00:00+07:00 B,,2026-11-20T09:00:00+07:00

    ตอบให้ได้ว่า

    • หนึ่งแถวแทนการอ่านอุณหภูมิห้องหนึ่งครั้ง
    • temperature_c หน่วยองศาเซลเซียส · room_id เป็นรหัสห้อง ไม่ใช่ค่าที่นำมาเฉลี่ย
    • ช่องว่างของห้อง B = ไม่มีค่าระบุไว้ในไฟล์นี้ ใช้แทน 0 องศาไม่ได้

  2. เปิด mock-study-data.csv ใน VS Code แล้วระบุว่าหนึ่งแถวแทนอะไร จากตาราง "ข้อมูล" ในหน้า Module 7

  3. เลือกคอลัมน์ที่จะใช้สองคอลัมน์ บอกความหมาย หน่วย และค่าที่ขาด หากคำอธิบายยังไม่ระบุให้บันทึกว่ายังไม่ทราบ

  4. ให้ AI รายงานโครงไฟล์ก่อนสร้างกราฟ วาง prompt นี้ แล้วต่อท้ายด้วย path ของ CSV ชื่อสองคอลัมน์ที่เลือก และตาราง "ข้อมูล" ที่คัดลอกจากหน้า Module 7

    อ่าน CSV นี้และคำอธิบายชุดข้อมูล สรุปว่าหนึ่งแถวแทนอะไร แต่ละคอลัมน์ที่ฉันเลือกมีความหมายและหน่วยใด พร้อมยกตัวอย่างค่าที่ตรวจย้อนถึงแถวได้สองค่า แจ้งสิ่งที่ยังไม่ทราบและค่าที่ขาดก่อนเสนอการคำนวณ

  5. ตรวจตัวอย่างสองค่ากลับกับไฟล์ต้นทางด้วยตนเอง เปิด CSV ไปที่แถวที่ AI ระบุ เทียบเลขทศนิยม เครื่องหมาย และช่องว่าง

  6. ถ้าไฟล์เปิดแล้วคอลัมน์เลื่อน ภาษาไทยผิด หรือรหัสหายเลขศูนย์นำหน้า ให้ตรวจตัวคั่น การเข้ารหัส และชนิดข้อมูลก่อนวิเคราะห์

  7. บันทึกผล สร้างไฟล์ใหม่ module-07-work/notes/file-reading.md (พิมพ์เอง หรือให้ AI สร้างโดยสร้างโฟลเดอร์ module-07-work/notes/ ถ้ายังไม่มี) ใส่คำตอบของขั้น 2, 3 และ 5

ตรวจก่อนจบ

ส่งงาน

  • X01 ไม่มีงานส่งแยก งานส่งของ Module 7 ทำตามหน้า Module 7

Exploring

CSV: หนึ่งแถวแทนอะไร ชื่อคอลัมน์ หน่วย และค่าที่ขาด

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI รายงานโครงของ CSV จากงานของคุณก่อนวิเคราะห์ แล้วตรวจค่ากลับถึงแถวต้นทางและบันทึกการตัดสินใจเรื่องค่าที่ขาด

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้แล้ว
  • CSV จากงานของคุณที่มีสิทธิ์ใช้กับ AI และไม่มีข้อมูลส่วนบุคคล (เช่น ผลการทดลอง ข้อมูลเครื่องวัด หรือตารางสรุป) พร้อมคำอธิบายข้อมูลถ้ามี หรือชุดสำรอง course-materials/module-07/examples/figure-consistency/mock-study-data.csv (ตัวติดตั้ง Module 1 วางไว้ให้) กับคอลัมน์ที่ยังไม่ได้ใช้ใน workshop

โจทย์

  1. สร้างไฟล์ output/prompts.md ในโฟลเดอร์งานของคุณ (เช่น module-07-work/output/prompts.md) สำหรับเก็บ prompt ที่ใช้ทุกรอบ
  2. เขียน prompt ของตนให้ AI รายงานโครงไฟล์ก่อนวิเคราะห์ ได้แก่ หนึ่งแถวแทนอะไร คอลัมน์ หน่วย ค่าที่ขาด และสิ่งที่ยังไม่ทราบ
  3. หาค่าที่ขาดหรือค่าที่น่าสงสัยอย่างน้อยหนึ่งจุด แล้วตัดสินเองว่าควรจัดการอย่างไร โดยอ้างคำอธิบายข้อมูล (หรือบันทึกว่าคำอธิบายยังไม่ระบุ)
  4. ตรวจค่าอย่างน้อยสองค่ากลับถึงแถวต้นทาง (ทศนิยม เครื่องหมาย ช่องว่าง)

ข้อกำหนด

  • ห้ามแก้ CSV ต้นฉบับ
  • ระบุว่าตรวจผลของ AI อย่างไร และแก้อะไรเอง
