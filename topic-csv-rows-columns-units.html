Workshop

CSV: หนึ่งแถวแทนอะไร ชื่อคอลัมน์ หน่วย และค่าที่ขาด

ใน workshop นี้คุณจะอ่าน CSV ตัวอย่างและข้อมูลจำลอง PM2.5 ของ Module 7 ให้ AI รายงานโครงไฟล์ ตรวจค่าที่ AI ยกมากลับกับไฟล์เอง แล้วบันทึกผลลงไฟล์ file-reading.md

ใช้เมื่อ: ก่อนเปิดข้อมูลใน Module 7

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • ไฟล์ตัวอย่างอยู่ที่ module-01-work/input/file-basics/ (ตัวติดตั้ง Module 1 วางไว้ให้ อ่านอย่างเดียว ห้ามแก้) ถ้ายังไม่มี ให้สั่ง AI ว่า AIRR init module-1 · งานที่คุณสร้างหรือแก้ทั้งหมดใน X01 เก็บที่ module-01-work/output/file-basics/
  • module-01-work/input/file-basics/room-temperature-readings.csv — CSV จำลองสองแถว (ขั้นที่ 1)
  • module-01-work/input/file-basics/mock-study-data.csv — ข้อมูลจำลอง PM2.5 480 แถว ไม่มีข้อมูลจริงของใคร
  • คำอธิบายชุดข้อมูล: ส่วน "นำเข้าข้อมูล" ในหน้า Module 7 (ตาราง "คอลัมน์ · ความหมาย")

คำที่ใช้ใน workshop นี้

  • CSV — ตารางที่เก็บเป็นข้อความ หนึ่งบรรทัดคือหนึ่งแถว ค่าในแถวคั่นด้วยจุลภาค
  • หน่วยวิเคราะห์ — สิ่งที่หนึ่งแถวแทน เช่น การวัดหนึ่งครั้ง หรือหนึ่งเครื่องในหนึ่งสัปดาห์
  • รหัส — คอลัมน์ที่ใช้ระบุ เช่น sensor_id ไม่ใช่ค่าที่นำมาคำนวณ
  • ค่าที่ขาด — ช่องว่างในไฟล์ แปลว่าไม่มีค่าระบุ ไม่ใช่ศูนย์

เริ่มหัวข้อ — ให้ AI รู้ว่ากำลังทำโมดูลไหน

ถ้าแชต AI เดิมทำโมดูลอื่นอยู่ ให้เปิดแชตใหม่ก่อน แล้ววาง prompt นี้

เริ่ม Module 1 หัวข้อ "CSV: หนึ่งแถวแทนอะไร ชื่อคอลัมน์ หน่วย และค่าที่ขาด": ทำงานตามแผนที่ไฟล์ใน module-01-work/ เท่านั้น อ่าน input/ และ course-materials/ โดยห้ามแก้ และเขียนผลลงตำแหน่งที่หัวข้อนี้กำหนด

ตรวจ: AI บอกได้ว่าไฟล์ที่หัวข้อนี้ใช้อยู่ที่ไหน · ถ้าไม่พบไฟล์ของหัวข้อนี้ ให้สั่ง AI รัน AIRR init module-1 ครั้งเดียว

ขั้นที่ 1 — อุ่นเครื่องกับตัวอย่างบนหน้านี้ (อ่านเอง ไม่ใช้ AI)

เปิด module-01-work/input/file-basics/room-temperature-readings.csv ใน VS Code (เนื้อหาตามด้านล่าง) มีสองแถว

room_id,temperature_c,reading_time A,26.5,2026-11-20T09:00:00+07:00 B,,2026-11-20T09:00:00+07:00

ตอบให้ได้ว่าหนึ่งแถวแทนอะไร คอลัมน์ไหนเป็นรหัส คอลัมน์ไหนเป็นค่าและหน่วยอะไร และช่องว่างของห้อง B หมายความว่าอะไร

ตรวจ: คำตอบของคุณคือ หนึ่งแถว = การอ่านอุณหภูมิห้องหนึ่งครั้ง · room_id เป็นรหัส · temperature_c เป็นองศาเซลเซียส · ช่องว่างของห้อง B = ไม่มีค่า ใช้แทน 0 องศาไม่ได้

ขั้นที่ 2 — เปิดไฟล์จริงและระบุหน่วยวิเคราะห์

เปิด module-01-work/input/file-basics/mock-study-data.csv ใน VS Code แล้วอ่านส่วน "นำเข้าข้อมูล" ในหน้า Module 7 เขียนหนึ่งประโยคว่าหนึ่งแถวแทนอะไร

ตรวจ: ประโยคของคุณตรงกับคำอธิบายในหน้า Module 7 (ค่าจากเครื่องวัดหนึ่งเครื่องในหนึ่งสัปดาห์)

ขั้นที่ 3 — เลือกสองคอลัมน์และบอกความหมาย หน่วย ค่าที่ขาด

เลือกสองคอลัมน์ ให้มีรหัสหนึ่งคอลัมน์และค่าหนึ่งคอลัมน์ (เช่น sensor_id กับ pm25_ug_m3) เขียนความหมายและหน่วยของแต่ละคอลัมน์ ถ้าคำอธิบายไม่ได้ระบุ ให้บันทึกว่า "ยังไม่ทราบ"

ตรวจ: บอกได้ว่าคอลัมน์ไหนเป็นรหัสและคอลัมน์ไหนนำมาคำนวณได้ และทุกหน่วยที่เขียนมีที่มาจากคำอธิบาย ไม่ได้เดา

ขั้นที่ 4 — ให้ AI รายงานโครงไฟล์ก่อนวิเคราะห์

วาง prompt นี้ แล้วต่อท้ายด้วย path ของ CSV และชื่อสองคอลัมน์ที่เลือก

อ่าน CSV นี้และคำอธิบายชุดข้อมูลในส่วน "นำเข้าข้อมูล" ของหน้า Module 7 (ฉันวางไว้ด้านล่าง) สรุปว่าหนึ่งแถวแทนอะไร คอลัมน์ที่ฉันเลือกมีความหมายและหน่วยใด นับจำนวนแถวและช่องว่างของสองคอลัมน์นี้ ยกตัวอย่างค่าสองค่าพร้อมเลขแถวให้ฉันตรวจ แจ้งสิ่งที่ยังไม่ทราบก่อนเสนอการคำนวณ ห้ามแก้ไฟล์

แล้ววางตาราง "คอลัมน์ · ความหมาย" ที่คัดลอกจากหน้า Module 7 ต่อท้าย

ตรวจ: AI รายงานจำนวนแถว 480 และจำนวนช่องว่างของสองคอลัมน์ (ชุดนี้ไม่มีค่าว่าง ถ้า AI บอกว่ามี ให้ถามว่าแถวไหน) และยกค่ามาสองค่าพร้อมเลขแถว

ขั้นที่ 5 — ตรวจสองค่ากลับกับไฟล์ด้วยตนเอง

เปิด CSV ไปที่แถวที่ AI ระบุ (VS Code: Ctrl+G แล้วพิมพ์เลขบรรทัด · macOS: Control+G ระวังว่าบรรทัดที่ 1 คือหัวตาราง) เทียบทศนิยม เครื่องหมาย และช่องว่าง

ตรวจ: ทั้งสองค่าตรงกับไฟล์ หรือคุณจดได้ว่าไม่ตรงตรงไหน

ขั้นที่ 6 — บันทึกผล

สร้าง module-01-work/output/file-basics/file-reading.md (พิมพ์เอง หรือให้ AI สร้าง โดยสร้างโฟลเดอร์ module-01-work/output/file-basics/ ถ้ายังไม่มี) ใส่คำตอบของขั้นที่ 2, 3 และ 5 ถ้าเปิดไฟล์แล้วคอลัมน์เลื่อน ภาษาไทยผิด หรือรหัสหายเลขศูนย์นำหน้า ให้จดไว้ด้วย (เป็นปัญหาตัวคั่น การเข้ารหัส หรือชนิดข้อมูล)

ตรวจ: เปิด file-reading.md แล้วเห็นคำตอบครบสามขั้น และ mock-study-data.csv ไม่ถูกแก้ (VS Code ไม่แสดงจุดแก้ค้างที่แท็บของไฟล์)

ตรวจก่อนจบ workshop

Exploring

CSV: หนึ่งแถวแทนอะไร ชื่อคอลัมน์ หน่วย และค่าที่ขาด

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI รายงานโครงของ CSV จากงานของคุณก่อนวิเคราะห์ แล้วตรวจค่ากลับถึงแถวต้นทางและบันทึกการตัดสินใจเรื่องค่าที่ขาด

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้แล้ว
  • CSV จากงานของคุณที่มีสิทธิ์ใช้กับ AI และไม่มีข้อมูลส่วนบุคคล (เช่น ผลการทดลอง ข้อมูลเครื่องวัด หรือตารางสรุป) พร้อมคำอธิบายข้อมูลถ้ามี หรือชุดสำรอง module-01-work/input/file-basics/mock-study-data.csv (ตัวติดตั้ง Module 1 วางไว้ให้) กับคอลัมน์ที่ยังไม่ได้ใช้ใน workshop

โจทย์

  1. สร้างไฟล์ output/prompts.md ในโฟลเดอร์งานของคุณ (เช่น module-01-work/output/file-basics/prompts.md) สำหรับเก็บ prompt ที่ใช้ทุกรอบ
  2. เขียน prompt ของตนให้ AI รายงานโครงไฟล์ก่อนวิเคราะห์ ได้แก่ หนึ่งแถวแทนอะไร คอลัมน์ หน่วย ค่าที่ขาด และสิ่งที่ยังไม่ทราบ
  3. หาค่าที่ขาดหรือค่าที่น่าสงสัยอย่างน้อยหนึ่งจุด แล้วตัดสินเองว่าควรจัดการอย่างไร โดยอ้างคำอธิบายข้อมูล (หรือบันทึกว่าคำอธิบายยังไม่ระบุ)
  4. ตรวจค่าอย่างน้อยสองค่ากลับถึงแถวต้นทาง (ทศนิยม เครื่องหมาย ช่องว่าง)

ข้อกำหนด

  • ห้ามแก้ CSV ต้นฉบับ
  • ระบุว่าตรวจผลของ AI อย่างไร และแก้อะไรเอง
