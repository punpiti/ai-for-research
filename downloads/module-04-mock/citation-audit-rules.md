# กติกาการตรวจการอ้างอิง Module 4

ไฟล์นี้ให้ AI อ่านก่อนทำ sub-module 4.1–4.3 ใช้คู่กับ `citation-register-template.csv`

## ตรวจสองชั้น

1. **ref มีจริง:** เอกสารมีอยู่จริง และ author, year, title, venue, DOI ตรงกับแหล่งทางการ
2. **cite ถูกต้อง:** ข้อความรอบ citation ตรงกับสิ่งที่เอกสารเขียน ในขอบเขตเดียวกัน

DOI ที่เปิดได้ยืนยันได้แค่ชั้นที่ 1 ตรวจกับ abstract ใช้คัดกรอง การตัดสินชั้นที่ 2 ต้องใช้ฉบับเต็ม

## คอลัมน์ของ citation-register.csv

หนึ่งแถวต่อหนึ่งรายการในรายการอ้างอิง ใช้หัวคอลัมน์ตาม `citation-register-template.csv` ทุกตัว

| คอลัมน์ | ใส่อะไร |
|---|---|
| ref_no, citation_key | ลำดับในรายการอ้างอิง และ key ใน refs.bib |
| raw_reference | ข้อความรายการอ้างอิงตามต้นฉบับ |
| openalex_id, doi | ผลจับคู่จาก OpenAlex (เว้นว่างถ้าไม่พบ) |
| identity_check | matched, metadata_conflict หรือ not_found พร้อมช่องที่ไม่ตรง |
| search_sources | แหล่งที่ค้นแล้ว เช่น OpenAlex; DOI; ThaiJO; TCI; ThaiLIS |
| retracted | true / false / unknown |
| abstract_source | openalex, publisher หรือ not found |
| local_fulltext | literature/markdown/<citation_key>.md หรือว่าง |
| cited_at | ทุกตำแหน่งที่ถูกอ้าง (หัวข้อ ย่อหน้า หน้า) คั่นด้วย ; |
| citing_context | ประโยครอบ citation ทุกตำแหน่ง คั่นด้วย ; |
| support | รองรับ / รองรับบางส่วน / ไม่รองรับ / ตรวจไม่ได้ พร้อมหน้าหรือส่วนของต้นฉบับ |
| checked_against | abstract หรือ full_text |
| status | หนึ่งในหกสถานะด้านล่าง เขียนตามตัวสะกดนี้ |
| decision | เก็บ / ลดขอบเขต / ตัดออก / หาแหล่งแทน |
| reviewer | ว่างไว้ให้ผู้ตรวจที่เป็นคนใส่ชื่อ |

ท้ายไฟล์สรุป (citation-register-summary.md) ต้องแยกสองกลุ่ม: citation ในเนื้อหาที่ไม่มีในรายการอ้างอิง
และรายการอ้างอิงที่ไม่ถูกอ้างในเนื้อหา

## หกสถานะ

| status | ใช้เมื่อ |
|---|---|
| verified | มีจริง metadata ตรง และรองรับข้อความในขอบเขตที่อ้าง |
| partially supported | รองรับบางส่วน ขอบเขต ประชากร หรือความมั่นใจแคบกว่าที่เขียน |
| not supported | มีจริง แต่ไม่รองรับ ผลตรงข้าม หรือถูกถอนแล้ว |
| not found | ยังหาแหล่งหรือฉบับเต็มไม่พบ บันทึกใน search_sources ว่าค้นที่ใดแล้ว |
| outdated or superseded | มีหลักฐาน มาตรฐาน หรือฉบับใหม่มาแทน |
| fabricated / phantom | ไม่มีจริงหลังตรวจหลายแหล่งทางการแล้ว |

ห้ามเปลี่ยน not found เป็น fabricated / phantom จากการค้นแหล่งเดียว โดยเฉพาะรายการภาษาไทย

## คุณภาพของชุดอ้างอิง (ใส่ใน citation-register-summary.md)

| ปัญหา | สัญญาณที่ต้องดู |
|---|---|
| พึ่งแหล่งเดียวมากเกินไป | แหล่งเดียวถูกอ้างหลายครั้ง และบางครั้งอ้างเกินกว่าที่เขียน |
| อ้างตนเองหรือกลุ่มเดียวกัน | สัดส่วนงานของผู้เขียนหรือกลุ่มเดียวกันสูง |
| ความน่าเชื่อถือ | บทความที่ถูกถอน, Wikipedia, รายงานภายในที่ตรวจสอบไม่ได้, ref ทิพย์ |
| ความใหม่ | มาตรฐานรุ่นเก่าที่มีรุ่นใหม่แทน หรือแหล่งส่วนใหญ่เก่าเมื่อเทียบกับหัวข้อ |
| ความหลากหลายและบริบท | ไม่มีงานจากบริบทของผู้วิจัย เช่น งานไทยหรือภูมิภาค |
| ขาดหลักฐานแย้ง | ข้อสรุปสำคัญอาศัยแหล่งเดียว หรือขัดกับแหล่งอื่นในรายการเดียวกัน |
| ความเรียบร้อยของรายการ | ปีผิด ขาด DOI มี citation ที่ไม่มีในรายการ หรือมีรายการที่ไม่ถูกอ้าง |

## รายการภาษาไทย

- OpenAlex ครอบคลุมวารสารไทยน้อย ค้นต่อใน ThaiJO, TCI และ ThaiLIS ก่อนตัดสิน
- พ.ศ. = ค.ศ. + 543 แปลงก่อนตัดสินว่าปีไม่ตรง
- เทียบชื่อผู้แต่งทั้งภาษาไทยและภาษาอังกฤษ ชื่อทับศัพท์มีหลายแบบ
- ไม่มี DOI ไม่ใช่สัญญาณว่าปลอม

## ห้ามเสมอ

- ห้ามแต่ง abstract, DOI หรือ metadata ที่หาไม่พบ ให้เขียนตามจริง
- ห้ามพิมพ์ OPENALEX_KEY ลงไฟล์ log หรือผลลัพธ์ใด
- ห้ามดาวน์โหลดผ่านสิทธิ์สมาชิกของมหาวิทยาลัยแบบอัตโนมัติ และห้ามใช้แหล่งที่ไม่ถูกต้องตามลิขสิทธิ์
