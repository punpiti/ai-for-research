# Module 7 — โจทย์สำรวจข้อมูลและสร้างกราฟ

ไฟล์นี้เป็น Prompt Card สำหรับกิจกรรมหลักของ Module 7 ผู้เรียนเริ่มด้วย prompt เดียว แล้วสนทนากับ AI
ต่อด้วยภาษาของตนเองได้อย่างอิสระ

## โจทย์เดียว

เปิดข้อมูล
`course-materials/module-07/examples/figure-consistency/mock-study-data.csv`
แล้วสำรวจว่า **ค่า PM2.5 เปลี่ยนอย่างไรตามพื้นที่ กลุ่ม ก่อน–หลังมาตรการ และเวลา**

ผู้เรียนเลือกมุมวิเคราะห์ วิธี และกราฟได้เอง เป้าหมายคือค้นหา 3–5 highlights ที่มีตัวเลขรองรับ
สร้างกราฟอย่างน้อยหนึ่งภาพ และเขียนข้อสรุปที่ระบุทั้งสิ่งที่ข้อมูลสนับสนุนและสิ่งที่ยังสรุปไม่ได้

## Prompt ตั้งต้นใน VS Code

```text
เปิดไฟล์ course-materials/module-07/examples/figure-consistency/mock-study-data.csv แล้วช่วยฉันสำรวจว่า PM2.5 เปลี่ยนอย่างไรตาม site, arm, period และ week ตรวจคุณภาพข้อมูลก่อน วิเคราะห์ได้อย่างอิสระ และสร้างกราฟที่เหมาะกับข้อค้นพบ ระหว่างทำให้บอกตัวเลขที่ใช้และเหตุผลที่เลือกกราฟ เมื่อฉันพอใจกับการวิเคราะห์แล้ว ให้บันทึก module-07-work/module-07-highlights.md ซึ่งมีคำถามที่สำรวจ, highlights 3–5 ข้อพร้อมหลักฐานตัวเลข, กราฟที่เลือกและเหตุผล, ข้อสรุปที่ชัดเจน, ข้อจำกัด และสิ่งที่ข้อมูลยังสรุปไม่ได้ บันทึกกราฟสุดท้าย 1–5 ภาพเป็น PNG, JPEG หรือ WebP ใน module-07-work/figures โดยใช้ชื่อไฟล์ภาษาอังกฤษที่สื่อความหมาย เริ่มจากสรุปโครงสร้างข้อมูลสั้น ๆ แล้วชวนฉันเลือกมุมที่อยากสำรวจต่อ
```

หลังจากส่ง prompt ตั้งต้น ผู้เรียนอาจขอให้ AI เปรียบเทียบมุมอื่น เปลี่ยนชนิดกราฟ ตรวจตัวเลข
หรือท้าทายข้อสรุปได้ตามความสนใจ ผู้เรียนเลือกกราฟเองหรือให้ AI เสนอได้ แต่ต้องอธิบายได้ว่ากราฟนั้นช่วยให้เห็นอะไร

## ผลลัพธ์ที่เก็บใน workspace

- `module-07-work/module-07-highlights.md`
- กราฟ 1–5 ภาพใน `module-07-work/figures/` เป็น PNG, JPEG หรือ WebP
- ไฟล์ประกอบที่ AI สร้างเพื่อให้ตรวจตัวเลขหรือเรียกผลซ้ำได้

ไฟล์ highlights ต้องมีหัวข้อ `คำถามที่สำรวจ`, `Highlights`, `กราฟที่เลือก`, `ข้อสรุป` และ
`ข้อจำกัดและสิ่งที่ยังสรุปไม่ได้` แต่ละ highlight ต้องมีตัวเลขหรือการเปรียบเทียบที่ตรวจย้อนกลับได้

## ส่งกลับเข้าสู่ระบบ

เชื่อม workspace กับ AIRR หนึ่งครั้งด้วย AIRR Key จากหน้า Module 7 แล้วส่งจาก Terminal ใน VS Code
ด้วย `tools/airr.ps1` หรือ `tools/airr.sh` ระบบส่ง `module-07-highlights.md` และกราฟใน
`module-07-work/figures/` ให้ผู้สอนตรวจ ไม่ส่งข้อมูลดิบ โค้ด หรือไฟล์อื่นใน workspace
คำสั่ง `status module-7` ใช้ดูผลตรวจและ feedback
