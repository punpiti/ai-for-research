# Module 7 Figure Consistency Audit — ชุดแบบฝึกสำหรับผู้เรียน

## ไฟล์ในชุดฝึก

- `mock-article-figure-consistency.pdf` — บทความจำลองที่ต้องตรวจเป็นเอกสารหนึ่งชิ้น
- `mock-study-data.csv` — ข้อมูลจำลอง 480 แถวที่ใช้สร้างตารางและรูปทั้งหมด
- `figure-consistency-audit-template.md` — แม่แบบเอกสารคำตอบฉบับสุดท้าย
- `module-07-submission-schema.json` — สัญญาสำหรับส่ง `module-07-highlights.md` ผ่านหน้าเว็บ

บทความนี้จงใจฝังข้อผิดพลาดเพื่อการเรียน ห้ามเปิดสคริปต์สร้างกรณีศึกษาหรือเฉลยผู้สอนก่อนส่งงาน

ไฟล์ `instructor-answer-key.md` และ `instructor-answer-deck.pptx` เป็นเอกสารผู้สอนภายใน
ไม่รวมอยู่ในชุดดาวน์โหลดของผู้เรียน

## ใช้ข้อมูลสำหรับโจทย์หลัก

โจทย์หลักให้สำรวจ `mock-study-data.csv` อย่างอิสระ สร้างกราฟ และบันทึก highlights 3–5 ข้อพร้อม
ข้อสรุปและข้อจำกัดลงใน `module-07-work/module-07-highlights.md` จากนั้นส่งไฟล์ highlights ผ่านหน้า Module 7

## กิจกรรมเสริม Figure Consistency Audit

งานนี้ต้องค้นหาความขัดแย้งที่เปลี่ยนข้อสรุปเมื่ออ่านตาราง รูป caption วิธีวิจัย และข้อความร่วมกัน
คำวิจารณ์ด้านความชอบส่วนตัวหรือความสวยงามเพียงอย่างเดียวไม่นับเป็นประเด็น

เขียนรอบแรกโดยไม่ใช้ AI จากนั้นใช้ AI เป็นผู้ตรวจคนที่สองได้ ผู้เรียนต้องตัดสินเองและระบุหน้า รูป
ตาราง คอลัมน์ หรือการคำนวณที่รองรับแต่ละประเด็น

บันทึกคำตอบกิจกรรมเสริมเป็น `module-07-figure-audit.md` ไว้ใน workspace ระบบรับงานของ Module 7
รับเฉพาะ `module-07-highlights.md` จากโจทย์หลัก
