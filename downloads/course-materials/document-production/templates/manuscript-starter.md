# Abstract

เขียนปัญหา ข้อมูล วิธี ผลหลักพร้อมตัวเลข และข้อจำกัดในย่อหน้าเดียวตามข้อกำหนด Journal A

# Introduction

อธิบายปัญหาการสรุปผลรวมเมื่อแต่ละพื้นที่อาจเปลี่ยนต่างทิศ ใช้ citation keys จาก `literature/references.bib` และแยก candidate gap ออกจาก novelty claim

# Data and Methods

รายงานว่าชุดข้อมูลจำลองมี 480 observations ครอบคลุม 3 sites, 2 arms, before/after, 16 weeks และ 5 sensors ต่อ site-arm-week ตรวจ missingness, duplicate และหน่วยก่อนวิเคราะห์

# Results

รายงานผลรวมและผลแยกพื้นที่จาก `input/analysis-summary.csv` อ้างรูปจาก `figures/pm25-before-after.png` ห้ามเลือกเฉพาะ North/Central แล้วละ South

# Discussion

อธิบายว่าความแตกต่างระหว่างพื้นที่เปลี่ยนการตีความผลรวมอย่างไร เชื่อมกับวรรณกรรมจำลองโดยไม่อ้างว่าพิสูจน์ผลของมาตรการ

# Limitations

ระบุข้อจำกัดของชุดข้อมูลจำลอง การมอบหมายมาตรการ ตัวแปรกวน repeated observations, uncertainty และรายละเอียด sensor/calibration ที่ไม่มี

# Conclusion

สรุปเฉพาะสิ่งที่ตัวเลขสนับสนุนและสิ่งที่ยังต้องตรวจเพิ่ม
