# Mock Journal B — Student Wellbeing Analytics Methods

เอกสารจำลองสำหรับ Module 8 เท่านั้น ไม่ใช่วารสารจริง

## Aims & Scope

รับงานที่เน้นวิธีวัด วิเคราะห์ และตรวจความน่าเชื่อถือของข้อมูลสุขภาวะนักศึกษา ผู้อ่านหลักคือนักวิธีวิจัย นักสถิติ และทีมประเมินผลสถาบัน

## Methods Brief

- 2,000 คำ ไม่รวม references และ appendix
- Structured abstract: Background, Methods, Results, Limitations; รวมไม่เกิน 200 คำ
- หัวข้อ: Measurement Context, Data and Design, Analysis, Results, Robustness, Limitations
- ต้องรายงาน instrument definition, missingness, uncertainty และ reproducibility note
- ใช้ numbered citations และ BibTeX
- double-anonymous review และต้องส่ง reporting checklist

## Submission Package

`main.tex`, `references.bib`, figures/tables, blinded PDF, title page แยก, reporting checklist, reproducibility note, data/code availability, ethics/consent, conflicts, funding และ AI-use disclosure

## Fit Warning for the Mock Case

เคสไม่มีข้อมูลรายบุคคล missingness record, uncertainty of the mean หรือ reproducible analysis code จึงมี conditional fit สำหรับตัวอย่างสอนเท่านั้น ต้นฉบับจริงสำหรับวารสารนี้เป็น BLOCKED จนกว่าจะมีข้อมูลและการวิเคราะห์เพิ่ม
