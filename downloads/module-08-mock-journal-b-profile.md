## Aims & Scope

รับงานที่เน้นวิธีวัด การตรวจคุณภาพ และความน่าเชื่อถือของข้อมูลสิ่งแวดล้อม ผู้อ่านหลักคือนักวิธีวิจัย นักสถิติ และทีมตรวจวัดภาคสนาม

## Methods Brief

- 2,200 คำ ไม่รวม references และ appendix
- Structured abstract: Background, Methods, Results, Limitations รวมไม่เกิน 220 คำ
- หัวข้อ: Measurement Context, Data Structure, Quality Checks, Analysis, Results, Robustness, Limitations
- ต้องรายงาน sensor definition, missingness, repeated observations, uncertainty และ reproducibility note
- ใช้ numbered citations และ BibTeX
- double-anonymous review และต้องส่ง reporting checklist

## Submission Package

`main.tex`, `references.bib`, figures/tables, blinded PDF, title page แยก, reporting checklist, reproducibility note, data/code availability, ethics, conflicts, funding และ AI-use disclosure

fit เป็นแบบมีเงื่อนไข ชุดข้อมูลฝึกมี sensor ID และ repeated weeks แต่ไม่มี calibration record หรือรายละเอียดเครื่องมือครบ จึงต้องระบุสิ่งที่ขาดเป็น BLOCKED และห้ามแต่งรายละเอียดเพิ่ม
