# Module 7 — รายการตรวจรวมไว้หน้าเดียว

ใช้เปิดคู่กับทุกกิจกรรมของ Module 7 · ทุกรายการเป็นจุดเริ่มตรวจ ไม่ใช่กฎตายตัว

## ก. งานอ่านค่า → กราฟเริ่มต้น → สิ่งที่ต้องตรวจ

จาก `module-07a-read-and-audit.ipynb` หัวข้อ 2 “ก่อนเลือกกราฟ ให้ระบุงานอ่านค่า”

| งานที่ผู้อ่านต้องทำ | จุดเริ่มต้นที่มักเหมาะ | สิ่งที่ต้องตรวจ |
|---|---|---|
| เปรียบเทียบค่าระหว่างกลุ่ม | dot/bar | baseline, order, uncertainty, n |
| ดูแนวโน้มตามเวลา | line | interval, missing time, smoothing, window |
| ดู distribution | dot/strip, histogram, ECDF, violin/box | bin/bandwidth, raw n, outliers |
| ดูความสัมพันธ์ | scatter/hexbin | overplotting, scale, confounders, causal overclaim |
| ดูองค์ประกอบของส่วนรวม | stacked bar/area | denominator, order, มากเกินไปหรือไม่ |
| ดูค่าประมาณและความไม่แน่นอน | interval/forest plot | interval type, reference, model |
| เทียบหลายกลุ่ม/หลายเวลา | small multiples | shared scale, panel order, empty panels |

## ข. กับดักกราฟสี่แบบและวิธีแก้

จาก `module-07a-read-and-audit.ipynb` หัวข้อ 4 “กราฟที่รันได้ แต่ยังใช้ไม่ได้”

| กรณี | ปัญหา | วิธีแก้ |
|---|---|---|
| 1. แกนตั้งเริ่มตรงไหน | bar ที่ตัดแกนตั้งทำให้ความต่างเล็กดูใหญ่ | bar เริ่มที่ศูนย์ หรือเปลี่ยนเป็น dot plot ถ้าต้องซูม |
| 2. แกนตั้งสองข้าง | ปรับช่วงแกนแล้วเส้นดูสัมพันธ์มากหรือน้อยได้ตามใจ | แยกเป็นสอง panel ที่ใช้แกนเวลาเดียวกัน หรือเขียนเหตุผลที่ต้องใช้สองแกน |
| 3. ช่วงเวลาที่เลือกและค่าสะสม | ตัดช่วงจนไม่เห็นจุดกลับตัว · ค่าสะสมเพิ่มต่อแม้ค่ารายปีลด | แสดงช่วงเวลาเต็ม ระบุว่าแกนตั้งเป็นค่ารายช่วงหรือค่าสะสม |
| 4. หลาย panel ฐานไม่เหมือนกัน | panel หน้าตาเหมือนกันแต่เป็น count, proportion, rate | ใช้หน่วยและตัวหารเดียวกัน หรือเขียนหน่วยกำกับทุก panel ให้ชัด |

คำตอบที่ดีไม่ใช่ “กราฟนี้หลอก” แต่ชี้ว่า baseline, scale, window, denominator หรือ aggregation ตัวใดทำให้เทียบผิด

## ค. 12 คำถามก่อนใช้กราฟ

1. เห็นข้อมูลจริงและ n หรือเห็นแค่ค่าสรุป
2. รูปแบบกราฟตรงกับสิ่งที่ผู้อ่านต้องทำไหม
3. ทุกส่วนของภาพแทนข้อมูลไหม (ไม่มีสามมิติประดับ)
4. สีมีหน้าที่ชัด และพิมพ์ขาวดำยังอ่านได้ไหม
5. colormap ตรงกับชนิดข้อมูลไหม
6. แถบความไม่แน่นอนบอกชนิดและ n ไหม
7. ข้อมูลส่วนไหนถูกคัดออก ด้วยเกณฑ์อะไร
8. กราฟแท่งเริ่มที่ศูนย์ไหม
9. ใช้แกนสองข้างโดยมีเหตุผลไหม
10. ช่วงเวลาและนิยามของแกนตั้งชัดไหม
11. ทุก panel ใช้หน่วย ตัวหาร และสเกลเดียวกันไหม
12. ตัวเลขในข้อความ ตาราง และภาพตรงกัน และไฟล์ที่ส่งออกยังอ่านได้ไหม

ข้อ 7 และ 12 ตรวจจากภาพอย่างเดียวไม่ได้ ต้องเปิดข้อมูลหรือโค้ด

## ง. Red team ก่อนส่ง 7 ข้อ

| ข้อ | ตรวจอะไร | ผ่านเมื่อ |
|---|---|---|
| 1 | แกนและ baseline | bar เริ่มที่ศูนย์ แกนสองข้างมีเหตุผลรองรับ |
| 2 | ตัวหารและหน่วย | ทุก panel ใช้ฐานเดียวกัน หน่วยครบ |
| 3 | n และข้อมูลดิบ | ระบุ n และเห็นข้อมูลจริงเมื่อ n น้อย |
| 4 | ชนิด interval | SD, SE, CI หรือ IQR เขียนไว้ในคำบรรยายภาพ |
| 5 | สีมีหน้าที่ | ยังอ่านได้เมื่อพิมพ์ขาวดำ |
| 6 | ชื่อภาพคือ claim | ไม่อ้างเกินกว่าที่ภาพแสดง |
| 7 | ตรวจย้อนกับ CSV | สุ่มอย่างน้อย 3 ค่าใน highlights แล้วหาเองจากข้อมูลต้นทาง |
