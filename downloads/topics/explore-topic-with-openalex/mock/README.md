# โฟลเดอร์ OpenAlex ของ Module 2

ทุกไฟล์ของหัวข้อ "หาข้อมูลเรื่องที่สนใจเพิ่มด้วย OpenAlex" อยู่ในโฟลเดอร์นี้เท่านั้น

| ไฟล์ | ใครสร้าง | คืออะไร |
|---|---|---|
| `topic-card.json` | คุณ (AI ช่วยเติมตัวเลข) | หัวข้อ คำถาม และจำนวนผลงาน — ส่งให้ผู้สอนตอน `AIRR submit module-2 --short` |
| `search-log.md` | AI | คำค้น ตัวกรอง URL ที่เรียก (ไม่มี key) วันที่ และจำนวนที่พบ |
| `works.json` | AI | ผลจาก OpenAlex API ที่เก็บไว้ (ต้นฉบับของรอบนี้ ห้ามแก้) |
| `excluded.md` | AI ตามที่คุณสั่ง | แหล่ง/วารสาร/ประเภทที่คัดออก พร้อมเหตุผลของคุณ |
| `refs.bib` | AI | BibTeX ของผลงานที่เก็บไว้ พร้อม abstract จาก OpenAlex เท่านั้น |
| `summaries/` | AI | สรุปจาก prompt แต่ละแบบ หนึ่งไฟล์ต่อหนึ่งแบบ |
| `prompts.md` | คุณ | prompt ที่ใช้และสิ่งที่สังเกต |

ห้ามวาง OpenAlex API key ในไฟล์ใดในโฟลเดอร์นี้ · key อยู่ใน `.airr/keys/openalex.txt` ของ workspace เท่านั้น
