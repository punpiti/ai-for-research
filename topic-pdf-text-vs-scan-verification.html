Workshop

PDF: ข้อความที่เลือกได้ ภาพสแกน และการตรวจสิ่งที่ AI อ่านกับหน้าต้นทาง

ใน workshop นี้คุณจะตรวจว่า PDF บทความจำลองเป็นข้อความที่เลือกได้หรือภาพสแกน ให้ AI ยกข้อความสองแห่งพร้อมตำแหน่ง แล้วเทียบกับหน้าเอกสารเองและบันทึกผล

ใช้เมื่อ: ก่อนให้ AI อ่านบทความใน Module 2/3/4 หรือเปิดรายงานใน Module 8

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • course-materials/module-07/examples/figure-consistency/mock-article-figure-consistency.pdf — บทความจำลอง 3 หน้า มีข้อความ รูป และตาราง เป็นข้อมูลจำลอง (ตัวติดตั้ง Module 1 วางไว้ให้ อ่านอย่างเดียว) หรือ PDF บทความ/รายงานของคุณเองที่จะใช้ในกิจกรรมปัจจุบัน
  • หมายเหตุ: บทความจำลองนี้ใช้ในกิจกรรมเสริม Figure Consistency Audit ของ Module 7 ด้วย workshop นี้ฝึกเฉพาะ การอ่านและตรวจข้อความกับหน้าต้นทาง ไม่ใช่การหาข้อผิดพลาดของบทความ

ขั้นตอน

  1. เปิด PDF แล้วเลือกหน้าที่มีข้อความและตารางหรือรูป

  2. ลองคัดลอกข้อความหนึ่งย่อหน้า (เช่น บทคัดย่อ) ไปวางในไฟล์ข้อความ ตรวจว่าลำดับข้อความตรงกับสิ่งที่เห็นบนหน้า ถ้าเลือกข้อความไม่ได้ อาจเป็นภาพสแกน ต้องใช้ OCR เพื่ออ่านข้อความจากภาพ

  3. ให้ AI อ่านข้อความที่ระบุ พร้อมบอกเลขหน้าหรือตำแหน่งที่ใช้ (ระบุ path ของ PDF และหน้าเอง)

    อ่านเฉพาะหน้าที่ฉันระบุใน PDF นี้ ยกข้อความหรือตัวเลขสองแห่งพร้อมตำแหน่งให้ฉันตรวจกลับกับหน้าเอกสาร หากเป็นภาพสแกน อ่านไม่ได้ หรือลำดับข้อความกำกวม ให้แจ้งก่อนสรุป และเก็บต้นฉบับไว้

  4. ตรวจข้อความหรือตัวเลขสองแห่งกลับกับหน้าเอกสาร รวมถึงเครื่องหมาย หน่วย และเชิงอรรถที่เกี่ยวข้อง (ตัวยก ตัวห้อย และหน่วยอย่าง µg/m³ เป็นจุดที่ข้อความที่คัดลอกหรืออ่านออกมาอาจแยกบรรทัดหรือเพี้ยนได้ ให้เทียบกับภาพหน้าเอกสาร)

  5. จดผล ลงไฟล์ module-07-work/notes/file-reading.md (สร้างใหม่ถ้ายังไม่มี หรือต่อท้ายไฟล์เดิมจากหัวข้อ CSV: หนึ่งแถวแทนอะไร ชื่อคอลัมน์ หน่วย และค่าที่ขาด): เลขหน้า/ตำแหน่ง ข้อความที่ AI ยกมา ผลเทียบ (ตรง / ไม่ตรง / ต้องตรวจจากภาพ) และข้อสรุปว่าไฟล์เป็นข้อความที่เลือกได้หรือภาพสแกน ส่วนใดต้องตรวจจากภาพ (ตาราง สมการ หน่วย)

  6. ถ้าต้องแก้รายงานที่ตนสร้าง ให้ระบุต้นฉบับที่แก้ไขได้ เช่น MD หรือ Word แล้วค่อยสร้าง PDF ใหม่ในกิจกรรมผลิตเอกสาร (Module 8)

ส่วนการเลือก template สร้าง PDF และตรวจรูปแบบเอกสารเพื่อส่งงานอยู่ใน Module 8

ตรวจก่อนจบ

ส่งงาน

  • X01 ไม่มีงานส่งแยก ประเมินจากการอ่านและตรวจไฟล์ในกิจกรรมนี้

Exploring

PDF: ข้อความที่เลือกได้ ภาพสแกน และการตรวจสิ่งที่ AI อ่านกับหน้าต้นทาง

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI อ่านเฉพาะส่วนที่ต้องใช้จาก PDF ในงานของคุณ แล้วตรวจผลกับหน้าเอกสารและสรุปข้อจำกัดของไฟล์

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้แล้ว
  • PDF ที่ใช้ในงานจริงและมีสิทธิ์ใช้กับ AI เช่น บทความที่อ้างอิง รายงานโครงการ หรือเอกสารเก่าที่เป็นภาพสแกน ถ้าเป็นไปได้ให้เลือกหน้าที่มีตาราง สมการ หน่วย หรือจัดสองคอลัมน์ (ชุดสำรอง: course-materials/module-07/examples/figure-consistency/mock-article-figure-consistency.pdf ที่ตัวติดตั้ง Module 1 วางไว้ หน้าที่ยังไม่ได้ตรวจใน workshop)

โจทย์

  1. สร้างไฟล์ output/prompts.md ในโฟลเดอร์งานของคุณ สำหรับเก็บ prompt ที่ใช้ทุกรอบ
  2. ตรวจเองก่อนว่าหน้าที่เลือกเป็นข้อความที่เลือกได้หรือภาพสแกน
  3. เขียน prompt ของตนให้ AI อ่านเฉพาะส่วนที่ต้องใช้ ยกข้อความหรือตัวเลขพร้อมตำแหน่ง และแจ้งเมื่ออ่านไม่ได้หรือกำกวม
  4. ตรวจผลกับหน้าเอกสารแล้วสรุปข้อจำกัดของไฟล์นี้สำหรับงานของตน

ข้อกำหนด

  • ไม่แก้ PDF ต้นฉบับ
  • ระบุว่าตรวจผลของ AI อย่างไร (เทียบกับภาพหน้าใด ตรงไหนต้องดูจากภาพ) และแก้อะไรเอง
