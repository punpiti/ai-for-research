Workshop

JSON: ชื่อช่อง ค่า และสถานะ true/false/null — อ่านผ่านไม่ได้แปลว่าค่าถูก

ใน workshop นี้คุณจะสร้างไฟล์ JSON บันทึกสถานะฝึกอ่านไฟล์ ให้ AI อธิบายชื่อช่องและค่า แล้วให้ AI แก้เฉพาะค่าที่คุณยืนยันจากสิ่งที่ทำจริง

ใช้เมื่อ: ต้องเปิดไฟล์สถานะหรือไฟล์ค่าตั้งต้นของเครื่องมือ

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • ควรทำ workshop CSV ของ X01 มาก่อน: ผลตรวจสองค่าที่บันทึกไว้ใน module-07-work/notes/file-reading.md ใช้ในขั้นที่ 4 (ถ้ายังไม่ได้ทำ ให้บอกผลตามจริงในขั้นที่ 4)

คำที่ใช้ใน workshop นี้

  • ชื่อช่อง (key) — ชื่อในเครื่องหมายคำพูดหน้าเครื่องหมาย : เช่น "activity"
  • ค่า — สิ่งหลัง : เป็นข้อความ ("..."), จำนวน (0), กลุ่ม ({ }) หรือสถานะ
  • true / false — จริง / เท็จ ตามความหมายของช่องนั้น
  • null — ไม่มีค่าระบุ ต่างจาก 0 และข้อความว่าง ""
  • อ่านเป็น JSON ได้ — รูปแบบถูก (คำพูดคู่ วงเล็บปีกกา จุลภาค) แต่ไม่ได้บอกว่าค่าถูกต้องตามความจริง

ขั้นที่ 1 — สร้างไฟล์ JSON ตัวอย่าง

ใน VS Code สร้างไฟล์ใหม่ module-07-work/notes/file-reading-practice.json (สร้างโฟลเดอร์ถ้ายังไม่มี) แล้ววางเนื้อหานี้ (ตัวอย่างจำลองสำหรับฝึก)

{ "activity": "file-reading-practice", "checks": { "source_opened": true, "values_verified": false }, "verified_count": 0, "review_note": null }

ตรวจ: VS Code ไม่ขีดเส้นแดงใต้บรรทัดใด (ถ้ามี แปลว่ารูปแบบผิด เช่น ขาดจุลภาคหรือคำพูด)

ขั้นที่ 2 — ให้ AI อธิบายชื่อช่องและค่า

วาง prompt นี้ แล้วระบุ path ของไฟล์ที่เพิ่งสร้าง

อธิบายชื่อช่องและค่าใน JSON นี้ก่อน ฉันจะบอกผลที่ทำจริงทีละข้อ จากนั้นแก้เฉพาะค่าที่ฉันยืนยัน คงชื่อช่องไว้ ตรวจว่าอ่านเป็น JSON ได้ และแสดงรายการเปลี่ยนให้ฉันตรวจ

ตรวจ: AI แยกได้ว่า activity เป็นข้อความ verified_count เป็นจำนวน checks เป็นกลุ่ม และ review_note เป็น null

ขั้นที่ 3 — อธิบายเองเรื่องสถานะ

เขียนหนึ่งประโยคว่าเหตุใด source_opened จึงเป็น true แต่ values_verified ยังเป็น false

ตรวจ: คำอธิบายของคุณแยก "เปิดไฟล์แล้ว" ออกจาก "ตรวจค่าแล้ว"

ขั้นที่ 4 — บอก AI ผลที่ทำจริง

ถ้าตรวจค่าจาก CSV ครบสองค่าแล้ว ให้บอก AI แก้ values_verified เป็น true และ verified_count เป็น 2 ถ้ายังไม่ครบ ให้บอกผลตามจริง (เช่น ตรวจได้ 1 ค่า) และไม่เปลี่ยน values_verified เป็น true

ตรวจ: ค่าที่ AI แก้ตรงกับจำนวนที่คุณตรวจจริง

ขั้นที่ 5 — เปิดไฟล์ที่แก้แล้ว

เปิด JSON ดูทีละบรรทัด และให้ AI ตรวจว่ายังอ่านเป็น JSON ได้

ตรวจ: ชื่อช่องทั้งหมดเหมือนขั้นที่ 1 มีเฉพาะ values_verified และ verified_count ที่เปลี่ยน และไฟล์ยังอ่านเป็น JSON ได้

ขั้นที่ 6 — แยก "รูปแบบผ่าน" ออกจาก "ค่าถูก"

เขียนหนึ่งประโยคว่าการที่ไฟล์อ่านเป็น JSON ได้ ยืนยันอะไรได้ และยืนยันอะไรไม่ได้

ตรวจ: คำตอบบอกว่ารูปแบบผ่านไม่ได้แปลว่าค่าในไฟล์ตรงกับสิ่งที่ทำจริง

Exploring

JSON: ชื่อช่อง ค่า และสถานะ true/false/null — อ่านผ่านไม่ได้แปลว่าค่าถูก

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI อธิบายไฟล์ JSON ในงานของคุณ แล้วแก้เฉพาะค่าที่คุณยืนยันจากสิ่งที่ทำจริง

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้แล้ว
  • ไฟล์ JSON ที่เกี่ยวกับงานของคุณ (ไม่มี key หรือข้อมูลส่วนบุคคล) เช่น
    • ไฟล์ค่าตั้งต้นของเครื่องมือ หรือผลส่งออกจากระบบที่ใช้ในงานวิจัย
    • .vscode/extensions.json ใน workspace (รายการส่วนขยายที่ตัวติดตั้งแนะนำ)
    • ชุดสำรอง: module-07-work/notes/file-reading-practice.json ที่คุณสร้างใน workshop

โจทย์

  1. ทำสำเนาไฟล์ก่อนแก้ไว้เทียบ และสร้างไฟล์ output/prompts.md ในโฟลเดอร์งานของคุณสำหรับเก็บ prompt ที่ใช้ทุกรอบ
  2. เขียน prompt ของตนให้ AI อธิบายชื่อช่อง ชนิดค่า และกลุ่มข้อมูล แล้วแก้เฉพาะค่าที่คุณยืนยันจากสิ่งที่ทำจริง
  3. ระบุอย่างน้อยหนึ่งช่องที่ตอนนี้ยังยืนยันไม่ได้ และตัดสินว่าควรคงค่า ใช้ false หรือ null พร้อมเหตุผล

ข้อกำหนด

  • ระบุว่าตรวจผลของ AI อย่างไร: ตรวจรูปแบบ (อ่านเป็น JSON ได้) และตรวจความจริงของค่าแยกกัน และแก้อะไรเอง
  • ถ้าเป็นไฟล์สถานะส่งงานจริง ห้ามตั้งค่าเป็น true/completed สำหรับสิ่งที่ยังไม่ได้ทำ
