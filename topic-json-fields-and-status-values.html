Workshop

JSON: ชื่อช่อง ค่า และสถานะ true/false/null — อ่านผ่านไม่ได้แปลว่าค่าถูก

ใน workshop นี้คุณจะสร้างไฟล์ JSON บันทึกสถานะฝึกอ่านไฟล์ ให้ AI อธิบายชื่อช่องและค่า แล้วให้ AI แก้เฉพาะค่าที่คุณยืนยันจากสิ่งที่ทำจริง

ใช้เมื่อ: จำเป็นต้องเปิดไฟล์สถานะหรือค่าตั้งต้น

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • ควรทำ workshop csv-rows-columns-units มาก่อน: ผลตรวจค่าสองค่าจาก CSV ที่บันทึกไว้ใน module-07-work/notes/file-reading.md ใช้ในขั้นที่ 4 (ถ้ายังไม่ได้ทำ ให้บอกผลตามจริงในขั้นที่ 4)

ขั้นตอน

  1. สร้างไฟล์ JSON ตัวอย่าง ใน VS Code สร้างไฟล์ใหม่ module-07-work/notes/file-reading-practice.json (สร้างโฟลเดอร์ถ้ายังไม่มี) แล้ววางเนื้อหานี้ (ตัวอย่างจำลอง บันทึกสถานะฝึกอ่านไฟล์ ไม่ใช่ไฟล์ส่งงาน AIRR)

    { "activity": "file-reading-practice", "checks": { "source_opened": true, "values_verified": false }, "verified_count": 0, "review_note": null }
    • activity เป็นข้อความ · verified_count เป็นจำนวน · checks รวมสถานะย่อย
    • true = จริง false = เท็จ ตามความหมายของช่องนั้น · null = ไม่มีค่าระบุ ต่างจาก 0 และข้อความว่าง ""
    • ชื่อช่องและข้อความใช้เครื่องหมายคำพูดคู่ วงเล็บปีกกาครอบกลุ่ม จุลภาคคั่นรายการ

  2. ให้ AI อธิบายชื่อช่องและค่า วาง prompt นี้ (ระบุ path ของไฟล์ที่เพิ่งสร้าง)

    อธิบายชื่อช่องและค่าใน JSON นี้ก่อน ฉันจะบอกผลที่ทำจริงทีละข้อ จากนั้นแก้เฉพาะค่าที่ฉันยืนยัน คงชื่อช่องไว้ ตรวจว่าอ่านเป็น JSON ได้ และแสดงรายการเปลี่ยนให้ฉันตรวจ

  3. อธิบายเอง ว่าเหตุใด source_opened จึงเป็น true แต่ values_verified ยังเป็น false

  4. บอก AI ผลที่ทำจริง ถ้าตรวจค่าจาก CSV ครบสองค่าแล้ว (จาก workshop csv-rows-columns-units) ให้บอก AI แก้สถานะเป็น true และจำนวนเป็น 2 ถ้ายังตรวจไม่ครบสองค่า ให้บอกผลตามจริง (เช่น ตรวจได้ 1 ค่า) และไม่เปลี่ยน values_verified เป็น true

  5. เปิด JSON ที่แก้แล้ว ตรวจว่าชื่อช่องคงเดิม และมีเฉพาะค่าที่ได้รับการยืนยันเปลี่ยนไป

  6. ให้ AI หรือโปรแกรมตรวจว่าไฟล์อ่านเป็น JSON ได้ แล้วตอบเองว่า "ตรวจรูปแบบผ่าน" ยังไม่ได้ยืนยันอะไรเกี่ยวกับความถูกของค่า

ตรวจก่อนจบ

ส่งงาน

  • X01 ไม่มีงานส่งแยก ไฟล์สถานะจริงของโมดูลอื่น (เช่น module-01-work/output/module-1-progress.json) ให้แก้ตามจริงแล้วส่งตามขั้นตอนของโมดูลนั้น: ให้ AI รันเครื่องมือ AIRR check → ยืนยัน → submit

Exploring

JSON: ชื่อช่อง ค่า และสถานะ true/false/null — อ่านผ่านไม่ได้แปลว่าค่าถูก

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI อธิบายไฟล์ JSON ในงานของคุณ แล้วแก้เฉพาะค่าที่คุณยืนยันจากสิ่งที่ทำจริง

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้แล้ว
  • ไฟล์ JSON ที่เกี่ยวกับงานของคุณ (ไม่มี key หรือข้อมูลส่วนบุคคล) เช่น
    • module-01-work/output/module-1-progress.json (สร้างด้วยคำสั่ง init ใน Module 1)
    • ไฟล์ค่าตั้งต้นของเครื่องมือ หรือผลส่งออกจากระบบที่ใช้ในงานวิจัย
    • ชุดสำรอง: module-07-work/notes/file-reading-practice.json ที่คุณสร้างใน workshop

โจทย์

  1. ทำสำเนาไฟล์ก่อนแก้ไว้เทียบ และสร้างไฟล์ output/prompts.md ในโฟลเดอร์งานของคุณสำหรับเก็บ prompt ที่ใช้ทุกรอบ
  2. เขียน prompt ของตนให้ AI อธิบายชื่อช่อง ชนิดค่า และกลุ่มข้อมูล แล้วแก้เฉพาะค่าที่คุณยืนยันจากสิ่งที่ทำจริง
  3. ระบุอย่างน้อยหนึ่งช่องที่ตอนนี้ยังยืนยันไม่ได้ และตัดสินว่าควรคงค่า ใช้ false หรือ null พร้อมเหตุผล

ข้อกำหนด

  • ระบุว่าตรวจผลของ AI อย่างไร: ตรวจรูปแบบ (อ่านเป็น JSON ได้) และตรวจความจริงของค่าแยกกัน และแก้อะไรเอง
  • ถ้าเป็นไฟล์สถานะส่งงานจริง ห้ามตั้งค่าเป็น true/completed สำหรับสิ่งที่ยังไม่ได้ทำ
