Workshop

จาก highlights สู่ย่อหน้า: ข้อตกลงของย่อหน้าและการตรวจย้อนทุกประโยค

ใน workshop นี้คุณจะกรอกข้อตกลงของย่อหน้า 2 ชุด (Results และ Limitations) ลงไฟล์ที่คุณสร้าง ให้ AI เรียบเรียงเป็นย่อหน้าใน source/manuscript.md แล้วตรวจย้อนทุกประโยคกับข้อตกลงและ CSV

ใช้ผล PM2.5 จำลองชุดเดียวกับ Module 7 (480 แถว ข้อมูลสมมติ) ถ้ามาจาก Module 7 ใช้ highlights ของตัวเองได้ ถ้าเริ่มที่หัวข้อนี้ใช้ฉบับตัวอย่าง

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • ติดตั้ง Module 8 แล้ว ตัวติดตั้งวางไฟล์เหล่านี้ไว้ให้:
    • module-08-work/input/module-07-highlights.md — highlights จาก Module 7 ของคุณ (หรือฉบับตัวอย่าง ถ้าเริ่มที่ Module 8)
    • module-08-work/input/analysis-summary.csv — ค่าเฉลี่ยรายพื้นที่/กลุ่ม/ช่วง สำหรับตรวจตัวเลข
    • module-08-work/source/manuscript.md — ต้นฉบับเริ่มต้นที่มีหัวข้อ Results และ Limitations แล้ว (ใต้หัวข้อยังเป็นคำแนะนำ)
    • module-08-work/figures/pm25-before-after.png

คำที่ใช้ใน workshop นี้

  • paragraph contract — ข้อตกลงที่ล็อก statement, evidence, limitation และสิ่งที่ห้ามเพิ่มก่อนให้ AI เขียน
  • reverse check — การตรวจย้อนทุกประโยคกลับไปยังช่องในข้อตกลงและไฟล์หลักฐาน
  • supported / revise / remove — สถานะว่าประโยคมีหลักฐาน ต้องแก้ หรือควรลบ
  • ถ้อยคำเชิงเหตุและผล — คำที่บอกว่าเหตุหนึ่งทำให้เกิดผล ซึ่งข้อมูลเชิงสังเกตชุดนี้ยังรองรับไม่ได้

ข้อตกลงของย่อหน้า (สิบช่อง)

Section/purpose: Statement: Evidence and exact numbers: Figure/table/citation references: Explanation supported by evidence: Alternative explanation or limitation: Uncertainty and scope: Terms that must remain unchanged: Claims that must not be added: Target length and tone:

ขั้นตอน

  1. ตรวจตัวเลขก่อนกรอก (3 นาที) เปิด input/module-07-highlights.md และ input/analysis-summary.csv ตรวจว่าตัวเลขใน highlights ตรงกับ CSV เมื่อปัดสองตำแหน่ง เช่น แถว All,Intervention,Before = 37.018 และ All,Intervention,After = 34.357 → 37.02 → 34.36 µg/m³; แถว South,Intervention,Before/After = 29.224 → 34.560 → 29.22 → 34.56 µg/m³

    ตรวจ: ตัวเลขรวมและ South ตรงกับ CSV เมื่อปัดสองตำแหน่ง

  2. สร้างไฟล์ข้อตกลงและกรอกชุดที่ 1 (Results) สร้าง module-08-work/source/paragraph-contracts.md (ไฟล์ทำงานของคุณ) คัดลอกสิบช่องด้านบนลงไป แล้วกรอกเอง

    ช่อง ตัวอย่าง
    Section/purpose Results — รายงานผลรวมและผลแยกพื้นที่
    Statement ค่าเฉลี่ยรวมของกลุ่ม Intervention ลดลง แต่ไม่ลดทุกพื้นที่
    Evidence รวม 37.02 → 34.36 µg/m³; South 29.22 → 34.56 µg/m³
    Figure reference figures/pm25-before-after.png
    Limitation ข้อมูลเชิงสังเกต ไม่มีการมอบหมายมาตรการ
    Claims that must not be added ถ้อยคำเชิงเหตุและผล เช่น “มาตรการทำให้ลดลง”

    เติมเองจาก highlights: ตัวเลขของ comparison (37.64 → 38.32), North (44.42 → 35.50), Central (37.41 → 33.01), จำนวน observations ต่อกลุ่ม และช่อง Uncertainty and scope / Target length and tone

    ตรวจ: ข้อตกลง Results ครบสิบช่องและคงทั้งผลรวมกับผลแยก South

  3. กรอกข้อตกลงชุดที่ 2 (Limitations) ในไฟล์เดียวกัน ใช้ข้อความในส่วน “ข้อจำกัด” ของ highlights เป็น Evidence: ชุดข้อมูลจำลองไม่มีรายละเอียดการสุ่ม การมอบหมายมาตรการ ตัวแปรกวน หรือแบบจำลอง uncertainty จึงรองรับการรายงานเชิงพรรณนา ไม่รองรับข้อสรุปเชิงเหตุ ลำดับที่เหมาะ: ข้อจำกัด → ผลต่อการตีความ → สิ่งที่ยังสรุปไม่ได้

    ตรวจ: ข้อตกลง Limitations ครบสิบช่องและระบุชัดว่าข้อมูลไม่รองรับข้อสรุปเชิงเหตุ

  4. ส่ง prompt ให้ AI เรียบเรียง (หนึ่งครั้งต่อหนึ่งข้อตกลง) AI จะวางย่อหน้าใต้หัวข้อ Results ใน source/manuscript.md

    อ่านข้อตกลงของย่อหน้าชุดที่ 1 ใน module-08-work/source/paragraph-contracts.md เขียนหนึ่งย่อหน้าจากข้อตกลงของย่อหน้านี้เท่านั้น เริ่มด้วย statement เชื่อม evidence และคำอธิบายตามลำดับ รักษาตัวเลข หน่วย ทิศทาง ความไม่แน่นอน และ reference marker ทุกจุด ระบุ limitation ตามที่ให้ ห้ามเพิ่ม mechanism, citation, result, ถ้อยคำเชิงเหตุและผล หรือการขยายผลที่ไม่มีในข้อตกลง หากข้อมูลไม่พอให้แทรก [ข้อมูลไม่พอ: ...] แทนการเดา วางย่อหน้าใต้หัวข้อ Results ใน module-08-work/source/manuscript.md โดยไม่แก้หัวข้ออื่น

    ทำซ้ำกับชุดที่ 2 โดยวางใต้หัวข้อ Limitations

    ตรวจ: AI แก้เฉพาะ Results และ Limitations และไม่เพิ่มตัวเลข citation หรือกลไกนอกข้อตกลง

  5. ส่ง prompt ให้ AI ทำตารางตรวจย้อนทุกประโยค AI จะตอบเป็นตารางในหน้าแชต โดยไม่แก้ไฟล์

    แยกย่อหน้าใต้หัวข้อ Results และ Limitations ใน module-08-work/source/manuscript.md ออกเป็นรายประโยค ทำตาราง: ประโยค | ช่องในข้อตกลงที่รองรับ | ตัวเลขในประโยคตรงกับ input/analysis-summary.csv หรือไม่ | สถานะ supported / revise / remove ชี้คำที่เพิ่มความมั่นใจเกินหลักฐาน เช่น พิสูจน์ ทำให้เกิด อย่างชัดเจน ใช้ได้ทั่วไป ห้ามแก้ manuscript.md เอง ให้รายงานแล้วหยุดรอ

    ตรวจ: ตารางมีหนึ่งแถวต่อหนึ่งประโยคและระบุช่องในข้อตกลงที่รองรับ

  6. ตรวจตารางของ AI ด้วยตัวเองแล้วแก้ เปิดข้อตกลงและ CSV เทียบอย่างน้อยทุกประโยคที่มีตัวเลข แล้วแก้หรือลบประโยคที่ไม่มีช่องรองรับใน source/manuscript.md ด้วยตัวเอง

    ตรวจ: ไม่มีประโยค revise/remove ค้าง และไฟล์ input ไม่ถูกแก้

ลำดับย่อหน้าตามส่วนของบทความ (อ้างอิง)

ส่วน ลำดับที่เหมาะสม สิ่งที่ต้องระวัง
Results ผล → ตัวเลข/รูป/ตาราง → การเปรียบเทียบ → ความไม่แน่นอน ไม่อธิบายกลไกเกินที่ผลแสดง
Discussion ความหมาย → เชื่อมผล → คำอธิบาย/citation → ข้อจำกัด → การนำไปใช้ ไม่เปลี่ยนความสัมพันธ์เป็นเหตุและผล
Introduction ปัญหา → ผลกระทบ → หลักฐานจากวรรณกรรม → gap → วัตถุประสงค์ ไม่แต่ง gap หรือ citation
Methods วัตถุประสงค์ → ขั้นตอน/พารามิเตอร์ → เหตุผล → รายละเอียดที่ทำซ้ำได้ ไม่เติมขั้นตอนที่ไม่ได้ทำจริง
Conclusion ข้อสรุปที่มีหลักฐาน → ประโยชน์ → ขอบเขต/ขั้นต่อไป ไม่เพิ่มผลใหม่หรือขยายประชากร
