Workshop 1

นำเข้าหลักฐานหลายรูปแบบ แล้วดูคำตอบรอบแรกของ AI

หัวข้อนี้ไม่มีไฟล์ใน mock/ เพราะใช้ชุดของโมดูลโดยตรง สำเนาสำหรับผู้สอน: downloads/module-02-food-evidence.zip และไฟล์ที่แตกแล้วใน downloads/module-02-food-evidence/ -->

ใน workshop นี้คุณจะให้ AI ตรวจและแตกชุดหลักฐานอาหารของ Module 2 โดยไม่แก้ต้นฉบับ แล้วถามคำถามร่วมหนึ่งรอบเพื่อเก็บคำตอบรอบแรกของ AI ไว้เปรียบเทียบ

ชุดหลักฐานเป็นกรณีสมมติ ข้อมูล ชื่อบุคคล และรีวิวสร้างขึ้นเพื่อการสอน ไม่มีข้อมูลจริงของใคร

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • ไฟล์ module-02-work/input/original/module-02-food-evidence.zip (ยังไม่แตกไฟล์) — ตัวติดตั้ง Module 1 วางไว้ให้ถ้าตอนติดตั้งเห็น PRACTICE_FILES_READY ถ้ายังไม่มี ให้ดาวน์โหลดจากหน้า Module 2 (โหลดผ่าน API ของโมดูล) แล้ววางไว้ที่ตำแหน่งนี้

คำถามร่วม

มื้อข้าวไข่เจียวเหมาะกับนักศึกษาที่มีงบไม่เกิน 80 บาท มีเวลา 30 นาที และต้องการอิ่มถึง 16:00 หรือไม่

ขั้นตอน

ทำทีละ Prompt แล้วหยุดดูผลก่อนไปขั้นต่อไป

  1. Prompt เริ่ม — เปิดชุดที่เตรียมให้ สั่ง AI

    ใช้ module-02-food-evidence.zip ใน module-02-work/input/original/ ตรวจรายการและแตกไฟล์อย่างปลอดภัยโดยไม่เขียนทับต้นฉบับ ถ้าไม่พบ ZIP ให้ถามฉันก่อน แสดงรายการไฟล์ที่อ่านได้และอ่านไม่ได้ แล้วหยุดรอ ยังไม่ตอบเรื่องอาหาร

    AI จะแตกไฟล์ไว้ในโฟลเดอร์ module-02-work/input/original/module-02-food-evidence/ และแสดงรายการไฟล์ในแชต สังเกต: AI พบไฟล์อะไรบ้าง ถ้าอ่านไฟล์ไม่ได้ บอกตรง ๆ หรือข้ามไปโดยไม่บอก

  2. เปิดโฟลเดอร์ที่เพิ่งแตก แล้วเทียบกับรายการที่ควรมี 9 ไฟล์: 01-lunch-brief-th.pdf, 02-menu-observations.xlsx, 03-omelette-recipe-bilingual.docx, 04-lunch-tray.png, 05-canteen-reviews.html, 06-web-source.txt, 07-mock-nutrition.csv, 08-example-meal-card.md, README.md อ่านตารางนี้ประกอบ ว่าไฟล์แต่ละชนิดบอกอะไรได้และไม่ได้

    ไฟล์ สิ่งที่บอก สิ่งที่บอกไม่ได้
    PDF ประกาศร้าน รายการอาหาร ราคาเริ่มต้น เวลาเปิด คำว่า “อิ่มนาน” “อิ่มนาน” ไม่มีนิยามหรือผลวัด
    Excel ข้อมูลสังเกต ราคา เวลารอ คะแนนความหิว–อิ่ม บันทึกสองภาษา มีค่าที่ขาดหนึ่งช่อง
    Word สูตรสองภาษา ส่วนประกอบของสูตร น้ำหนักข้าว และน้ำมันที่เหลือหลังทอด
    ภาพถาดอาหาร สิ่งที่มองเห็นบนถาด ราคา คุณค่าทางอาหาร รสชาติ ความอิ่ม
    เว็บไซต์รีวิว คำบอกเล่าของผู้รีวิวสองวัน (มีทั้ง URL จริงและสำเนา HTML) เนื้อหาบนเว็บอาจเปลี่ยนภายหลัง
    CSV โภชนาการ ตัวเลขจำลองสำหรับฝึกอ่านตาราง ไม่ใช่ค่าที่วัดจากอาหารจริง

    จุดที่ต้องสังเกต: PDF ระบุราคาเริ่มต้น 55 บาท แต่รีวิวหนึ่งรายจ่าย 60 บาทเพราะเพิ่มข้าว เวลารอมีทั้ง 8 และ 18 นาที และผู้รีวิวสองรายหิวอีกครั้งคนละเวลา ความต่างเหล่านี้อาจเกิดจากวัน ปริมาณ และบุคคล ห้ามเลือกตัวเลขหนึ่งค่าแล้วใช้เป็นคำตอบสากล

  3. Prompt 1 — ถามสั้น ๆ สั่ง AI

    อ่านชุดอาหารที่เตรียมให้ แล้วสรุปว่าข้าวไข่เจียวมื้อนี้เหมาะกับคนงบ 80 บาท และทำให้อิ่มถึง 16:00 หรือไม่ ตอบสั้น ๆ เก็บคำตอบนี้ไว้เปรียบเทียบรอบต่อไป

    AI จะตอบในแชต — นี่คือ คำตอบรอบแรก เก็บไว้ (ไม่ปิดแชตนี้ หรือคัดลอกเก็บไว้เอง) เพื่อใช้ในกิจกรรม evidence-levels-source-tracing สังเกต: มีคำตอบไหนระบุที่มา มีข้อไหนฟันธงทั้งที่ยังไม่มีข้อมูล ยังไม่ต้องตัดสินว่าคำตอบถูกหรือผิด เป้าหมายคือเห็นพฤติกรรมตามธรรมชาติของ AI เมื่อไม่กำหนดกติกาเรื่องหลักฐาน

  4. (ไม่บังคับ — ขยายเวลา/ทำหลังเรียน) Prompt แรกฉบับเต็ม — นำเข้าพร้อม inventory และรายงานนำเข้า ใช้แทน Prompt เริ่มเมื่อมีเวลา (คัดจากหน้า Module 2 แบบฝึกเต็ม ขั้น 01) Prompt นี้ใช้บริหารจัดการข้อมูล ยังไม่ให้ AI ตอบคำถามเรื่องอาหาร ถ้าแตกไฟล์ไปแล้วในขั้นที่ 1 AI จะรายงานว่าปลายทางมีอยู่แล้วและถามคุณก่อน

    งาน: รับและจัดชุดข้อมูล Module 2 โดยยังไม่วิเคราะห์คำถามเรื่องอาหาร หา module-02-work/input/original/module-02-food-evidence.zip หากไม่พบให้หยุดและบอกฉัน ห้ามค้นทั้งเครื่อง แสดงรายการไฟล์ใน ZIP และตรวจว่า path ภายในไม่เขียนออกนอกโฟลเดอร์ปลายทาง แตกไฟล์ไปที่ module-02-work/input/original/module-02-food-evidence/ โดยไม่ลบ ZIP และไม่เขียนทับไฟล์เดิม หากปลายทางมีอยู่แล้วให้รายงานและถามก่อน สร้าง inventory ที่ระบุชื่อไฟล์ ชนิดไฟล์ ขนาด ภาษา และ SHA-256 พร้อมตรวจว่ามี PDF, XLSX, DOCX, PNG, HTML, TXT และ README ครบ อ่าน README ก่อน แล้วใช้เครื่องมือใน Workspace สร้างสำเนาที่ค้นได้ไว้ใน module-02-work/input/markdown/module-02-food-evidence/ อ่าน 06-web-source.txt แล้วดึงเฉพาะ live_url ที่กำหนด หากเข้าถึงได้ให้เก็บสำเนาแบบลงวันที่ พร้อม final URL, เวลาเข้าถึง, HTTP status, content type และ SHA-256 แล้วเปรียบเทียบกับ 05-canteen-reviews.html หากเข้าไม่ได้ให้ใช้สำเนาเดิมและบันทึกว่ายังไม่ได้ตรวจเว็บจริง ห้ามค้นเว็บเรื่องอาหารเพิ่มเติม สำหรับ Excel ให้เก็บชื่อ sheet หัวตาราง ชนิดข้อมูล และค่าที่ขาด สำหรับ Word/PDF ให้เก็บหัวข้อและตำแหน่ง สำหรับภาพให้แยกสิ่งที่มองเห็นออกจากสิ่งที่ภาพยืนยันไม่ได้ สำหรับ HTML ให้เก็บหัวข้อ ภาษา URL และเวลาที่เข้าถึง สร้าง module-02-work/input/markdown/module-02-food-evidence/import-report.md ระบุวิธีอ่านแต่ละไฟล์ ผลดึงเว็บ ความต่างระหว่างหน้าเว็บกับสำเนา สิ่งที่สูญหาย คำเตือน และจุดที่ฉันควรเปิดเทียบกับต้นฉบับ กติกา: ห้ามแก้ ลบ หรือเขียนทับไฟล์ต้นฉบับ ห้ามติดตั้งโปรแกรมเพิ่มก่อนตรวจเครื่องมือที่ Workspace มีอยู่ ยังไม่ตอบว่าควรเลือกมื้อข้าวไข่เจียวหรือไม่ เมื่อเสร็จ ให้แสดง inventory รายชื่อไฟล์ที่สร้าง และรอฉันตรวจ import-report.md

    AI จะสร้างสำเนาที่ค้นได้และ module-02-work/input/markdown/module-02-food-evidence/import-report.md สังเกต: เปิด import-report.md แล้วเทียบกับต้นฉบับอย่างน้อยหนึ่งไฟล์ต่อชนิด เช่น ค่าที่ขาดใน Excel ถูกรายงานหรือไม่ และบันทึกว่าใช้เว็บจริงหรือสำเนา fallback เหตุที่ต้องบันทึก URL วันที่เข้าถึง และรุ่นที่ใช้: เนื้อหาบนเว็บอาจเปลี่ยนภายหลัง

โจทย์

  4. เขียน prompt สั้นถามคำถามของตนเองหนึ่งรอบ โดยยังไม่กำหนดกติกาหลักฐาน แล้วเก็บคำตอบไว้เป็นรอบแรก
  5. เปิดต้นฉบับเองแล้วเขียนตารางสั้น ๆ ใน prompts.md: ไฟล์ | ชนิด | บอกอะไรได้ | บอกอะไรไม่ได้

L1–L4: บอกว่าข้อความเชื่อได้แค่ไหน

ระดับ ความหมาย ต้องมี
L1 พบโดยตรง ตัวเลข วันที่ คำพูด หรือข้อความที่อยู่ในต้นฉบับ ชื่อไฟล์และตำแหน่ง
L2 ความเห็นในต้นฉบับ การตีความหรือข้อสรุปของผู้เขียนเอกสาร ชื่อไฟล์และตำแหน่ง
L3 การสังเคราะห์ ข้อสังเกตที่เชื่อมจากหลายเอกสาร อย่างน้อยสองแหล่ง และมนุษย์ตรวจเหตุผล
L4 ยังไม่มีหลักฐาน คำตอบใหม่ การคาดการณ์ หรือสาเหตุที่เอกสารพิสูจน์ไม่ได้ ระบุว่ายังไม่ทราบ หรือต้องค้นเพิ่ม

ตัวอย่างจากชุดนี้: คำว่า “อิ่มนาน” ใน PDF เป็นคำของผู้ขาย ไม่มีนิยามหรือผลวัด; ตัวเลขใน 07-mock-nutrition.csv เป็นข้อมูลแต่งขึ้นเพื่อการสอน (คอลัมน์ evidence_status = fictional teaching values not measured)

ขั้นตอน

  1. อ่านคำตอบรอบแรกอีกครั้ง แล้วจดคร่าว ๆ ว่าข้อความไหนน่าจะเป็น L1, L2, L3 หรือ L4 (ไม่ต้องละเอียด ใช้เทียบกับขั้นถัดไป)

  2. Prompt 2 — เพิ่มกติกาเรื่องหลักฐาน สั่ง AI

    ตอบคำถามเดิมอีกครั้ง ใช้เฉพาะไฟล์ในชุดอาหาร แสดงตารางสั้น ๆ: ข้อสรุป | ไฟล์และตำแหน่งที่รองรับ | สิ่งที่ยังตอบไม่ได้ แยกข้อมูลในสูตร ตาราง และสิ่งที่เห็นในภาพ ตัวเลขใน 07-mock-nutrition.csv เป็นข้อมูลจำลอง ไม่ใช่ค่าจากอาหารจริง ห้ามเดาข้อมูลที่ขาด เทียบกับคำตอบรอบแรกว่ามีข้อไหนที่ต้องแก้หรือยังเหมือนเดิม

    AI จะแสดง ตารางข้อสรุป ในแชต ซึ่งขั้นต่อไปใช้ตรวจ

  3. เทียบตารางข้อสรุปกับรอบแรก

    • ที่มาชัดขึ้นหรือไม่ (มีชื่อไฟล์และตำแหน่งจริงไหม)
    • ข้อความเรื่องความอิ่มและตัวเลขโภชนาการเปลี่ยนอย่างไร ตัวเลขโภชนาการถูกระบุว่าเป็นข้อมูลจำลองไหม
    • ราคา 55/60 บาท และเวลารอ 8/18 นาที ถูกเขียนเป็นช่วงหรือเงื่อนไข หรือถูกเลือกเป็นตัวเลขเดียว

  4. สุ่มเปิดต้นฉบับ อย่างน้อยสองแถวของตาราง แล้วตรวจว่าไฟล์และตำแหน่งที่ AI อ้างมีข้อความนั้นจริง

  5. ถ้ายังเดา ให้สั่งแก้ — ชี้ข้อนั้น บอก AI ว่าแถวใดไม่มีหลักฐานในไฟล์ที่อ้าง และขอให้ย้ายไปช่อง “สิ่งที่ยังตอบไม่ได้”

  6. จดข้อสังเกตสั้น ๆ ว่ารอบสองต่างจากรอบแรกอย่างไร รายงานผลตามจริง: ไม่กำหนดว่ารอบสองต้องดีขึ้นเสมอ ถ้าไม่ดีขึ้นให้บันทึกตามที่เกิด

ตรวจก่อนจบ

ส่งงาน

  • หัวข้อนี้ยังไม่ส่งแยก ทำหัวข้อ สร้างบัตรสรุปจากหลักฐาน แล้วสั่งย่อโดยตัวเลข หน่วย และข้อจำกัดไม่หาย ต่อ แล้วส่งตามขั้นส่งงานของ Module 2 (ให้ AI รันเครื่องมือ AIRR check → ยืนยัน → submit)

L1–L4 และ Prompt ที่บังคับให้ระบุที่มา

ในโจทย์เปิดนี้คุณจะเขียน prompt รอบสองเองให้ AI ระบุไฟล์และตำแหน่ง แล้วจัด L1–L4 ด้วยตนเองหลังเปิดต้นฉบับ จนได้ตารางระดับหลักฐานและผลเทียบรอบแรกกับรอบสอง

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ชุดไฟล์ คำถาม และคำตอบรอบแรกจากโจทย์เปิดของ multiformat-evidence-intake (หรือชุดสำรอง module-02-work/input/original/module-02-food-evidence/ จาก workshop พร้อมคำถามใหม่ของตนเอง)
  • module-02-work/output/prompts.md ที่คุณสร้างไว้ในโจทย์เปิดก่อนหน้า (ถ้ายังไม่มี ให้สร้างเองตอนเริ่ม)

โจทย์

  1. เขียน prompt รอบสองเองที่มีอย่างน้อย: ขอบเขตไฟล์ที่ใช้ได้ รูปแบบคำตอบ วิธีระบุไฟล์และตำแหน่ง และกติกาเมื่อไม่พบข้อมูล
  2. ถ้าชุดของคุณมีข้อมูลจำลอง ข้อมูลประมาณ หรือข้อมูลที่ยังไม่ยืนยัน ให้ prompt บอก AI ว่าข้อมูลใดเป็นแบบนั้น
  3. เลือกข้อความสำคัญจากคำตอบรอบสอง 4–6 ข้อ แล้ว จัด L1–L4 ด้วยตนเอง หลังเปิดต้นฉบับ
  4. เขียนตารางใน prompts.md: ข้อความ | ระดับ L1–L4 (ผู้เรียนจัด) | ไฟล์และตำแหน่ง | เหตุผล

ข้อกำหนด

  • เก็บ prompt ที่ใช้ทุกรอบไว้ใน module-02-work/output/prompts.md
  • ระบุว่าตรวจผลของ AI อย่างไร (เปิดไฟล์ใด ตรวจตำแหน่งใด) และแก้อะไรเอง
  • เทียบรอบแรกกับรอบสองด้วยจำนวนข้อความที่ตรวจย้อนได้ และข้อความที่ไม่มีหลักฐาน รายงานตามจริงแม้ไม่ดีขึ้น
  • ถ้าแหล่งให้ค่าต่างกัน ห้ามเลือกตัวเลขเดียวเป็นคำตอบสากล ให้ระบุช่วงหรือเงื่อนไข
