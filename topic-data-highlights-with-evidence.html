Workshop 1

หา 3–5 highlights จากข้อมูลที่มีตัวเลขรองรับ

ใน workshop นี้คุณจะสำรวจข้อมูล PM2.5 จำลองกับ AI เลือกกราฟ 1–5 ภาพเก็บใน module-07-work/figures/ และเขียน highlights 3–5 ข้อที่มีตัวเลขรองรับลงไฟล์ module-07-work/module-07-highlights.md ซึ่งเป็นงานส่งของ Module 7 และเป็น input ของ Module 8

ทำตามได้ครบด้วยข้อมูล PM2.5 จำลองของบทเรียน (ไม่มีข้อมูลจริงของใคร) ไม่ต้องสร้าง mock เพิ่ม และใช้ทุกอย่างจากหัวข้อก่อนหน้า

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว · Python ของโมดูล .venv-module07 (ตัวติดตั้ง Module 1 สร้างไว้ เมื่อเห็น MODULE7_READY)
  • ข้อมูล: course-materials/module-07/examples/figure-consistency/mock-study-data.csv (ติดตั้งมากับ Module 1 · ข้อมูล PM2.5 จำลอง รายสัปดาห์ 480 แถว ไม่ใช่ข้อมูลวิจัยจริง ห้ามแก้ไฟล์ต้นฉบับ)
  • ไฟล์งาน module-07-work/module-07-highlights.md (ตัวติดตั้ง Module 1 เตรียมโครงห้าหัวข้อไว้แล้ว ยังว่าง) และโฟลเดอร์ module-07-work/figures/ (ตัวติดตั้งสร้างไว้ อาจมีภาพจาก Prompt activities ก่อนหน้าอยู่แล้ว)
  • ตารางงานอ่านค่าจากกิจกรรม choose-chart-by-reader-task (หัวข้อ อ่านข้อมูลและเลือกกราฟให้ตรงงานของผู้อ่าน) และ module-07-work/chart-choice-notes.md ที่คุณสร้างใน Prompt ของกิจกรรมนั้น
  • (ทางเลือก) course-materials/module-07/templates/module-07-visualization-workflow-and-prompts.md (ติดตั้งมากับ Module 1)

โจทย์

ค่า PM2.5 เปลี่ยนอย่างไรตามพื้นที่ กลุ่ม ก่อน–หลังมาตรการ และเวลา คุณเลือกมุมวิเคราะห์ วิธี และชนิดกราฟเอง

ขั้นตอน

  1. ให้ AI ทำ ใบรับการนำเข้า ก่อน (จำนวนแถว × คอลัมน์ ชนิดข้อมูล ค่าที่ไม่ซ้ำ ข้อมูลที่หาย และคำเตือน ห้ามแก้ไฟล์ต้นฉบับ) ด้วยคำสั่งเริ่มต้นนี้

    อ่าน mock-study-data.csv โดยไม่แก้ไฟล์ต้นฉบับ ทำใบรับการนำเข้า แล้วเสนอคำถามสำรวจ 3 ข้อ สำหรับแต่ละข้อ บอกงานอ่านค่า กราฟที่เหมาะ และสิ่งที่กราฟนั้นอาจซ่อนไว้ ยังไม่ต้องสรุปผล

    ตรวจใบรับเอง: ต้องได้ 480 แถว และค่าที่ไม่ซ้ำของ site, arm, period ตรงกับตารางคอลัมน์ด้านบน

  2. ระบุ หน่วยวิเคราะห์ ว่าหนึ่งแถวคือค่าวัดของเครื่องหนึ่งในหนึ่งสัปดาห์ แล้วตัดสินว่าจะรวมค่าระดับใด (เช่น ต่อ site × arm × period หรือต่อ week) และจดเหตุผลไว้ใต้หัวข้อ ## คำถามที่สำรวจ ใน module-07-work/module-07-highlights.md

  3. สำรวจด้วย กราฟการแจกแจง ก่อน แล้วจึงเลือกกราฟสื่อสาร (ใช้ตารางงานอ่านค่าและ module-07-work/chart-choice-notes.md)

  4. ให้ AI บันทึกกราฟที่เลือกไว้ใน module-07-work/figures/ (PNG, JPEG หรือ WebP ไม่เกิน 2 MB ต่อภาพ, 1–5 ภาพ, ชื่อไฟล์ภาษาอังกฤษที่สื่อความหมาย)

  5. เขียน highlights ลง module-07-work/module-07-highlights.md ตามโครงไฟล์ด้านล่าง (จะให้ AI ร่างก็ได้ แต่ตัวเลขทุกตัวต้องมาจากผลที่คุณตรวจแล้ว)

  6. ตรวจย้อนกลับกับ CSV ด้วยตนเองอย่างน้อย 3 ค่า (วิธีละเอียดอยู่ในกิจกรรมถัดไป red-team-figures-against-source-csv)

ทางเลือก: ถ้าอยากให้ AI พาสำรวจแบบสนทนาตั้งแต่ต้น ใช้ prompt ตั้งต้นใน course-materials/module-07/templates/module-07-visualization-workflow-and-prompts.md (ส่วน "Prompt ตั้งต้นใน VS Code" — ใช้ได้กับ AI ตัวใดก็ได้)

ตัวอย่างรูปแบบ highlight หนึ่งข้อ

ในภาพรวมทุกพื้นที่ ค่าเฉลี่ย PM2.5 ของกลุ่ม Intervention ลดจาก 37.0 เป็น 34.4 µg/m³ หลังเริ่มมาตรการ (120 ค่าวัดต่อช่วง) ขณะที่กลุ่ม Comparison เพิ่มเล็กน้อยจาก 37.6 เป็น 38.3 µg/m³ ข้อมูลนี้เป็นการสังเกต จึงยังสรุปไม่ได้ว่ามาตรการเป็นสาเหตุ

สังเกตว่ามีตัวเลข หน่วย ฐานเปรียบเทียบ จำนวนค่าวัด และขอบเขตของข้อสรุป ใช้เป็นรูปแบบ แล้วหาข้อค้นพบของคุณเอง เช่น ความต่างระหว่างพื้นที่ หรือการเปลี่ยนตามสัปดาห์ (อย่าคัดลอกตัวอย่างนี้เป็น highlight ของคุณ)

Exploring 1

หา 3–5 highlights จากข้อมูลที่มีตัวเลขรองรับ

ใน Exploring workshop นี้คุณจะเขียน prompt เองตั้งแต่ใบรับการนำเข้าจนถึงกราฟสื่อสารกับข้อมูลตารางของคุณ แล้วได้ module-07-work/output/highlights.md ที่มี highlights 3–5 ข้อในโครงห้าหัวข้อเดียวกับ workshop

ผู้เรียนเขียน prompt เอง ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว · โฟลเดอร์ module-07-work/ และ Python ของโมดูล .venv-module07 (ตัวติดตั้ง Module 1 สร้างไว้)
  • ทำ workshop "หา 3–5 highlights จากข้อมูลที่มีตัวเลขรองรับ" ของหัวข้อนี้แล้ว (รู้จักโครงห้าหัวข้อของไฟล์ highlights)
  • ชุดข้อมูลตารางหนึ่งชุดจากงานวิจัยของคุณ ที่มีสิทธิ์นำเข้า AI
    • ถ้ายังไม่มี: ใช้ course-materials/module-07/examples/figure-consistency/mock-study-data.csv (ติดตั้งมากับ Module 1) หรือกรณีฝึกสำรองประชากรไทย (ข้อมูลเปิด ให้ AI ดาวน์โหลดและทำใบรับข้อมูลตามหน้านั้น)

ขั้นตอน

  1. สร้างโฟลเดอร์ module-07-work/output/ และไฟล์ module-07-work/output/prompts.md (ถ้ามีจาก Exploring workshop ข้ออื่นแล้ว ให้เพิ่มหัวข้อใหม่ต่อท้าย) ไว้จดทุกรอบเป็น prompt → สรุปคำตอบของ AI → สิ่งที่คุณตัดสินใจ
  2. ตั้งคำถามสำรวจหนึ่งข้อ
  3. เขียน prompt ให้ AI ทำใบรับการนำเข้า (จำนวนแถว/คอลัมน์ ค่าหาย คำเตือน) ตรวจเอง แล้วบันทึกเป็น module-07-work/output/import-receipt.md
  4. ระบุหน่วยวิเคราะห์และระดับการรวมค่าพร้อมเหตุผล
  5. เขียน prompt ให้ AI สำรวจการแจกแจงก่อน แล้วจึงทำกราฟสื่อสาร เก็บภาพไว้ใน module-07-work/output/figures/
  6. สร้าง module-07-work/output/highlights.md เขียน highlights 3–5 ข้อ ข้อสรุป และข้อจำกัด ในโครงห้าหัวข้อเดียวกับ workshop
  7. ตรวจย้อนกับข้อมูลต้นทางด้วยตนเองอย่างน้อย 3 ค่า

ข้อกำหนด

  • เขียน prompt เองทุกข้อ ไม่ใช้ prompt สำเร็จรูปจาก workshop และจดทุกรอบใน module-07-work/output/prompts.md
  • ระบุว่าตรวจผลของ AI อย่างไร (เปิดภาพดูเอง คำนวณเอง หรือเปิดข้อมูลต้นทาง) และแก้อะไรเอง
  • ข้อมูลที่ไม่มีสิทธิ์นำเข้า AI (ข้อมูลส่วนบุคคล ข้อมูลลับ manuscript ที่ยังไม่เผยแพร่) ให้ใช้ข้อมูลจำลอง/ข้อมูลเปิดแทน
  • ถ้า AI เสนอวิธีทางสถิติที่คุณอธิบายเหตุผลไม่ได้ ให้หยุดและปรึกษาผู้เชี่ยวชาญก่อนใช้ผล
  • ห้ามแก้ไฟล์ข้อมูลต้นฉบับ งานทั้งหมดเก็บใน module-07-work/output/ (highlights.md, figures/, import-receipt.md)

Workshop 2

Red team ก่อนส่ง: ตรวจกราฟและ highlights 7 ข้อ

ใน workshop นี้คุณจะจับคู่กับเพื่อนตรวจกราฟและ highlights ของกันและกันด้วยรายการ 7 ข้อ ตรวจตัวเลขย้อนกับ CSV เองอย่างน้อย 3 ค่า แล้วสร้าง module-07-work/red-team.md และแก้งานให้พร้อมส่ง

ใช้ผลงานจากกิจกรรม evidence-backed-data-highlights (หัวข้อ จากข้อมูลสู่ highlights ที่ตรวจย้อนได้) ไม่ต้องสร้าง mock เพิ่ม

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • module-07-work/module-07-highlights.md ที่มี highlights 3–5 ข้อ และกราฟ 1–5 ภาพใน module-07-work/figures/ ที่คุณทำในกิจกรรม evidence-backed-data-highlights (ของคุณ และของเพื่อนที่จับคู่)
  • ข้อมูลต้นทาง: course-materials/module-07/examples/figure-consistency/mock-study-data.csv (ติดตั้งมากับ Module 1 · อ่านอย่างเดียว)
  • spreadsheet หรือ Python ที่คุณใช้คำนวณเองได้ (เช่น .venv-module07 ที่ตัวติดตั้ง Module 1 สร้างไว้)

รายการตรวจ 7 ข้อ

ข้อ ตรวจอะไร ผ่านเมื่อ
1 แกนและ baseline bar เริ่มที่ศูนย์ แกนสองข้างมีเหตุผลรองรับ
2 ตัวหารและหน่วย ทุก panel ใช้ฐานเดียวกัน หน่วยครบ
3 n และข้อมูลดิบ ระบุ n และเห็นข้อมูลจริงเมื่อ n น้อย
4 ชนิด interval SD, SE, CI หรือ IQR เขียนไว้ในคำบรรยายภาพ
5 สีมีหน้าที่ ยังอ่านได้เมื่อพิมพ์ขาวดำ
6 ชื่อภาพคือ claim ไม่อ้างเกินกว่าที่ภาพแสดง
7 ตรวจย้อนกับ CSV สุ่มอย่างน้อย 3 ค่าใน highlights แล้วหาเองจากข้อมูลต้นทาง

ขั้นตอน

  1. จับคู่กับเพื่อน สลับไฟล์ highlights และกราฟกัน
  2. สร้างไฟล์ module-07-work/red-team.md สำหรับจดผลตรวจงานของเพื่อน
  3. ตรวจข้อ 1–6 ด้วยตาจากภาพและคำบรรยายภาพ จดผล ผ่าน/ไม่ผ่าน พร้อมจุดที่เห็น ลงใน red-team.md
  4. ข้อ 7: เลือกตัวเลขอย่างน้อย 3 ค่าใน highlights แล้วหาเองจาก CSV (กรองตาม site/arm/period/week ที่ highlight อ้าง แล้วนับแถวและคำนวณค่าเฉลี่ยหรือค่าที่อ้าง) ด้วย spreadsheet หรือโค้ดที่คุณเขียน/อ่านเข้าใจเอง
    • อย่าถาม AI ตัวเดียวกับที่ทำงานนั้นให้ "ตรวจว่าถูกไหม"
    • บันทึกลง red-team.md: ค่าที่ highlight อ้าง | เงื่อนไขกรอง | n ที่ได้ | ค่าที่คุณคำนวณ | ตรง/ไม่ตรง
  5. คืนผลตรวจให้เจ้าของงาน เจ้าของงานแก้ไฟล์ highlights/กราฟของตัวเองเฉพาะข้อที่ไม่ผ่าน

เสริม · Workshop

ตรวจความสอดคล้องของภาพ ตาราง และข้อความทั้งเอกสาร

ใน workshop นี้คุณจะตรวจบทความจำลองหาความไม่สอดคล้องระหว่าง Methods ตาราง รูป caption และข้อสรุปด้วยตัวเองก่อน ใช้ AI เป็นผู้ตรวจคนที่สอง แล้วกรอกผลลง module-07-work/module-07-figure-audit.md

ทำตามได้ครบด้วยบทความจำลองที่ฝังข้อผิดพลาดไว้เพื่อการเรียน (ข้อมูล PM2.5 จำลองชุดเดียวกัน) ไม่ต้องสร้าง mock เพิ่ม

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • ไฟล์ที่ติดตั้งมากับ Module 1 (อ่านอย่างเดียว):
    • course-materials/module-07/examples/figure-consistency/mock-article-figure-consistency.pdf
    • course-materials/module-07/examples/figure-consistency/mock-study-data.csv
  • module-07-work/module-07-figure-audit.md (ตัวติดตั้ง Module 1 คัดลอกจาก figure-consistency-audit-template.md ไว้ให้ เป็นแม่แบบที่ยังไม่กรอก)
  • ห้ามเปิดสคริปต์สร้างกรณีศึกษาหรือเฉลยผู้สอนก่อนส่งงาน

ขั้นตอน

  1. รอบแรกทำเอง (ไม่ใช้ AI): อ่านบทความจำลองทั้งฉบับ แล้วเทียบ Methods, ตาราง, รูป, caption และข้อสรุป ไล่ตามหมวดในแม่แบบ

    • สีและความหมายของภาพ: สีเดียวกันแทนสิ่งเดียวกันทุกภาพหรือไม่ lower/higher หรือ positive/negative มีความหมายคงที่หรือไม่
    • Population ตัวหาร และการคัดออก: จำนวน observation ที่คาดจากข้อมูล เทียบกับที่รายงาน กลุ่มหรือ site ที่หายไป
    • สถิติและการแปลงค่า: mean/median/rate/change/cumulative ที่แต่ละส่วนใช้ นิยาม change และทิศทางเครื่องหมาย
    • Scale: panel หรือภาพใดใช้ช่วงแกนไม่เหมือนกัน
    • ข้อความ–ตาราง–รูป: ข้อความใดไม่ตรงกับตารางหรือรูป caption ใดกล่าวเกินข้อมูล

  2. กรอก Cross-figure issue ledger ใน module-07-work/module-07-figure-audit.md ให้มีอย่างน้อย 6 ประเด็น โดยอย่างน้อย 4 ประเด็นต้องอาศัยการอ่านตั้งแต่สองตำแหน่งขึ้นไป ระบุหน้า รูป ตาราง คอลัมน์ หรือการคำนวณที่รองรับ

  3. ตรวจค่าจาก CSV ด้วยตนเองอย่างน้อย 3 ค่า (เช่น จำนวน observation ต่อกลุ่มที่บทความรายงาน)

  4. รอบสองใช้ AI เป็นผู้ตรวจคนที่สอง ตัวอย่าง prompt

    อ่าน mock-article-figure-consistency.pdf และ mock-study-data.csv โดยไม่แก้ไฟล์ หาความไม่สอดคล้องระหว่าง Methods ตาราง รูป caption และข้อสรุป ที่เปลี่ยนข้อสรุป (สี นิยาม ทิศทางเครื่องหมาย สถิติ กลุ่มข้อมูล ช่วงแกน population) ไม่นับเรื่องความสวยงาม แต่ละประเด็นระบุตำแหน่งที่ต้องอ่านร่วมกันและหลักฐานจากข้อมูล ยังไม่ต้องเขียนลงไฟล์ของฉัน

  5. เทียบผลของ AI กับ ledger ของคุณ ตัดสินเองว่าจะเพิ่มประเด็นใด (ตรวจหลักฐานทุกข้อที่ AI เสนอก่อนรับ) และทำเครื่องหมาย AI used after the human-first pass: yes

  6. เขียน Executive diagnosis และ Minimum corrected claim ในแม่แบบ
