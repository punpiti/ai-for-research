Learning outcomes

จบคลาสแล้ว
ทำอะไรได้

01

Research Question Development

เปลี่ยนปัญหา ช่องว่าง และหลักฐานให้เป็นคำถามวิจัยที่ชัดและทดสอบได้

02

Literature & Citation Audit

ค้นต้นทาง ตรวจ citation และชี้ได้ว่าหลักฐานรองรับข้อความใด เพียงใด

03

Research Design & Quality Control

เชื่อมคำถาม ตัวแปร ข้อมูล วิธีวัด การวิเคราะห์ และขอบเขตข้อสรุปให้สอดคล้องกัน

04

Non-coding Data Analytics

วิเคราะห์ Excel, CSV หรือ SPSS ด้วย Python ที่ AI เขียนและรันให้ โดยผู้เรียนตรวจข้อมูล วิธี และผลลัพธ์

05

Data Visualization & Machine Learning

สร้างรูปและตารางพร้อมเผยแพร่ ทดลองโมเดล Machine Learning และแปลผลตามคำถามวิจัย

06

Manuscript Preparation

เปลี่ยน Markdown และ JSON เป็น Word, LaTeX และ PDF พร้อมรูป ตาราง citation และรายการอ้างอิง

Requirements

ใช้ notebook
ไม่ต้องเขียนโปรแกรม

ใช้เครื่องและงานของตนเองตั้งแต่วันแรก เพื่อให้สิ่งที่ติดตั้งและไฟล์งานพร้อมใช้ต่อหลังจบคลาส

อุปกรณ์

Notebook ส่วนตัว

Windows 11, macOS หรือ Linux ที่ติดตั้งโปรแกรมได้ ไม่ใช้ tablet หรือ iPad เป็นเครื่องหลัก

พื้นฐาน

ไม่ต้องมีพื้นฐานเขียนโปรแกรม

AI เขียนและรัน Python ให้ ผู้เรียนกำหนดโจทย์ ตรวจข้อมูล วิธีวิเคราะห์ และผลลัพธ์

ก่อนมาเรียน

สิทธิ์ติดตั้งและไฟล์วิจัย

เตรียมรหัสผ่านติดตั้งโปรแกรม อินเทอร์เน็ต และงานหรือข้อมูลหนึ่งชุดที่มีสิทธิ์ใช้

Notebook เท่านั้น

ไม่แนะนำ tablet, iPad หรือ Chromebook เป็นเครื่องหลัก เพราะกิจกรรมต้องติดตั้งโปรแกรมและจัดการไฟล์ในเครื่อง

หากงานวิจัยหรือชุดข้อมูลยังไม่พร้อม สามารถใช้กรณีศึกษาและข้อมูลสำรองของคลาสได้

รับอาจารย์และนักวิจัย — รุ่นนี้ยังไม่เปิดรับนิสิต

เนื้อหาบางส่วนใช้สำหรับออกแบบ กำกับ และตรวจประเมินกระบวนการเรียนรู้กับงานวิจัยของนิสิต จึงตรวจสิทธิ์ก่อนเข้าร่วม
