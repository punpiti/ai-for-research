Before class

เตรียมอะไร
มาด้วย

ใช้เครื่องและงานของตนเองตั้งแต่วันแรก เพื่อให้สิ่งที่ติดตั้ง ไฟล์งาน และเครื่องมือที่ปรับไว้ยังอยู่พร้อมใช้หลังจบคลาส

อุปกรณ์หลัก

โน้ตบุ๊กส่วนตัวพร้อมที่ชาร์จ

  • Windows 11, macOS หรือ Linux ที่ติดตั้งโปรแกรมได้
  • พื้นที่ว่างอย่างน้อย 20 GB และ browser รุ่นปัจจุบัน
  • ทราบรหัสผ่านหรือมีสิทธิ์อนุมัติการติดตั้งโปรแกรมในเครื่อง
บัญชีและการเชื่อมต่อ

อีเมลที่ใช้สมัครและอินเทอร์เน็ต

  • เปิดอีเมลที่ใช้ลงทะเบียนได้ระหว่างเรียน
  • เชื่อมต่ออินเทอร์เน็ตสำหรับดาวน์โหลดเครื่องมือและใช้ AI
  • รายละเอียดบัญชี AI หรือ API key จะแจ้งในห้องเรียน
งานวิจัย

งานหนึ่งเรื่องที่อยากทำให้เดินหน้า

  • หัวข้อ โครงร่าง บทความ ร่างต้นฉบับ หรือเอกสารที่กำลังใช้
  • ชุดข้อมูล Excel, CSV หรือ SPSS หากต้องการทำกิจกรรมวิเคราะห์ข้อมูล
  • นำเฉพาะข้อมูลที่มีสิทธิ์ใช้ และตัดข้อมูลลับหรือข้อมูลส่วนบุคคลที่ไม่จำเป็นออก
แนะนำให้ใช้โน้ตบุ๊กส่วนตัว

คลาสมีการติดตั้ง VS Code, Python, เครื่องมือเอกสาร และพื้นที่งานวิจัยไว้ในเครื่อง ผู้เรียนจึงนำสภาพแวดล้อมเดิมกลับไปทำงานต่อได้ทันที ไม่แนะนำ tablet, iPad หรือ Chromebook เป็นเครื่องหลัก เพราะไม่รองรับกิจกรรมติดตั้งและจัดการไฟล์ทั้งหมดของคลาส

หากงานวิจัยหรือชุดข้อมูลยังไม่พร้อม สามารถใช้กรณีศึกษาและข้อมูลสำรองของคลาสได้

Return on your time

เวลาที่ลงไป
ได้อะไรกลับมา

01

งานวิจัยของตนเองเดินหน้าต่อ

ได้สรุปกรอบงานวิจัย (research brief) ที่ปรับโจทย์และคำถามวิจัยแล้ว ตารางตรวจวรรณกรรมและ citation พร้อมแผนการศึกษา การวิเคราะห์ หรือร่างต้นฉบับตามความพร้อมของโครงการ

02

ผลิตงานได้ต่อเนื่องขึ้น

ได้โครงโครงการ แม่แบบ คำสั่ง และ checklist ที่ปรับกับงานของตนเอง เพื่อนำกลับไปใช้กับการค้นหลักฐาน วิเคราะห์ข้อมูล สร้างตารางและภาพ และจัดทำเอกสารรอบต่อไป

03

มีจุดตรวจคุณภาพก่อนเผยแพร่

ได้วิธีตรวจแหล่งอ้างอิง ความเชื่อมโยงของโจทย์กับแบบการศึกษา ความถูกต้องของข้อมูล และขอบเขตของข้อสรุป รวมถึงการคุ้มครองข้อมูลและการเปิดเผยการใช้ AI

Learning outcomes

เมื่อจบคลาส
ผู้เรียนสามารถ

01

กำหนดโจทย์วิจัย

ตรวจและปรับสายเหตุผลจากปัญหา ช่องว่าง วัตถุประสงค์ ไปถึงคำถามวิจัยด้วยหลักฐาน

02

ตรวจวรรณกรรมและ citation

ค้นแหล่งต้นทาง ยืนยันว่ารายการอ้างอิงมีอยู่จริง และตัดสินว่าหลักฐานรองรับข้อความได้เพียงใด

03

ออกแบบการศึกษา

เชื่อมสมมติฐาน ตัวแปร กลุ่มตัวอย่าง วิธีวัด และเกณฑ์แปลผลกับข้อสรุปที่ต้องการทดสอบ

04

Non-coding Data Analytics & Visualization

ให้ AI เขียนและรัน Python เพื่อวิเคราะห์ Excel, CSV หรือ SPSS สร้างตารางและภาพ และทดลอง Machine Learning เมื่อสอดคล้องกับคำถามวิจัย ผู้เรียนตรวจข้อมูล วิธี และผลลัพธ์โดยไม่ต้องเขียนโปรแกรม

05

Manuscript Preparation

จัดเนื้อหาและผลลัพธ์ด้วย Markdown และ JSON แล้วให้ AI สร้าง Word หรือ LaTeX พร้อมรูป ตาราง รายการอ้างอิง และ PDF ตามข้อกำหนดของแหล่งเผยแพร่

06

กำกับการใช้ AI ในงานวิจัย

ประเมิน privacy, confidentiality, citation, ethics, ข้อจำกัด และการเปิดเผยการใช้ AI

เนื้อหาที่เรียน

ตั้งแต่ตั้งคำถาม
ถึงต้นฉบับพร้อมเผยแพร่

  1. 01

    เตรียมพื้นที่ทำงานวิจัยกับ AI

    จัดเครื่องมือ โครงงาน และขอบเขตข้อมูลให้พร้อมใช้ โดย AI รับงาน Markdown, JSON, Python และ LaTeX

  2. 02

    อ่านหลักฐานและตรวจคำตอบ AI

    ทำงานกับข้อมูลหลายรูปแบบ เก็บเนื้อหาใน Markdown และผลตรวจแบบมีโครงสร้างใน JSON แล้วแยกข้อเท็จจริงออกจากข้อสรุป

  3. 03

    พัฒนาโจทย์และคำถามวิจัย

    เชื่อมปัญหา ช่องว่าง วัตถุประสงค์ และคำถามวิจัยด้วยเหตุผลและหลักฐาน

  4. 04

    ค้นและตรวจวรรณกรรม

    ค้นแหล่งต้นทาง ตรวจรายการอ้างอิง และสังเคราะห์สิ่งที่หลักฐานรองรับ

  5. 05

    วางตรรกะและคุณูปการของงานวิจัย

    เชื่อมคำถามวิจัย แบบการศึกษา ความใหม่ ขอบเขต และเป้าหมายการเผยแพร่

  6. 06

    ทดสอบความแข็งแรงของแบบการศึกษา

    ตรวจสมมติฐาน ตัวแปร กลุ่มเปรียบเทียบ วิธีวัด และเกณฑ์แปลผล

  7. 07

    Non-coding Data Analytics, Visualization & Machine Learning

    ให้ AI เขียนและรัน Python เพื่อวิเคราะห์ข้อมูล สร้างตารางและภาพ และทดลองโมเดลที่เหมาะกับคำถามวิจัย โดยผู้เรียนไม่ต้องเขียนโปรแกรม

  8. 08

    Manuscript Preparation

    ให้ AI เปลี่ยน Markdown และผลลัพธ์ที่ตรวจแล้วเป็นต้นฉบับ Word หรือ LaTeX และ PDF ตามข้อกำหนดของแหล่งเผยแพร่

  9. 09

    ออกแบบวิธีใช้ AI ในงานวิจัยของตนเอง

    กำหนดขอบเขต วิธีตรวจหลักฐาน การคุ้มครองข้อมูล และการเปิดเผยการใช้ AI
