Workshop

ตรวจ references.bib พร้อมที่มาของ abstract และทำ literature map

ใน workshop นี้คุณจะให้ AI ตรวจระเบียนใน references.bib แล้วกรอกผลลง bibliography audit, literature map และ candidate gap จากนั้นตรวจทุกแถวกลับไปที่ .bib ด้วยตัวเอง

ใช้ระเบียนอ้างอิงจำลอง 3 รายการ (ทุกระเบียนติดป้าย Synthetic teaching record; not a real publication — ห้ามนำไปอ้างนอกแบบฝึก)

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • ติดตั้ง Module 8 แล้ว ตัวติดตั้งวางไฟล์เหล่านี้ไว้ให้:
    • module-08-work/literature/references.bib — 3 ระเบียน: Arun2024CommunityPM, Chen2023SensorWeeks, Diaz2025BeforeAfter
    • module-08-work/literature/bibliography-audit.md, literature-map.md, candidate-gap.md — ไฟล์ที่มีแต่หัวตาราง/หัวข้อ ยังไม่มีเนื้อหา
    • module-08-work/input/module-07-highlights.md — ใช้เทียบว่าวรรณกรรมเกี่ยวกับงานอย่างไร

คำที่ใช้ใน workshop นี้

  • BibTeX record — ระเบียนอ้างอิงหนึ่งรายการในไฟล์ .bib
  • citation key — รหัสที่เชื่อมข้อความในต้นฉบับกับระเบียน BibTeX
  • abstract source — แหล่งที่นำ abstract ต้นฉบับมา ต้องตรวจย้อนกลับได้
  • literature map — ตารางที่แยก problem, context, method, finding และ limitation ของแต่ละงาน
  • candidate gap — ประเด็นที่ควรค้นต่อ ยังไม่ใช่หลักฐานยืนยันความใหม่

ขั้นตอน

  1. อ่านเองก่อน (1 นาที) เปิด literature/references.bib ดูหนึ่งระเบียน: มี abstract, abstract_source, accessed และ note อะไรบ้าง สังเกตบรรทัดแรกของไฟล์ที่บอกว่าเป็นระเบียนสังเคราะห์

    ตรวจ: ชี้ citation key และตำแหน่งของ abstract_source ในระเบียนที่เปิดได้

  2. ส่ง prompt ให้ AI ตรวจระเบียน AI จะเติมแถวลงตารางใน literature/bibliography-audit.md

    อ่านเฉพาะไฟล์ module-08-work/literature/references.bib ไม่ต้องค้นเว็บ ตรวจทุกระเบียน: ชนิดรายการ citation key, author, title, year, venue, DOI/URL, abstract, abstract_source และ accessed ตรวจ key ซ้ำ field ขาด และ DOI ซ้ำ ระบุว่าระเบียนใดติดป้ายว่าเป็นข้อมูลจำลอง ห้ามแต่ง author, title, year, DOI หรือ abstract ห้ามสร้าง abstract จากชื่อเรื่อง ระเบียนที่ตรวจไม่ได้ให้เว้น field และระบุสถานะ บันทึกผลลงตารางใน module-08-work/literature/bibliography-audit.md (Citation key | Metadata | Abstract source | Status / action) แล้วหยุดให้ฉันตรวจ

    ตรวจ: audit มีทั้งสาม citation key และไม่มี metadata หรือ abstract ที่ไม่มีใน .bib

  3. ตรวจผลของ AI (2 นาที) เลือกอย่างน้อย 1 ระเบียน เปิด .bib เทียบกับแถวใน bibliography-audit.md ทีละ field

    • abstract ใน audit (ถ้ามีการคัดลอก) ตรงกับใน .bib ทุกคำหรือไม่ AI สรุปหรือแปลแทนต้นฉบับโดยไม่ติดป้ายหรือไม่
    • สถานะบอกชัดหรือไม่ว่าเป็น synthetic record ใช้ในแบบฝึกเท่านั้น (DOI ในชุดนี้ไม่ใช่ DOI จริง จึงตรวจกับ publisher ไม่ได้ — สถานะต้องบอกตามนั้น ไม่ใช่ “verified”)

    ตรวจ: ระเบียนที่สุ่มเทียบตรงกับ .bib ทีละ field และยังติดป้าย synthetic record

  4. ส่ง prompt ให้ AI ทำ literature map และ candidate gap AI จะเติม literature/literature-map.md และ literature/candidate-gap.md

    สร้าง literature map จาก module-08-work/literature/references.bib โดยใช้เฉพาะ title, abstract และ metadata แยก problem/context, method, finding และ limitation ของแต่ละรายการ อ้าง citation key ทุกข้อ แยกสิ่งที่พบจริงจากการตีความ บันทึกใน module-08-work/literature/literature-map.md จากนั้นเติม module-08-work/literature/candidate-gap.md ตามหัวข้อ Observed in corpus, Candidate gap, Counterevidence และ Search needed ทุก candidate gap ต้องมี citation key ที่รองรับ และคำค้นต่อ ห้ามใช้คำว่า novel หรือยืนยันว่าเป็น research gap แล้วรอฉันตรวจ

    ตรวจ: ทุกแถวใน literature map มี citation key และทุก candidate gap มี counterevidence หรือคำค้นต่อ

  5. ตรวจและแก้เอง เปิด literature-map.md ดูว่าทุกแถวชี้กลับไปที่ abstract ได้ เปิด candidate-gap.md เทียบกับ input/module-07-highlights.md ว่าข้อใดสัมพันธ์กับคำถามของงาน PM2.5 (ผลรวมกับผลแยกพื้นที่, repeated sensor observations, การใช้ถ้อยคำเชิงเหตุ) แล้วแก้หรือลบข้อที่ไม่มีหลักฐาน

    ตรวจ: ไม่มีข้อใดอ้าง novelty และไฟล์ references.bib ไม่ถูกแก้

ข้อควรรู้

  • งานจริง: นำเข้าระเบียนจาก DOI, publisher, Crossref หรือฐานข้อมูลที่ตรวจสอบได้ และเก็บ abstract ต้นฉบับจากหน้า publisher หรือฐานข้อมูลที่ตรวจแล้ว ระเบียนที่ยังตรวจไม่ได้ใช้ abstract = {} และบันทึกใน audit
  • การไม่พบประเด็นใน corpus ชุดเล็กเป็นเพียงข้อจำกัดของการค้น ยังไม่ใช่หลักฐานความใหม่ของงาน

Exploring

ตรวจ references.bib พร้อมที่มาของ abstract และทำ literature map

ในกิจกรรมนี้คุณจะเขียน prompt เองเพื่อให้ AI ช่วยสร้างหรือตรวจ BibTeX ของรายการอ้างอิงในงานของคุณ แล้วทำ bibliography audit, literature map และ candidate gap (ไม่มี prompt สำเร็จรูปให้)

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • งานของคุณเองที่กำลังเขียน (บทความ/ข้อเสนอโครงการ/บทในวิทยานิพนธ์) ที่มีรายการอ้างอิง
  • DOI หรือหน้า publisher ของรายการอ้างอิงที่จะใช้ ที่คุณเปิดดูได้

โจทย์

  1. เลือกรายการอ้างอิง 3–5 รายการจากงานของคุณ
  2. สร้างโฟลเดอร์ output/ ในโฟลเดอร์งานของคุณ (ถ้ายังไม่มี) และไฟล์ output/prompts.md สำหรับบันทึก prompt ทุกรอบ (prompt, สรุปผลที่ได้, สิ่งที่ปรับในรอบถัดไปและเหตุผล)
  3. เขียน prompt ให้ AI ช่วยสร้างหรือตรวจ BibTeX จาก DOI/หน้า publisher ที่คุณให้ ลง output/references.bib พร้อม abstract ต้นฉบับ abstract_source และ accessed — ระเบียนหรือ abstract ที่ตรวจไม่ได้ให้เว้นไว้และบันทึกสถานะ ห้ามให้ AI แต่งจากความจำหรือจากชื่อเรื่อง
  4. ให้ AI บันทึกผลตรวจลง output/bibliography-audit.md แล้วเปิดตรวจกับต้นทางเอง บันทึกว่าตรวจกับเอกสารใดและแก้อะไรเอง
  5. ทำ output/literature-map.md และ output/candidate-gap.md จากระเบียนชุดนั้น
