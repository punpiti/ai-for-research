1 · MD

Markdown — ข้อความที่มีโครงสร้าง

Markdown เก็บเนื้อหาเป็นข้อความในไฟล์ .md เครื่องหมายบางตัวบอกหัวข้อหรือรายการ เมื่อเปิด Preview โปรแกรมจะแสดงผลตามโครงสร้างนั้น

# Room temperature note

## Observation

- Room A: 26.5 degrees Celsius
- Room B: value missing

## Limitation

One reading per room cannot describe the whole day.

# คือหัวข้อหลัก ## คือหัวข้อย่อย และ - คือรายการ ข้อความหลังเครื่องหมายยังเป็นเนื้อหาที่ตรวจและแก้ได้ PDF ที่สร้างจากต้นฉบับนี้เป็นผลลัพธ์สำหรับอ่านหรือส่งต่อ ถ้าต้องแก้เนื้อหา ให้แก้ .md แล้วสร้าง PDF ใหม่

ลองทำและตรวจผล

  1. ให้ AI สร้างตัวอย่างนี้ในโฟลเดอร์งานของกิจกรรมปัจจุบัน หรือเปิดต้นฉบับที่กิจกรรมเตรียมไว้
  2. เปิด Preview (Ctrl+Shift+V, macOS: Command+Shift+V) แล้วชี้ว่าหัวข้อหลัก หัวข้อย่อย และรายการตรงกับบรรทัดใดในต้นฉบับ
  3. เปลี่ยนชื่อหัวข้อหนึ่งแห่ง แล้วตรวจว่าตัวเลข 26.5 และข้อความข้อจำกัดยังเหมือนเดิม
  4. อธิบายว่าถ้าพบข้อความผิดใน PDF จะกลับไปแก้ไฟล์ไหน
อธิบายหัวข้อและรายการในไฟล์ Markdown นี้จากข้อความที่มีอยู่ แล้วเปลี่ยนเฉพาะชื่อหัวข้อที่ฉันระบุ แสดงสิ่งที่เปลี่ยนและรอให้ฉันตรวจ อย่าเปลี่ยนตัวเลขหรือข้อจำกัด
ผ่านส่วนนี้เมื่อ: แก้หัวข้อได้ และตรวจได้ว่าข้อมูลส่วนอื่นถูกเปลี่ยนหรือไม่

2 · CSV

CSV — ตารางที่เก็บเป็นข้อความ

CSV เก็บตารางเป็นข้อความ ตัวอย่างนี้ใช้จุลภาคคั่นช่อง บรรทัดแรกเป็นชื่อคอลัมน์ และแต่ละบรรทัดถัดมาคือการอ่านอุณหภูมิห้องหนึ่งครั้ง (ข้อมูลจำลอง)

room_id,temperature_c,reading_time
A,26.5,2026-11-20T09:00:00+07:00
B,,2026-11-20T09:00:00+07:00

temperature_c มีหน่วยองศาเซลเซียส ช่องว่างของห้อง B หมายถึงไม่มีค่าในไฟล์นี้ จึงไม่ใช่ศูนย์องศา ต้องอ่านคำอธิบายข้อมูลก่อนตัดสินใจจัดการค่าที่ขาด ส่วน room_id เป็นรหัสห้อง ไม่ใช่ค่าที่นำมาเฉลี่ย

ลองทำและตรวจผล

  1. เปิด CSV ของกิจกรรม (เช่น ข้อมูลใน Module 7) และระบุจากคำอธิบายชุดข้อมูลว่าหนึ่งแถวแทนอะไร
  2. เลือกสองคอลัมน์ที่จะใช้ บอกความหมาย หน่วย และค่าที่ขาด ถ้าคำอธิบายไม่ระบุ ให้บันทึกว่ายังไม่ทราบ
  3. ให้ AI อ่านข้อมูลแล้วรายงานชื่อคอลัมน์ จำนวนแถว และตัวอย่างค่าก่อนสร้างกราฟ
  4. ตรวจตัวอย่างสองค่ากลับกับไฟล์ต้นทาง รวมถึงเลขทศนิยม เครื่องหมาย และช่องว่าง
อ่าน CSV นี้และคำอธิบายชุดข้อมูล สรุปว่าหนึ่งแถวแทนอะไร แต่ละคอลัมน์ที่ฉันเลือกมีความหมายและหน่วยใด พร้อมยกตัวอย่างค่าที่ตรวจย้อนถึงแถวได้สองค่า แจ้งสิ่งที่ยังไม่ทราบและค่าที่ขาดก่อนเสนอการคำนวณ
เปิดแล้วดูแปลก? ถ้าคอลัมน์เลื่อน ภาษาไทยเพี้ยน หรือรหัสหายเลขศูนย์นำหน้า ให้ตรวจตัวคั่น การเข้ารหัส และชนิดข้อมูลก่อนวิเคราะห์
ผ่านส่วนนี้เมื่อ: บอกได้ว่าหนึ่งแถวหมายถึงอะไร และตรวจค่ากลับกับต้นทางได้

3 · PDF

PDF — เอกสารสำหรับเปิดอ่านและตรวจหน้าต้นทาง

PDF เก็บเอกสารที่จัดหน้าแล้ว เช่น บทความหรือรายงาน ไฟล์หนึ่งอาจมีทั้งข้อความที่เลือกคัดลอกได้และภาพสแกน เราเห็นหน้าเอกสารครบ แต่เครื่องมืออ่านข้อความอาจอ่านบางส่วนไม่ได้

ลองเลือกและคัดลอกข้อความสั้น ๆ จากหน้าที่ต้องใช้ ถ้าเลือกไม่ได้ อาจต้องใช้ OCR อ่านข้อความจากภาพ ถ้าเลือกได้ ก็ยังต้องตรวจลำดับการอ่าน ตาราง สมการ ตัวเลข และหน่วยกับภาพหน้าเอกสาร โดยเฉพาะหน้าสองคอลัมน์ ข้อความที่ AI อ่านได้ต้องเทียบกับต้นทางเสมอ

ลองทำและตรวจผล

  1. เปิด PDF บทความหรือรายงานที่จะใช้ในกิจกรรม แล้วเลือกหน้าที่มีทั้งข้อความและตารางหรือรูป
  2. ลองคัดลอกข้อความหนึ่งย่อหน้า และตรวจว่าลำดับข้อความตรงกับที่เห็นบนหน้า
  3. ให้ AI อ่านข้อความที่ระบุพร้อมบอกเลขหน้าหรือตำแหน่ง ถ้าอ่านไม่ได้ให้แจ้งตามจริง
  4. ตรวจข้อความหรือตัวเลขสองแห่งกลับกับหน้าเอกสาร รวมถึงเครื่องหมาย หน่วย และเชิงอรรถ
  5. ถ้าต้องแก้รายงานที่ตนสร้าง ให้แก้ต้นฉบับ เช่น MD หรือ Word แล้วสร้าง PDF ใหม่ ไม่แก้ PDF โดยตรง
อ่านเฉพาะหน้าที่ฉันระบุใน PDF นี้ ยกข้อความหรือตัวเลขสองแห่งพร้อมตำแหน่งให้ฉันตรวจกลับกับหน้าเอกสาร หากเป็นภาพสแกน อ่านไม่ได้ หรือลำดับข้อความกำกวม ให้แจ้งก่อนสรุป และเก็บต้นฉบับไว้
ผ่านส่วนนี้เมื่อ: เปิดหน้าต้นทาง ตรวจข้อความที่ AI อ่าน และบอกข้อจำกัดของไฟล์ได้

4 · JSON

JSON — ข้อมูลเป็นชื่อช่องและค่า

JSON เก็บข้อมูลเป็นชื่อช่องและค่าที่มีโครงสร้าง ตัวอย่างนี้เป็นสถานะฝึกอ่านไฟล์ ไม่ใช่ไฟล์ส่งงาน AIRR

{
  "activity": "file-reading-practice",
  "checks": {
    "source_opened": true,
    "values_verified": false
  },
  "verified_count": 0,
  "review_note": null
}

activity เป็นข้อความ verified_count เป็นจำนวน checks รวมสถานะย่อยไว้ true คือจริง false คือเท็จตามความหมายของช่องนั้น ส่วน null คือไม่มีค่า ซึ่งต่างจากเลข 0 และข้อความว่าง ""

ชื่อช่องและข้อความต้องอยู่ในเครื่องหมายคำพูดคู่ วงเล็บปีกกาครอบกลุ่มข้อมูล และจุลภาคคั่นรายการ ถ้าเครื่องหมายเหล่านี้ผิด โปรแกรมจะอ่านไฟล์ไม่ได้ ให้ AI ช่วยแก้โครงสร้างได้ แต่ค่าที่ใส่ต้องมาจากสิ่งที่คุณทำจริง

ลองทำและตรวจผล

  1. อธิบายว่าทำไม source_opened เป็น true แต่ values_verified ยังเป็น false
  2. ตรวจค่าจาก CSV ให้ครบสองค่าจริง ก่อนให้ AI เปลี่ยนสถานะเป็น true และจำนวนเป็น 2
  3. เปิด JSON ที่แก้แล้ว ตรวจว่าชื่อช่องเหมือนเดิม และเปลี่ยนเฉพาะค่าที่ยืนยันแล้ว
  4. ให้ AI หรือโปรแกรมตรวจว่าไฟล์อ่านเป็น JSON ได้ จากนั้นตรวจต่อว่าค่าตรงกับความจริง
อธิบายชื่อช่องและค่าใน JSON นี้ก่อน ฉันจะบอกผลที่ทำจริงทีละข้อ จากนั้นแก้เฉพาะค่าที่ฉันยืนยัน คงชื่อช่องไว้ ตรวจว่าอ่านเป็น JSON ได้ และแสดงรายการเปลี่ยนให้ฉันตรวจ
ผ่านส่วนนี้เมื่อ: แยกข้อความ จำนวน และสถานะได้ และอธิบายได้ว่า JSON ที่อ่านผ่านแล้วก็ยังอาจรายงานค่าผิดได้
