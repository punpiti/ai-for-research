Workshop

ตรวจชื่อเรื่องและบทคัดย่อ

ใน workshop นี้คุณจะตรวจว่าชื่อเรื่องและบทคัดย่อบอกปัญหา วิธี ผล และข้อสรุปตรงกับเนื้องาน

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • เอกสารของคุณ (proposal บทความ หรือวิทยานิพนธ์) ที่มีสิทธิ์นำเข้า AI วางไว้ในโฟลเดอร์งาน เช่น module-03-work/input/

แนวคิดที่ใช้

1. ชื่อเรื่องวิจัย

  • ต้องทำ: ระบุปรากฏการณ์ ตัวแปรหลัก หรือการแทรกแซง ประชากร/บริบท และบางครั้งรวมการออกแบบงานวิจัย
  • ตรวจ: ชื่อเรื่องอธิบายงานที่ทำจริงหรือไม่
  • การค้นเจอ: ชื่อเรื่องที่อ่อนทำให้งานค้นไม่เจอ ผู้อ่าน ผู้ประเมิน และระบบค้นหาควรพอรู้หัวข้อ บริบท และสิ่งหลักที่ศึกษาจากชื่อเรื่อง
  • ความผิดพลาดที่พบบ่อย: ใช้คำว่า “มีประสิทธิผล” “เหมาะที่สุด” หรือ “ผ่านการตรวจสอบแล้ว” โดยไม่มีการเปรียบเทียบหรือหลักฐานรองรับ
  • ตัวอย่าง: “การเปลี่ยนแปลงคะแนนความหิวที่รายงานด้วยตนเองใน 60 นาทีหลังอาหารที่กำหนด: การสังเกตกรณีเดียว”

2. บทคัดย่อ

  • ต้องมี: ปัญหา/ความจำเป็น วัตถุประสงค์ การออกแบบ/ข้อมูล วิธีวิจัย ผลหลัก และข้อสรุปที่มีขอบเขต
  • ตรวจ: ตัวเลขและข้อกล่าวอ้างในบทคัดย่อตรงกับรายงานหลักหรือไม่
  • ความผิดพลาดที่พบบ่อย: บทคัดย่อมีแรงจูงใจและวิธีวิจัย แต่ไม่มีผลจริง
  • ผลต่อผู้อ่าน: ถ้าบทคัดย่ออ่านไม่เข้าใจ ผู้อ่านจะไม่คาดหวังว่าส่วนอื่นจะชัดขึ้น บทคัดย่อที่อ่อนมักทำให้คนหยุดอ่าน
  • กติกา: บทคัดย่อคือสายเหตุผลของงานวิจัยแบบย่อ ไม่ใช่โฆษณา

ขั้นที่ 1 — อ่านแนวคิดแล้วเลือกส่วนที่จะตรวจ

อ่าน "แนวคิดที่ใช้" ด้านบน แล้วเลือกส่วนของเอกสารที่เกี่ยวกับชื่อเรื่องและบทคัดย่อ จดชื่อหัวข้อและเลขหน้า

ตรวจ: บอกได้ว่าส่วนที่เลือกอยู่หน้าไหน และเกี่ยวกับแนวคิดข้อใด

ขั้นที่ 2 — ให้ AI ตรวจพร้อมตำแหน่ง

วาง prompt นี้ แล้วระบุ path ของเอกสารและส่วนที่เลือก

อ่านเฉพาะส่วนที่ฉันระบุในเอกสารนี้ ตรวจตามแนวคิดเรื่องชื่อเรื่องและบทคัดย่อ ทุกประเด็นต้องยกข้อความจริงพร้อมหัวข้อและเลขหน้า แยกสิ่งที่ยืนยันได้จากเอกสาร สิ่งที่เป็นการตีความ และสิ่งที่ยังต้องตรวจ จัดระดับความรุนแรง (สำคัญ / ควรแก้ / เล็กน้อย) ห้ามแก้ไฟล์ ห้ามเติมข้อมูลที่เอกสารไม่มี

ตรวจ: ทุกประเด็นที่ AI ยกมามีข้อความจริงและเลขหน้า

ขั้นที่ 3 — ตรวจผลของ AI เอง

เปิดเอกสารไปที่ตำแหน่งที่ AI อ้างอย่างน้อยสองจุด เทียบข้อความ แล้วตัดสินเองว่าเห็นด้วย เห็นด้วยบางส่วน หรือไม่เห็นด้วย พร้อมเหตุผล บันทึกลง module-03-work/notes/review-notes.md

ตรวจ: review-notes.md มีอย่างน้อยสองประเด็นที่คุณเปิดตรวจเองพร้อมคำตัดสินและเหตุผล

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI ช่วยตรวจงานของคุณด้วยแนวคิดของหัวข้อนี้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้แล้ว
  • งานอีกส่วนหนึ่งของคุณ (หรือของนิสิตที่ดูแล) ที่ยังไม่ได้ตรวจใน workshop

โจทย์

  1. สร้างไฟล์ output/prompts.md ในโฟลเดอร์งานของคุณ สำหรับเก็บ prompt ทุกรอบ
  2. เขียน prompt ของตนให้ AI ตรวจชื่อเรื่องและบทคัดย่อ โดยบังคับให้ยกข้อความพร้อมตำแหน่ง
  3. ตัดสินเองทุกประเด็น แล้วแก้งานจริงอย่างน้อยหนึ่งจุด
