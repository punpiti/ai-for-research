Prompt

สร้าง PDF จาก content.md

ใน workshop นี้คุณจะให้ AI สร้าง PDF จากไฟล์ Markdown เปิดตรวจเอง แล้วแก้ที่ต้นฉบับและสร้างใหม่

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • ไฟล์ module-01-work/content.md (ตัวติดตั้ง Module 1 สร้างไว้ให้ เป็นข้อความตัวอย่าง)

ขั้นตอน

  1. เปิด module-01-work/content.md แล้วพิมพ์หัวข้องานวิจัยของคุณเป็นภาษาไทยหนึ่งบรรทัด

  2. กด Ctrl+Shift+V (macOS: Command+Shift+V) ดู Preview ว่าหัวข้อแสดงตามที่พิมพ์

  3. สั่ง AI

    อ่าน module-01-work/content.md แล้วสร้าง module-01-work/output/content.pdf โดยไม่เปลี่ยนไฟล์ต้นฉบับ จากนั้นตรวจว่า PDF เปิดอ่านได้

  4. เปิด module-01-work/output/content.pdf ที่ AI เพิ่งสร้าง ดูสระ วรรณยุกต์ และว่าไม่มีกล่องสี่เหลี่ยมแทนตัวอักษร

  5. สั่ง AI แก้ที่ต้นฉบับแล้วสร้างใหม่ (ไม่แก้ PDF โดยตรง)

    แก้ module-01-work/content.md โดยเพิ่มบรรทัดสั้น ๆ หนึ่งบรรทัดท้ายไฟล์ว่า "ทดสอบการแก้ไฟล์ด้วย AI" ห้ามเปลี่ยนบรรทัดอื่น แสดงสิ่งที่เปลี่ยน แล้วสร้าง module-01-work/output/content.pdf ใหม่จากไฟล์นี้

สร้าง PDF แรกจาก Markdown ด้วย AI: แก้ที่ต้นฉบับ แล้วสร้างใหม่

ไม่มี prompt สำเร็จรูป — เขียนเอง

โจทย์

  • เลือกข้อความสั้นจากงานของคุณที่เปิดเผยได้ (บทคัดย่อ คำอธิบายโครงการ ประกาศถึงนิสิต ไม่เกินหนึ่งหน้า)
  • ให้ AI วางเป็นไฟล์ Markdown ใหม่ในโฟลเดอร์งาน แก้หนึ่งจุดตามที่คุณกำหนด แล้วสร้าง PDF ลง output/
  • เปิด PDF หาจุดที่ต้องแก้อย่างน้อยหนึ่งจุด แล้วแก้ที่ Markdown และสร้าง PDF ใหม่

ข้อกำหนด

  • เก็บ prompt ทุกรอบไว้ใน output/prompts.md
  • บันทึกเหตุผลว่าทำไมข้อความที่เลือกจึงนำเข้า AI ได้ (สิทธิ์และความเป็นส่วนตัว)
