Prompt

สร้าง PDF จาก content.md

ใน workshop นี้คุณจะให้ AI สร้าง PDF จากไฟล์ Markdown เปิดตรวจเอง แล้วแก้ที่ต้นฉบับและสร้างใหม่

ใช้เมื่อ: ยังไม่เคยสร้าง PDF ภาษาไทยจาก Markdown ใน workspace นี้ หรือก่อนทำ Module 8

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว
  • ไฟล์ module-01-work/content.md (ตัวติดตั้ง Module 1 สร้างไว้ให้ เป็นข้อความตัวอย่าง)

คำที่ใช้ใน workshop นี้

  • ต้นฉบับ — ไฟล์ .md ที่แก้ได้ · ผลลัพธ์ — PDF ที่สร้างจากต้นฉบับ แก้ตรงไม่ได้
  • สร้างใหม่ (build) — ให้ AI แปลงต้นฉบับเป็น PDF อีกรอบหลังแก้ต้นฉบับ
  • กล่องสี่เหลี่ยม — ตัวอักษรที่ฟอนต์ไม่มี เป็นสัญญาณว่า PDF ภาษาไทยมีปัญหา

เริ่มหัวข้อ — ให้ AI รู้ว่ากำลังทำโมดูลไหน

ถ้าแชต AI เดิมทำโมดูลอื่นอยู่ ให้เปิดแชตใหม่ก่อน แล้ววาง prompt นี้

เริ่ม Module 1 หัวข้อ "สร้าง PDF แรกจาก Markdown ด้วย AI: แก้ที่ต้นฉบับ แล้วสร้างใหม่": รัน AIRR update แล้วรัน AIRR init module-1 (ต้องทำทุกครั้งที่เริ่มหัวข้อ ไฟล์ที่ฉันแก้แล้วจะไม่ถูกเขียนทับ) แล้วอ่านส่วน AIRR CONTEXT ที่ได้ ทำงานตามแผนที่ไฟล์ใน module-01-work/ เท่านั้น อ่าน input/ และ course-materials/ โดยห้ามแก้ และเขียนผลลงตำแหน่งที่หัวข้อนี้กำหนด

ตรวจ: AI แสดง AIRR INIT PASS · module-1 และบอกได้ว่าไฟล์ที่หัวข้อนี้ใช้อยู่ที่ไหน

ขั้นที่ 1 — ใส่หัวข้องานวิจัยในต้นฉบับ

เปิด module-01-work/content.md แล้วพิมพ์หัวข้องานวิจัยของคุณเป็นภาษาไทยหนึ่งบรรทัด บันทึกไฟล์

ตรวจ: กด Ctrl+Shift+V (macOS: Command+Shift+V) แล้ว Preview แสดงหัวข้อตามที่พิมพ์

ขั้นที่ 2 — ให้ AI สร้าง PDF

อ่าน module-01-work/content.md แล้วสร้าง module-01-work/output/content.pdf โดยไม่เปลี่ยนไฟล์ต้นฉบับ จากนั้นตรวจว่า PDF เปิดอ่านได้

ตรวจ: AI แจ้งว่าสร้าง module-01-work/output/content.pdf แล้ว และไม่ได้แก้ content.md

ขั้นที่ 3 — เปิด PDF ตรวจภาษาไทยเอง

เปิด module-01-work/output/content.pdf ดูสระ วรรณยุกต์ และตัวอักษรทุกตัวในหัวข้อของคุณ

ตรวจ: ภาษาไทยอ่านถูก ไม่มีกล่องสี่เหลี่ยมแทนตัวอักษร และสระไม่ลอยหรือซ้อนผิดที่

ขั้นที่ 4 — แก้ที่ต้นฉบับแล้วสร้างใหม่

แก้ module-01-work/content.md โดยเพิ่มบรรทัดสั้น ๆ หนึ่งบรรทัดท้ายไฟล์ว่า "ทดสอบการแก้ไฟล์ด้วย AI" ห้ามเปลี่ยนบรรทัดอื่น แสดงสิ่งที่เปลี่ยน แล้วสร้าง module-01-work/output/content.pdf ใหม่จากไฟล์นี้

ตรวจ: AI แสดงว่าเพิ่มเพียงหนึ่งบรรทัด และ PDF ที่เปิดใหม่มีบรรทัดนั้น

ขั้นที่ 5 — บอกว่าถ้า PDF ผิดต้องแก้ที่ไหน

เขียนหนึ่งประโยคว่าถ้าเจอคำผิดใน PDF จะกลับไปแก้ไฟล์ใด

ตรวจ: คำตอบคือแก้ content.md แล้วสร้าง PDF ใหม่ ไม่ใช่แก้ PDF

Exploring

สร้าง PDF แรกจาก Markdown ด้วย AI: แก้ที่ต้นฉบับ แล้วสร้างใหม่

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI สร้าง PDF จากข้อความในงานของคุณ แล้วแก้ที่ต้นฉบับและสร้างใหม่

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้แล้ว (สร้าง module-01-work/output/content.pdf ได้)
  • ข้อความสั้นจากงานของคุณที่เปิดเผยได้ ไม่เกินหนึ่งหน้า

โจทย์

  • เลือกข้อความสั้นจากงานของคุณที่เปิดเผยได้ (บทคัดย่อ คำอธิบายโครงการ ประกาศถึงนิสิต ไม่เกินหนึ่งหน้า)
  • ให้ AI วางเป็นไฟล์ Markdown ใหม่ในโฟลเดอร์งาน แก้หนึ่งจุดตามที่คุณกำหนด แล้วสร้าง PDF ลง output/
  • เปิด PDF หาจุดที่ต้องแก้อย่างน้อยหนึ่งจุด แล้วแก้ที่ Markdown และสร้าง PDF ใหม่

ข้อกำหนด

  • เก็บ prompt ทุกรอบไว้ใน output/prompts.md
  • บันทึกเหตุผลว่าทำไมข้อความที่เลือกจึงนำเข้า AI ได้ (สิทธิ์และความเป็นส่วนตัว)
