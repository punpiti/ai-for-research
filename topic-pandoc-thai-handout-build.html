Workshop

สร้างเอกสารประกอบการสอนภาษาไทยด้วย pandoc ตัวกรอง Lua และ XeLaTeX

ใน workshop นี้คุณจะแยกเนื้อหา Markdown ออกจากรูปแบบ (metadata ส่วนหัว LaTeX ตัวกรอง Lua)

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ผ่าน Module 1: เปิด ai-for-research-workspace ใน VS Code และ AI panel เชื่อมแล้ว (มี pandoc และ XeLaTeX จากตัวติดตั้ง)
  • ทำหัวข้อ "สร้าง PDF จาก Markdown ครั้งแรก" ของ X01 แล้ว
  • ไฟล์ Markdown ภาษาไทยของคุณ เช่น เอกสารประกอบการสอน คู่มือ หรือรายงาน

ขั้นที่ 1 — แยกเนื้อหาออกจากรูปแบบ

เขียนเนื้อหาเป็น Markdown ไฟล์เดียว ส่วนรูปแบบเก็บแยก: metadata (.yaml) ส่วนหัว LaTeX (.tex) และตัวกรอง Lua (.lua) ที่ปรับตาราง กล่องข้อความ และหัวข้อ

ตรวจ: ไฟล์เนื้อหาไม่มีคำสั่ง LaTeX ปนอยู่

ขั้นที่ 2 — ให้ AI สร้างชุดสร้าง PDF

สร้างโฟลเดอร์ module-09-work/handout/ มี metadata.yaml (ชื่อเรื่อง ผู้เขียน ภาษา th ฟอนต์ Sarabun) header.tex (ส่วนหัว/ท้ายหน้า เลขหน้า) filter.lua (ปรับความกว้างคอลัมน์ของตารางตามเนื้อหา) และ build.sh ที่เรียก pandoc --pdf-engine=xelatex กับไฟล์ Markdown ของฉัน แสดงไฟล์ที่สร้างให้ฉันตรวจก่อนรัน

ตรวจ: มีครบสี่ไฟล์ และ build.sh ไม่ลบหรือแก้ไฟล์ Markdown ต้นฉบับ

ขั้นที่ 3 — สร้างและตรวจ PDF

ให้ AI รัน build.sh แล้วเปิด PDF ตรวจภาษาไทย ตาราง สารบัญ และลิงก์

ตรวจ: ไม่มีกล่องสี่เหลี่ยม ตารางไม่ล้นหน้า และสารบัญกดไปหัวข้อได้

Exploring

สร้างเอกสารประกอบการสอนภาษาไทยด้วย pandoc ตัวกรอง Lua และ XeLaTeX

ในโจทย์นี้คุณจะเขียน prompt เองให้ AI ช่วยตรวจงานของคุณด้วยแนวคิดของหัวข้อนี้

ไม่มี prompt สำเร็จรูปให้

ก่อนเริ่ม (ต้องมีอยู่แล้ว)

  • ทำ workshop ของหัวข้อนี้แล้ว
  • งานอีกส่วนหนึ่งของคุณ (หรือของนิสิตที่ดูแล) ที่ยังไม่ได้ตรวจใน workshop

โจทย์

  1. สร้างไฟล์ output/prompts.md ในโฟลเดอร์งานของคุณ สำหรับเก็บ prompt ทุกรอบ
  2. เขียน prompt ของตนให้ AI ตรวจการสร้างเอกสารภาษาไทยจาก Markdown โดยบังคับให้ยกข้อความพร้อมตำแหน่ง
  3. ตัดสินเองทุกประเด็น แล้วแก้งานจริงอย่างน้อยหนึ่งจุด
